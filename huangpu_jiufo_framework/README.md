# 广州黄埔区九佛TOD全球自贸区 — 策划服务建议书(报价版)

依据线上沟通确定的策划服务框架:第一至第三部分由我方(复旦大学住房政策研究中心、
上海市杨浦区科技企业联合会)负责;第四部分「场景营造与空间引导」由**内里集**负责,
我方不承担该部分工作。我方负责范围(第一至第三部分)按 **16 万元**报价(含税参考价)。
