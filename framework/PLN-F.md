# 前世叙事的功能分析框架（PLN-F）

> Past-Life Narrative Functional Framework · v1.0  
> 用途：内容分析、语料标注、AI 提示约束、跨文化对照。  
> 姿态：功能分析 ≠ 真伪裁判；描述叙事「完成了什么社会—心理工作」。

---

## 1. 核心主张

前世故事的情节可以无穷变幻，但其**稳定功能**高度收敛为四维：

| 代码 | 中文 | English | 一句话 |
|------|------|---------|--------|
| F1 | 心理补偿 | Psychological Compensation | 用「另一世的我」消化创伤、遗憾、不公与未完成之事 |
| F2 | 关系解释 | Relational Explanation | 为亲密、疏离、冲突与缘分提供超验因果剧本 |
| F3 | 身份建构 | Identity Construction | 借前世地位/天赋/使命重写当下自我叙事 |
| F4 | 道德约束 | Moral Constraint | 以跨世因果规范行为，把伦理后果拉长到来世 |

真实文本通常是**主功能 + 辅功能**叠加，很少单维。

---

## 2. 四维详解

### F1 心理补偿

- **触发**：丧失、挫败、创伤、疾病、阶层固化、平凡自我的不满。
- **机制**：意义修复、责任部分外移、希望延期（来世可偿）。
- **信号词/装置**：功课、消业、未完成的功课、催眠回溯、灵魂功课。
- **受益对象**：主要是叙事主体的自我整合与情绪调节。

### F2 关系解释

- **触发**：强烈吸引/排斥、反复纠缠、亲子张力、圈内认同。
- **机制**：把偶然关系改写为「早有剧本」；为原谅或决裂提供合法性。
- **信号词/装置**：缘分、债、冤家、灵魂伴侣、双生火焰、讨债孩子。
- **受益对象**：关系双方或家庭系统。

### F3 身份建构

- **触发**：边缘感、成名欲、天赋叙事需求、制度性宗教身份。
- **机制**：前世地位抬升当下；使命叙事赋予人生目的；制度化认证（如活佛）。
- **信号词/装置**：转世、活佛、圣者前世、灵魂家族、特殊使命。
- **风险**：精英前世通胀、历史/族群挪用、权威压制对话。

### F4 道德约束

- **触发**：需要超越当世可见奖惩的伦理秩序。
- **机制**：善恶账本跨世；恐惧（恶趣）+ 希望（福报）双轨规训。
- **信号词/装置**：业、果报、功德、恶报、戒律、劝善。
- **受益对象**：社群秩序与个体自我规训。

## 3. 跨文化功能权重（启发式）

权重：● 强 · ◐ 中 · ○ 弱（分析用，非绝对）。

| 文化传统 | F1 补偿 | F2 关系 | F3 身份 | F4 道德 | 主导载体 |
|----------|---------|---------|---------|---------|----------|
| 印度教/佛教教理 | ◐ | ◐ | ● | ● | 经典、戒律、修行阶位 |
| 汉传民间 | ◐ | ● | ○ | ● | 善书、宝卷、家庭伦理叙事 |
| 藏传转世制度 | ○ | ◐ | ● | ◐ | 寻访、认证、坐床制度 |
| 日本流行文化 | ◐ | ● | ◐ | ○ | 动漫、小说、命定重逢 |
| 西方新时代 | ● | ● | ● | ○ | 催眠回溯、工作坊、疗愈课 |
| 非洲祖灵回归 | ◐ | ◐ | ● | ◐ | 氏族连续、祖先义务 |

### 读法

- **教理传统**往往 F4/F3 重，私人疗愈口语弱。
- **流行与消费灵性**往往 F1/F2/F3 重，F4 淡化。
- **制度化转世**把 F3 做成可认证的社会资本。
- **祖灵型**强调社群连续，而非「我前世是法老」式个人幻想。

---

## 4. 功能联动（常见组合）

1. **补偿 → 关系**：疗愈闭环常落在「前世爱人出现」。
2. **身份 → 道德**：「我曾是修行者」既抬升自我，也施加戒律期待。
3. **道德 → 补偿**：「受苦是消业」把惩罚话术改写成安慰。
4. **关系 → 身份**：「灵魂家族」同时划圈与抬高圈内人。

标注时写：`primary_function` + `secondary_functions[]`。

---

## 5. AI 标注字段

与 `framework/pln_f.schema.json` 对齐：

| 字段 | 说明 |
|------|------|
| `primary_function` | F1–F4 单选 |
| `secondary_functions` | 辅功能多选，可空 |
| `culture_frame` | 教理 / 民间 / 流行 / 治疗 / 制度 / 祖灵 等 |
| `narrative_device` | 业、缘、债、使命、回溯等装置词列表 |
| `beneficiary` | self / dyad / family / community / institution |
| `legitimacy_claim` | 经典、大师、催眠、梦、族谱、平台达人等 |
| `evidence_spans` | 支撑判定的原文片段 |
| `risk_flags` | historical_appropriation / coercive_framing / anxiety_marketing / elite_inflation 等 |
| `cross_cultural_note` | 若换文化框架，功能权重可能如何漂移 |

---

## 6. 推荐分析提示词

```text
请用 PLN-F（前世叙事功能分析框架）分析下列文本：
1) 判定 primary_function 与 secondary_functions，并引用原文依据（evidence_spans）；
2) 指出 narrative_device 与 culture_frame；
3) 说明 beneficiary 与 legitimacy_claim；
4) 若跨文化改写，功能权重可能如何漂移（cross_cultural_note）；
5) 标出 risk_flags（若无则空数组）。
输出严格符合 pln_f.schema.json 的 JSON；不做真伪裁决。
```

---

## 7. 应用与边界

**适用**：内容研究、标注体系、叙事生成约束、疗愈伦理审查、RAG 知识片段。

**边界**：

- 不宣称前世存在与否；不把信仰降格为「纯幻觉」。
- 矩阵是启发式工具；深度个案需民族志与教义学。
- 不以框架协助操控性营销或针对脆弱人群的恐惧贩卖。
