# 汇报 PPT 生成器

本目录包含一份 Python 脚本，用 [`python-pptx`](https://python-pptx.readthedocs.io/) 生成汇报演示文稿：

> **《面向"十五五"的不动产转型与高质量发展：从空间开发向科技赋能平台迈进》**

输出文件位于仓库根目录：`十五五不动产高质量发展汇报.pptx`（共 24 页，16:9）。

## 使用方法

```bash
pip install python-pptx
python3 ppt/build_ppt.py
```

脚本运行后会在仓库根目录覆盖生成 `十五五不动产高质量发展汇报.pptx`。
