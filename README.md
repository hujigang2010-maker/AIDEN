# 群邦 · 领事会客厅 —— 三方战略合作策划案

以领事为纽带的城市开放与企业出海引领计划。本仓库用脚本一键生成可直接对外使用的
**PPT 策划案**、**Excel 收费与测算表格** 以及 **Markdown 文稿**。

合作三方：

- **复旦大学政党建设研究中心**（或相关政策研究中心）—— 学术与政策背书
- **上海市杨浦区科技企业联合会** —— 企业资源与产业落地
- **APP 群邦俱乐部（88 国总领事俱乐部，金茂大厦 86 楼）** —— 领事资源与活动落地

## 交付物（`output/`）

| 文件 | 说明 |
| --- | --- |
| `群邦-领事会客厅-三方战略合作策划案.pptx` | 21 页 PPT 策划案（含 7 张数据表页） |
| `群邦-领事会客厅-收费与测算表格.xlsx` | 8 个工作表的收费、分润、路线图与收入测算 |
| `群邦-领事会客厅-策划案.md` | 便于阅读与二次编辑的 Markdown 文稿 |

## 核心内容

1. **背景与机遇** —— 领事人脉 + 金茂 86 楼地标空间 + 高校背书的稀缺叠加。
2. **价值闭环** —— 活动获客 → 会籍沉淀 → 出海·招商 → 政企复购。
3. **六大产品线** —— 国家会客厅、领事专题活动（小/中/大型）、高端商务出海深度游、
   企业出海对接、会员体系、智库·课题·培训。
4. **国家会客厅（旗舰）** —— “某某国家会客厅”空间命名、企业会籍、园区/政府招商。
5. **收费体系与测算** —— 七张表给出活动、会客厅、出海、会员定价，三方分润、
   12 个月路线图与第一年收入测算。
6. **合规与风险** —— 外事纪律、内容中立、财务与品牌风险管理。

> 所有金额均为人民币，用于商业测算示意，最终以三方框架协议及单项目合同为准。

## 重新生成

依赖：`python-pptx`、`openpyxl`。

```bash
pip install python-pptx openpyxl

python3 scripts/generate_ppt.py     # 生成 PPT
python3 scripts/generate_tables.py  # 生成 Excel
python3 scripts/generate_md.py      # 生成 Markdown
```

全部结构化内容集中在 `scripts/content.py`，修改后重新运行即可同步更新三份交付物。
