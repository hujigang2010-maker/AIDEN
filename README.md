# 复旦大学住房政策研究中心 · 小程序交付包

本分支在《小程序执行文案》V1.0 基础上完成文案优化，并提供两套可交付物：

1. **HTML 高保真样张**（可直接浏览器演示）
2. **微信小程序源码骨架**（可用微信开发者工具导入）

> 说明：云端环境无法完成微信小程序正式发布（需 AppID、微信开发者工具与主体认证）。因此以 HTML 样张作为即时展示，小程序源码供本地导入继续开发。

---

## 目录结构

```
docs/                 优化版执行文案（Markdown + DOCX）
demo/index.html       微信小程序风格交互样张（推荐演示）
miniprogram/          可导入微信开发者工具的源码
```

---

## 快速预览 HTML 样张

在仓库根目录启动静态服务后，打开 `demo/index.html`：

```bash
python3 -m http.server 8080 --directory demo
# 浏览器访问 http://localhost:8080/
```

样张包含：

- 首页主视觉与四入口
- 研究成果分类筛选与详情
- 政策数据库搜索 / 分类
- 关于中心展开介绍与邮箱复制

---

## 导入微信小程序

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「导入项目」，目录指向本仓库的 `miniprogram/`
3. AppID 可先使用测试号 / `touristappid`，正式上线前替换为中心主体 AppID
4. 替换 `utils/data.js` 中的演示数据与图片资源

### 已实现页面

| 页面 | 路径 | 能力 |
|------|------|------|
| 首页 | `pages/index` | 主视觉、入口、动态流、分享 |
| 研究成果 | `pages/research` | 分类筛选、卡片列表、详情跳转 |
| 政策数据库 | `pages/policy` | 搜索、分类、空态提示 |
| 关于中心 | `pages/about` | 简介展开、研究方向、联系复制 |
| 详情 | `pages/detail` | 研究/政策详情 |
