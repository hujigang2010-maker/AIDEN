# 复旦大学住房政策研究中心 · 活动平台小程序

参照「复旦管院校友平台」小程序，为住房政策研究中心搭建以**活动**为核心的服务平台：覆盖未来活动、活动回顾与主题展示，并提供明确**收费入口**。

## 交付物

| 文件 | 说明 |
|------|------|
| `output/复旦大学住房政策研究中心-小程序功能蓝图.xlsx` | 管理学院 / EE 教育中心职能清单 → 住房中心功能映射、收费设计、MVP 分期 |
| `miniprogram/` | 可导入微信开发者工具的小程序演示工程 |
| `demo/index.html` | 浏览器可直接打开的交互演示 |
| `docs/产品说明.md` | 定位、信息架构与收费说明 |

## 重新生成 Excel

```bash
python3 scripts/build_hprc_platform_excel.py
```

## 微信开发者工具

1. 导入目录 `miniprogram/`
2. AppID 可选用测试号
3. 支付为演示弹窗，不会真实扣款

## 信息架构（Tab）

首页｜活动｜回顾｜我的

- **活动**：论坛 / 沙龙 / 培训 / 参访，含票种与报名支付
- **回顾**：往期纪要、相册、主题展览入口
- **我的**：会员、支持中心、订单（收费入口聚合）
