# 赴宁波港及宁波经济技术开发区考察交流策划案

面向 **宁波经济技术开发区投资促进局** 的正式策划案，由以下双方联合组织提交：

- 复旦大学住房政策研究中心
- 上海市杨浦区科技企业联合会

考察人员为复旦大学校友及上海市科技企业家，拟于 **2026年8–10月择一两日** 赴宁波港精选点位及当地特色企业开展参访与投促交流，围绕招商引资、科技孵化、产业导入、PE/VC 与 CVC 投资等事项建立可跟进的互动链接。

## 交付物

| 文件 | 说明 |
| --- | --- |
| `output/赴宁波港及宁波经济技术开发区考察交流策划案.docx` | 正式 Word 策划案（可直接发送贵局） |
| `output/赴宁波港及宁波经济技术开发区考察交流策划案.pptx` | 汇报版 PPT（17 页） |
| `output/赴宁波港及宁波经济技术开发区考察交流策划案.md` | Markdown 便于阅读与二次编辑 |

## 内容结构（V1.1）

1. 项目背景与目的  
2. 组织方与接待单位分工  
3. 考察人员构成（建议 15–30 人）  
4. 四大合作方向  
5. **宁波港及周边参访资源筛选**（可接待 / 认知价值 / 产业匹配 / 互动转化）  
   - 港口线：穿山港区北三集司、环球航运广场展示厅、梅山港区、中国港口博物馆  
   - 产业孵化线：海天智造、极氪梅山工厂、拓普/东方电缆、科技创业园2.0/甬江科创区  
   - 四大互动链接：港航圆桌、制造对接、落地工作坊、PE/VC·CVC 投洽  
6. 时间与已嵌入点位的一日 / 两日行程  
7. 预期成果与长效合作  
8. 恳请投促局支持事项与下一步工作  

## 生成方式

```bash
pip install python-pptx python-docx
python3 generate_word.py
python3 generate_ppt.py
python3 generate_md.py
```

所有文案集中在 `content.py`，三份交付物共享，保证内容一致。
