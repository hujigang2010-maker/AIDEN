# 东方修行路径对照表

对照佛家（禅宗 / 净土 / 唯识）、道家（内丹 / 符箓 / 导引）、儒家（修身 / 慎独）的目标、方法、入门门槛与典型误区。

## 交付物

| 文件 | 说明 |
|------|------|
| `deliverables/东方修行路径对照表.xlsx` | 九个工作表：总览、三教总对照、分路径详表、四维深比、入门路线图、误区速查、术语简释 |
| `deliverables/东方修行路径对照表.pptx` | 14 页讲解稿，便于分享与讨论 |

## 重新生成

```bash
python3 scripts/build_cultivation_paths_excel.py
python3 scripts/build_cultivation_paths_ppt.py
```

依赖：`python-pptx`、`openpyxl`。

## 使用说明

- 本材料是**知识对照 / 学习地图**，非宗教劝信，亦不替代师承与专业医疗。
- 建议先读 Excel「01 三教总对照」，再按兴趣进入分路径表；用「06 入门路线图」「07 误区速查」做选择与自检。
