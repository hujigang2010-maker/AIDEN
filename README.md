# AI × 不动产资产管理高级研修班

本分支交付一份对外展示用的 16:9 PPT 方案，依据 2026-08-28 项目研讨材料整理，主线为 **AI + 不动产资产管理培训**。澳大利亚商务考察仅作为圈层延展出现，不并入主报价。

## 生成

```bash
python3 scripts/build_ai_real_estate_deck.py
```

输出：`output/AI+不动产资产管理高级研修班_合作方案.pptx`

依赖：`python-pptx`。中文字体使用文泉驿微米黑。

## 主办与分成口径

- **联合主办**：复旦大学住房政策研究中心、上海市杨浦区科技企业联合会、上海市工商联房地产商会资产管理分会。
- **L1（建议默认）**：中心联合主办，学费进第三方账户。复旦中心品牌使用费建议为学费的 10%–15%（待中心书面确认）；渠道与班费先扣后，剩余按科企联 30% / 资管分会 35% / 运营 35% 分配。
- **L2（学员点选）**：学校官方结业证 + 学校发票。学校非学历培训分成待书面确认，按同类高校 50%–80% 预留（交大口径约 80%）。
- 复旦的「品牌 / 意识形态审核」和「学校财务分成」分开列项，不混成一笔。

## 使用说明

- 适合对三家主办和渠道讲解，约 20–25 分钟。
- 收益页为合作对齐用示意测算，不是对学员的承诺。
- 招生主视觉不得使用复旦校名、校徽；固定表述为「住房政策研究中心联合主办」。
