## 结论（先看这里）

- **谁受伤**：64 岁男性胡志远（病历、腕带、出院记录；云影像脱敏为胡**）。
- **伤了什么**：右开放性踝关节骨折脱位、韧带断裂、皮肤坏死；胫骨远端和腓骨近端骨折。**2026-08-14 19:01** 在齐鲁医院手足与显微重建外科行切开复位内外固定、韧带缝合、清创、VSD。8 月 15 日是术后 CT，不是手术日。
- **什么不是这次伤的**：右足组成骨完整；跟骨骨刺、退变不要写成跟骨粉碎骨折。高血压、糖尿病是既往病。
- **谁伤残**：**现在谁都还没有伤残等级。** CT 和出院记录都不是伤残鉴定书。评残须治疗终结后由司法鉴定机构做。
- **医院**：齐鲁住院号 0001519455，2026-08-14 14:14 入院、08-17 08:00 出院，住院 3 天。人已到市北区人民医院。转院录音只看三点——原医院结算、新医院入院、承保公司书面确认二甲资格和比例。费用按 4 万元逐笔核清。
- **本周**：医保能报 ≠ 美团险能报。出院时仍带 VSD 和外固定架，不是康复期。
- **过程补充（8/19 确认）**：地点为抚顺路和哈尔滨路路口（抚顺路批发市场）。认定书尚未出具。人民医院可以赔、比例待定。驾驶人有驾驶资格证书。乔刘记商贸/刘孝春雇佣无合同，工伤排除，已垫付 3 万须写收据。

## 网页总览（思维树）

进入 `web/` 后安装并启动：

```bash
cd web
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`。三个页签：

1. **思维树**：点树枝看「做什么 / 怎么推进 / 会得到什么」
2. **每周做什么**：第 1 周到评残
3. **会得到什么**：过程结果、钱从谁出、甲乙丙三种结局

构建静态页：`npm run build`，产物在 `web/dist/`。
