# 上海学区板块差异化选房地图

基于「避开新上海人集中新区、选择人口空心化老板块」的选房纪要，对全市主要板块做学区竞争与策略契合度标记。

## 生成方式

```bash
python3 scripts/generate_shanghai_school_district_map.py
```

## 交付物

| 文件 | 说明 |
|------|------|
| `output/上海学区板块差异化选房地图.xlsx` | 五工作表：入选结果、全市板块标记、十六区总览、图例逻辑、统计 |
| `output/上海学区板块差异化选房地图.html` | 可筛选交互页，含入选看房清单 |

本地预览 HTML：

```bash
python3 -m http.server 8765 --directory output
# 浏览器打开 http://localhost:8765/上海学区板块差异化选房地图.html
```

## 本轮入选（策略结果）

1. **浦东 · 潍坊新村（陆家嘴南）** — 明珠/浦师附小，纪要核心推荐  
2. **杨浦 · 鞍山/四平、杨浦滨江** — 老破小挂户 + 滨江空心化特征  
3. **黄浦 · 五里桥、打浦桥、老西门/蓬莱、豫园等** — 老城人口少、公办均衡  
4. **次优观察** — 虹口老板块、塘桥、黄兴公园等  

排除主线：嘉定、松江（含九亭）、闵行大部分、浦东大部分（张江/花木等）。

> 对口学校与入户年限以各区教育局当年文件为准；本表为决策辅助，非官方承诺。
