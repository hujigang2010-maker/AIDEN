# 上海 / 长三角产业研学考察计划 与 合作框架

面向「中钢协流通分会 × 复旦大学房地产研究中心 × 杨浦区科技企业联合会」三方合作，
生成两份交付物：

- **PPT**：`output/中钢协_上海长三角产业研学考察计划与合作框架.pptx`（12 页）
- **Excel**：`output/中钢协_上海长三角产业研学考察计划_排期表.xlsx`（7 个工作表）

## 内容概要

四期考察，每期两天半（2.5 天），上海为主、长三角延伸，每期含标杆项目（房地产标杆项目，非房企）、
标杆园区、智能制造工厂与科技企业，并配供需闭门撮合：

| 期次 | 时间窗口 | 主题 |
| --- | --- | --- |
| 第一期 | 8月底/9月初 | 地产标杆 × 城市更新（存量盘活） |
| 第二期 | 9月底/10月初 | 滨水城市更新 × 产业园区 |
| 第三期 | 10月底/11月初 | 智能制造 × 钢材新场景（发那科专场） |
| 第四期 | 11月底 | 新能源应用场景（光伏 / 储能 / 新能源汽车用钢） |

合作框架涵盖：两阶段设计（共建期不计营收 → 盈利期按比例提成）、盈利底线与分配红线
（我方无会员制、不以亏损为前提、利润分配向我方倾斜）、痛点应对、收费结构、目标里程碑，
并明确战略目标——成为中钢协在上海及长三角区域统筹的总战略合作伙伴。

## 生成方式

```bash
pip install python-pptx openpyxl

python3 build_excel.py   # 生成 Excel
```

所有文案集中在 `content.py`，两份交付物共享，保证内容一致。
