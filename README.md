# 港大经管学院上海中心 · 外滩产业课堂

面向 **香港大学经管学院上海中心**（接口人：招生官 **潘嘉琰**）的联合策划与合作文本。
核心商业结构：**只收一笔前期联合策划服务费，不碰学费分成。**

## 思路

上海中心不缺品牌和场地，缺的是把「产业转化」做成可持续的高管到场机制。
潘老师负责华东 EMBA，需要的是 8 年以上管理经验的决策者。联合策划方用科企联与产业圈层把人送进外滩中心：

**来的人谈产业，名单共管，会后由招生官一对一。录取权在港大。**

合作成立方式：签一份短协议，支付 **人民币 88,000 元** 前期费用，锁住 90 天策划和首场样板。

## 重新生成

```bash
python3 -m pip install python-pptx python-docx openpyxl
python3 scripts/build_all.py
python3 scripts/verify.py
```

文案集中在 `scripts/content.py`。金额、周期、名单人数改一处即可同步全部文件。

## 口径（不要改偏）

- 对方岗位按 **华东 EMBA 招生官** 写，不写成全学院总代理。
- 产品是 **外滩·产业课堂**，不是宣讲会外包，也不是联合学位。
- 协议性质是 **联合策划服务**，不是招生中介分成。
- 88,000 元覆盖 90 天 + 首场；第二场建议 68,000 元/场，另签才生效。
- 不承诺录取人数，不承诺学费流水。
- 甲方结算主体、乙方有权签署机构在签署页填写，生成稿留空。
