# AIDEN

AIDEN 是一个多任务工作区。`main` 分支存放共享配置；具体应用和文档交付物位于各自的 `cursor/*` 功能分支。

## 显示语言

本仓库默认使用**简体中文**。首次打开项目时，请安装推荐的中文语言包，并在命令面板中选择 **Configure Display Language → 中文(简体)**，然后重启 Cursor。

更多说明见 [AGENTS.md](./AGENTS.md)。

## 本分支：《知行觉醒：让道理长进生命里》书稿

作者署名胡继刚。全书参照周岭《认知觉醒》的写法，用认知科学解释心的机制，并结合王德峰教授所讲的阳明心学（以及海德格尔、马克思与禅宗）探讨方向与意义，主线是"知行合一"。

| 路径 | 内容 |
| --- | --- |
| `output/知行觉醒_书稿全文.md` | **合并后的全书 Markdown**（含自动生成的可点击目录），直接阅读或复制即可 |
| `manuscript/00_扉页与自序.md` | 扉页、题记、目录占位、自序 |
| `manuscript/01_…` — `04_…` | 上篇"见心"：焦虑、心的结构、元认知与良知、真知（篇末附答问） |
| `manuscript/05_…` — `10_…` | 中篇"知行"：知行合一、立志、专注、学习、情绪、逆境（篇末附答问） |
| `manuscript/11_…` — `15_…` | 下篇"安身"：常人、抽象统治、命运、死亡、万物一体（篇末附答问） |
| `manuscript/16_…` | 终篇"日课"：把觉醒落在每一天 |
| `manuscript/17_结语与后记.md` | 结语、后记、作者简介 |
| `manuscript/18_附录.md` | 全书练习一览、两种语言对照表、延伸阅读与参考文献 |
| `scripts/build_book.py` | 合并分章源稿、生成目录并做校验 |

每章结构：经典引语 → 现象 → 认知科学视角 → 心学与哲学视角 → 会通与方法 → 练习 → 本章要点。

修改 `manuscript/` 下的源稿后，重新生成全文并校验（只依赖 Python 3 标准库）：

```bash
python3 scripts/build_book.py --check
```
