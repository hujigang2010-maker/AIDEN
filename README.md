# 复旦科技园创业孵化基地 · 2026 年度材料

基于 2023 年上海市创业孵化示范基地评审 PPT，结合《2026年度工作报告》原稿（覆盖 2025 年工作），整理生成：

1. **Word 年度工作报告**
2. **PPT 工作报告**（结构对标 2023 评审稿，数据更新为 2025/2026）

## 生成方式

```bash
python3 scripts/build_2026_annual_report.py
python3 scripts/build_2026_work_report_ppt.py
```

## 输出文件

- `dist/复旦科技园创业孵化基地2026年度工作报告.docx`
- `dist/复旦科技园创业孵化基地2026年工作报告.pptx`

## 目录说明

- `source/`：原始 PDF、Markdown 整理稿、Word 原稿
- `assets/images/`：自 2023 PPT/PDF 抽取并精选的配图
- `scripts/`：文档生成脚本
