# 王德峰老师 10 月 31 日活动合作方案

基于双方已沟通的两种设想（买断授权 / 渠道抽成），整理为两份 Word：

1. **对外版**：给对方看，定位为联合主办 / 独家运营，按收入来源分成。
2. **内部版**：只给己方看，含谈判锚点、底线、话术、买断测算和合同红线。

## 文件

| 文件 | 用途 |
|---|---|
| `output/王德峰老师10月31日活动_联合运营合作方案_对外版.docx` | 可发给对方 |
| `output/王德峰老师10月31日活动_合作谈判方案_内部版.docx` | 内部留存，请勿外传 |
