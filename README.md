# 能量话语体系对照表

五种「能量」话语的概念对照：物理学能量、生物学能量、心理学能量（意志力/心流）、道家真气、灵性能量。标明可互译处与不可通约处。

## 生成

```bash
python3 scripts/generate_energy_discourse_comparison.py
```

依赖：`openpyxl`、`python-docx`。

## 产物

| 文件 | 说明 |
|------|------|
| `output/能量话语体系对照表.xlsx` | 使用说明、总览对照、互译矩阵、可译/不可通约清单、术语漂移 |
| `output/能量话语体系对照表_说明.docx` | 论述版：判准、例析、写作用法 |

## 互译等级（摘要）

- **强可互译**：物理 ↔ 生物（焦耳/卡路里/ATP）
- **部分可译**：生物 ↔ 心理（疲劳等局部机制）；道家 ↔ 灵性（修炼家族相似）
- **弱类比**：心理 ↔ 道家/灵性（体验相似）；练习效应 ↔ 生理指标
- **不可通约**：物理 ↔ 真气本体/灵性；心理字面能量 ↔ 热力学守恒
