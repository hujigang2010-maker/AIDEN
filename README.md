## 顶层逻辑（One-Pager · 给决策人）

- **客群三圈层**：链主独栋（A 栋）→ 生态联办（B/C 栋）→ 服务+冠松后市场（D/E 栋）
- **差异化壁垒**：① 中心城区 + 独栋；② 户外封闭测试区 1.2 万㎡；③ 静安"一企一策"政策包；④ 冠松集团汽车后市场资源闭环
- **TOP5 链主**：华为车 BU / 百度 Apollo / 小鹏 / 地平线 / Momenta
- **300 家生态库**：5 家中介 + 9 类来源；线索→签约 17% 转化模型
- **9 月发布会**：200 人 · 5+ 家签约 · "iDrive · 静安 10 条"政策包发布
- **四档商业**：甲(链主月费+政策返还) / 乙(生态月费) / 丙(共享月费+服务佣金) / 丁(对赌)
- **三年目标**：入驻率 92% · 链主 ≥ 3 · 生态 ≥ 60 · Y3 EBITDA 转正达 1.25 亿元
