# 复旦链接 · 开放协作平台

由**复旦大学住房政策研究中心**发起。视觉主色 **NYU Violet `#57068C`**（高大上紫，非灰）。

板块模式对齐**教育中心**：公开课程、定制培训、在线学习、活动报名、平台新闻、关于我们。  
活动运营吸收**互动吧**全链路能力（轻松办活动、多票种、海报裂变、验票签到、现场互动、私域沉淀等），对外品牌仍用复旦链接。
