## 核心结论摘要

1. **怎么投**：场地方免租 10–20 年 + 约 5000 万设备装修；主赞助/金牌展席捐赠；政府补贴与科协专项；项目方建设期尽量零资本金。
2. **怎么赚**：租金与运营服务、研学接待、认证服务、孵化持股、外埠模板输出、海外内容变现。
3. **政策怎么用**：教育部研学/教师培训要求 → 客流；科协牵头 → 名称 IP；闲置物业与扶持基金 → 场地与资金封闭。
