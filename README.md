# 上海 / 长三角产业研学考察计划 与 联合主办合作框架

面向「中国钢铁工业协会（总会） × 复旦大学住房政策研究中心 × 上海市科技企业联合会 · 上海市杨浦区科技企业联合会」
的对等（总会对总会 · 商务对商务）合作，生成两份交付物：

- **PPT**：`output/中钢协_上海长三角产业研学考察计划与合作框架.pptx`（16 页）
- **Excel**：`output/中钢协_上海长三角产业研学考察计划_排期表.xlsx`（8 个工作表）

## 内容概要

四期考察，每期两天半（2.5 天），上海为主、长三角延伸，每期含不动产标杆项目（考察项目本身，非开发企业）、
标杆园区、智能制造工厂与科技企业，并配供需闭门撮合：

| 期次 | 时间窗口 | 主题 |
| --- | --- | --- |
| 第一期 | 8月底/9月初 | 不动产标杆 × 城市更新（存量盘活） |
| 第二期 | 9月底/10月初 | 滨水城市更新 × 产业园区 |
| 第三期 | 10月底/11月初 | 智能制造 × 钢材新场景（发那科专场） |
| 第四期 | 11月底 | 新能源应用场景（光伏 / 储能 / 新能源汽车用钢） |

联合主办合作框架（对等）涵盖：

- 合作层级与双方主体（总会对总会 · 对等）；
- 针对对方「各收各钱、自负盈亏」方案的指导性立场（红线，不接受各收各钱）；
- 我方核心商业资产界定（品牌 / 渠道 / 智力资产）；
- 三种商业对价方案（A 品牌授权买断 / B 增量收益与会员转化分成 / C 产业撮合 FA 居间）；
- 分成落位（明确 · 可执行 · 可追溯：品牌与资源服务费、前端分成、人头费、会员转化分佣、居间佣金）；
- 核心保护条款（名单共管、社群独立权、品牌使用边界、分佣确认与追溯）；
- 对外沟通话术（商业升维版 / 战略高位切入版）与我方底线、对方反应分级应对；
- 战略目标——成为中国钢铁工业协会在上海及长三角区域统筹的总战略合作伙伴。

## 生成方式

```bash
pip install python-pptx openpyxl
python3 build_ppt.py     # 生成 PPT
python3 build_excel.py   # 生成 Excel
```

所有文案集中在 `content.py`，两份交付物共享，保证内容一致。
