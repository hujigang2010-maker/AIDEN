## 核心结论

- **战略定位**：做「进入山姆的能力」，而非单纯卖货
- **首选路径**：自有品牌 3 个月区域试点 → 验证后转 Member's Mark 贴牌
- **首批试点**：青岛虾米（纪要点名）+ 黑猪肉马蹄丸（差异化替代）
- **关键约束**：差异化替代 existing SKU，不做全新品类
