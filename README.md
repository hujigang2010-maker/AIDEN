# 复兴岛·全球创客岛收官答卷大会（V3.3）

**主呈现：PPT + Excel**  
Slogan：**锚定全球创客岛，答卷量子城市**  
主题：**创客复兴·智汇杨浦**

## V3.3 升级要点

1. **四层结构**：主论坛 + 分论坛 + 体验/游戏层 + 黑客松  
2. **敦煌意向**：壁画 IP 文旅科技落户样本（约 2000㎡ / 净高 9–11m；950 万数据标注待核实）  
3. **冷启动原则**：智库/顾问定位、一事一议、先调研后成交、服务 9/15 节点  
4. **杨浦企业互动**：优刻得、智谱、苏度、卓益得等同台  
5. **东亚+东南亚领事**：驻沪总领事姓名入册，暂按全部出席准备（约 11 国）  
6. **出海领事专报**：六大行业方向 × 当地支持诉求 × 国别匹配（单独 PPT + 总方案内嵌）
