## 生成

```bash
python3 -m pip install python-docx
python3 scripts/build_re_ops_qa_docx.py
python3 scripts/verify_re_ops_qa_docx.py
```

输出文件：`deliverables/房地产开发运营一线答疑.docx`

## 说明

文中税率、预征率以全国规则为骨架，具体城市细则会有差异；数字多为教学级示意。不构成投资建议或税务鉴证。
