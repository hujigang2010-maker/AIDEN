# 复旦杨浦科创生态共建计划 · 宣传交付物

复旦大学住房政策研究中心（秘书长）与杨浦区科技企业联合会（会长）联合发起，面向网上传播与公众号「复联会」的活动宣传材料。

## 核心定位

**一场活动，三重价值：促招商｜强链条｜聚人群**

以复旦智力对接杨浦产业，为科技企业提供空间、资本、技术、客户的一站式连接平台。

## 内容结构

1. **为什么是现在** — 连接密度决定区域高度
2. **三大目标** — 促进招商 / 促进生态链达成 / 促进高端客户群形成
3. **活动怎么做** — 认识 → 对话 → 匹配 → 跟进
4. **谁应该来** — 科技企业、投资、高校、产业链、园区、高端客户
5. **活动信息** — 时间地点待填，公众号「复联会」承接传播
