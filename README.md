# AIDEN

## 本分支交付物

《**反者道之动**》详细内容大纲——结合《道德经》「反者道之动，弱者道之用」与纳西姆·塔勒布《反脆弱》的思路，参照《反脆弱》「分卷、多章、短小精悍」的体例组织全书。

### 文件

| 路径 | 说明 |
| --- | --- |
| `outline/反者道之动_详细大纲.md` | Markdown 详细大纲（可直接阅读/迭代） |
| `dist/反者道之动_详细内容大纲.docx` | Word 版大纲 |
| `scripts/build_outline_docx.py` | 由大纲内容生成 DOCX |

### 生成 Word

```bash
pip install python-docx
python3 scripts/build_outline_docx.py
```

### 结构速览

- **七卷三十六章** + 前言、后记、三则附录
- 第一至三卷：立概念、诊现代、换世界观（道动于反 → 怕反 → 备势）
- 第四至六卷：弱用、非线性、日损（建设与方法）
- 第七卷：皮肤在局与知止（伦理收束）
