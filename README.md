# 复旦终身教育学院 × 杨浦区科技企业联合会

2026—2027 年战略合作洽谈稿。内容来自 2026 年 11 月 6 日、11 月 10 日的洽谈纪要，以及据此整理的实施建议。课程名称、价格、证书和收益分成均未获学院批准。

## 交付文件

生成后位于 `output/`：

- `复旦终身教育学院与杨浦科联合作框架方案.docx`：可提交讨论的完整文本，含四个附件。
- `复旦终身教育学院与杨浦科联合作洽谈.pptx`：当面汇报用，25 页。
- `复旦终身教育学院与杨浦科联合作工作表.xlsx`：可筛选台账。金色单元格是假设，修改后由公式重算。`08_内部跟进` 不要随外发材料提交。

## 重新生成

```bash
python3 scripts/build_all.py
```

依赖：`python-docx`、`python-pptx`、`openpyxl`。
