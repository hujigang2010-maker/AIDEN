# 东方枢纽 × 复旦大学 × 上海市科技企业联合会 —— 下半年三方合作计划

本仓库根据两份会议纪要，生成面向东方枢纽 133 万方招商项目的**下半年 12 场活动合作计划**，
包含活动规划、时间建议、主题内容、详细策划案、合理报价与招商引资价值分析。

> 定位：以**上海市级资源 + 浦东新区资源**联动为核心（市/区商务委与投资促进部门共同背书），
> 复旦大学提供学术与科技智库背书，上海市科技企业联合会负责科技企业邀约与执行。
> 视觉风格：商务紫（PPT + Excel 统一配色）。

## 交付物（PPT + 表格）

| 文件 | 说明 | 用途 |

| `东方枢纽三方合作计划_汇报PPT.pptx` | 17 页汇报演示（16:9） | 对外汇报 / 客户呈送 |
| `东方枢纽三方合作计划_明细表.xlsx` | 5 张明细表 | 内部审阅 / 落地执行 |

### PPT 结构（18 页）
封面 → 目录 → 三方定位 → 政府资源背书矩阵（市级+浦东新区）→ 战略目标与原则 →
六大产业 → 12 场总览表 → 详细策划案（6 页·每页 2 场）→ 报价体系 →
招商价值·转化漏斗 → 招商价值·去化测算与价值支柱 → 执行机制 → 下一步。

### Excel 工作表（5 张）
1. `1-12场活动总览` —— 时间 / 主题 / 板块 / 规模 / 场地 / 档位 / 报价
2. `2-逐场详细策划` —— 内容建议 / 拟邀嘉宾 / 招商衔接价值 / 报价
3. `3-报价体系` —— 三档模型构成明细 + 全年预算汇总
4. `4-招商引资价值分析` —— 转化漏斗 / 去化测算 / 六大价值支柱 / 投入产出
5. `5-合作资源与执行机制` —— 三方定位 / 政府资源背书矩阵 / OA 流程 / 指定供应商

## 核心结论
- **12 场活动**：两旗舰（200 人）+ 六市区专场（80 人）+ 四小而美闭门（30 人）。
- **合理报价（已下调）**：全年合计约 **111.2 万元**（A 档 3.6 / B 档 8.8 / C 档 22 万元·场），较初版 288 万元下调约 **61%**，上不封顶原则下的合理基准价。
- **招商价值**：累计触达约 1,000 家企业决策层，中性情景可带动约 **6.65 万方**去化（≈133 万方的 5%），
  并引入 5–8 个政府飞地办事处。

> 报价与招商测算均为**初步建议/测算假设**，用于展示价值逻辑；最终以邀约名单、规模确认及东方枢纽指定策划供应商合同为准。
