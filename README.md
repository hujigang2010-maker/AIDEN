## V1.1 修订要点

1. **人名更正**：胡继刚、陈胜、陈红苗。
2. **删除不切实际前提**：不再写「免租 10–20 年」「场地方无偿出资约 5000 万」「项目方建设期零资本金」等；改为租金阶梯/装修共担与启动金闭环。
3. **删减展示性堆砌**：去掉具身概念层、名人直播等不可控话术；内容以可签约展位与可授权案例为主。
4. **话术务实化**：政策按保守到账入预算；收入不把境外变现、快速外埠复制算作一期必达。
