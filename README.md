# 上海市云计算创新基地 · 招商合作版宣传册（PPT）

一份**图文结合、商务大气**的 16:9 演示型宣传册，按「招商转化型」逻辑重排：
**价值 → 证明 → 资源 → 入口**，可直接用于路演、招商、合作洽谈与领导汇报。

## 成品文件（`dist/`）

| 文件 | 说明 |
| --- | --- |
| `上海云基地-招商合作版宣传册.pptx` | 主交付物，11 页，可在 PowerPoint / WPS / Keynote 中编辑 |
| `上海云基地-招商合作版宣传册.pdf` | 同内容 PDF，便于直接发送与打印 |

> PPT 默认使用「微软雅黑」中文字体；在 Windows / Mac 上打开即为最佳效果。

## 内容结构（11 页）

1. **封面** —— 主标题 + 一句话钩子「中国云计算与 AI 产业创新策源地」
2. **一句话价值** —— 「把『技术公司』变成『产业公司』的地方」
3. **为什么选我们** —— 政策 / 资本 / 产业 / 场景 四大核心优势
4. **三位一体模式** —— 基金（钱）→ 基地（空间）→ 服务（能力）
5. **产业实力** —— 近 200 家企业、60 亿+ 产值、67 家获投等硬数字
6. **明星企业** —— 已上市 / Pre-IPO / 高成长 / 细分龙头 / 早期高潜 分层展示
7. **产业方向** —— 云计算·云原生 / 大数据·AI / 边缘计算 / SaaS·智能终端 四大赛道
8. **你将获得** —— 客户视角的六项服务（投融资、场景、客户、政策、国际化、人才）
9. **合作方式** —— 转化页：欢迎入驻、投资、生态共建，含联系 CTA
10. **发展历程** —— 2010→2025 横向时间轴
11. **封底** —— 运营主体、地址、口号

## 设计

- 配色：深海军蓝（主）+ 科技青（强调）+ 鎏金（高端点缀）
- 所有中文文字由 PPT 文本框渲染，**清晰、可编辑**；图片仅作背景与配图
- 配图为多张商务科技风视觉素材（封面外滩天际线、生态网络、握手合作等），见 `assets/`

## 重新生成 / 二次编辑

```bash
pip install python-pptx Pillow
python3 build_deck.py        # 输出到 dist/
```

- 修改文案：直接编辑 `build_deck.py` 中对应 `slide_*()` 函数内的文本，或在 PowerPoint 中直接改。
- 替换配图：覆盖 `assets/` 下同名 PNG 后重新运行脚本即可。
- 导出 PDF（可选，需本机安装 LibreOffice）：

```bash
soffice --headless --convert-to pdf dist/上海云基地-招商合作版宣传册.pptx --outdir dist
```
