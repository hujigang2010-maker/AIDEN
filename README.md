# 2026 年具身智能机器人白皮书

以**复旦大学住房政策研究中心**名义撰写的智库白皮书，梳理 2026 年世界人工智能大会（WAIC）及同期国内外展会报道，分析具身智能机器人从“展台炫技”转向“真实作业”的产业转折，并从住房、社区与适老化视角展望 2030 年。

## 生成文档

```bash
python3 scripts/build_whitepaper.py
```

输出文件：

- `dist/复旦大学住房政策研究中心_2026年具身智能机器人白皮书.docx`

可选校验：

```bash
python3 scripts/verify_whitepaper.py
```

## 资料范围

白皮书综合了 2026 年 1 月至 8 月公开报道，重点覆盖：

- 2026 世界人工智能大会（7 月 17–20 日，上海）
- CES 2026、汉诺威工业博览会、北京亦庄人形机器人半程马拉松
- 即将开幕的 2026 世界机器人大会，以及工博会、高交会预告
- 居家、社区、康养场景与住房政策交叉议题
