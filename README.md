## 四、内容主线（贯穿三份文件）

- **报告定位**：上海首份面向全域商办楼宇与产业园区的供需双侧 · 企业迁徙 · 产业流动 · 资产运营决策报告
- **核心突破**：核心区 → 全域 · 写字楼 → 全类型 · 租金空置 → 双侧 · 静态 → 动态 · 描述 → 应用
- **数据底座**：六大基础数据库（楼宇/园区、租金/空置、企业入驻、企业迁徙、产业标签、政策配套）
- **指标模型**：五大指数（市场景气、楼宇/园区竞争力、企业需求热度、产业集聚度、供需匹配度）
- **采集路径**：四阶段（中心城区 → 浦东 → 重点产业区 → 16 区全域）
- **联合分工**：易居研究院 / 复旦大学住房政策研究中心 / 数据技术与 AI 采集方
- **商业化矩阵**：月度简报 + 季度深度 + 年度白皮书 + 区域专项 + 楼宇/园区诊断 + 企业选址服务

> 仅供联合课题组内部研讨使用（讨论稿）。
