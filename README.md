# 潮起潮落 TIDELINE × 北外滩尚9·一滴水

青年文化消费场景创新暨长期战略合作综合方案。本分支交付两份可直接使用的文件：

- `deliverables/潮起潮落TIDELINE-北外滩尚9一滴水-综合合作方案.pptx`：向一滴水经营者汇报的 16:9 方案。重点是商业价值、长期业务和收入模式。
- `deliverables/潮起潮落TIDELINE-北外滩尚9一滴水-方案附表.xlsx`：可筛选的明细表，以及一滴水本次收益的空白测算。

## 口径

客流、曝光、合作资源和经营收益都是计划目标或合作设想，不是已经兑现的结果。赞助金额是原稿建议档位。北京惠迪的案例规模来自公司自述。面积 1,780㎡ 是需求加总，不是场地须提供的净面积。活动日期、主办主体和审批手续仍待确认。

测算表里只有黄色单元格需要填写。绿色单元格是公式。未来订单和机会成本单独列示，不计入本次直接经营结果。

python3 scripts/build_all.py
