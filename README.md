# 同浦汇业务承接策划案

给**上海同浦汇科技有限公司**的承接方案：由杨浦区科技企业服务中心承接创智汇 **30 场活动全案执行** 与 **科技企业服务中心筹备**。

依据 2026-08-31 赛道调整交流：园区主叙事由原 AI+IP 转为 **智能建造 × 建筑产业出海**，政策包装为现代服务业 + 新一代信息技术。同浦汇保留园区招服入口与客户关系；服中心承接可核验交付。

## 生成

```bash
python3 scripts/build_all.py
```

也可单独运行：

```bash
python3 scripts/build_proposal_pptx.py
python3 scripts/build_proposal_docx.py
python3 scripts/build_proposal_xlsx.py
```

## 交付物

| 文件 | 用途 |
| --- | --- |
| `output/同浦汇_30场活动与科技企业服务中心筹备_业务承接策划案.pptx` | 16 页会面汇报 |
| `output/同浦汇_30场活动与科技企业服务中心筹备_业务承接策划案.docx` | 可打印全文 |
| `output/同浦汇_30场活动与科技企业服务中心筹备_执行台账.xlsx` | 排期、90 天、付款、确认项 |

口径数据在 `scripts/proposal_data.py`，三份文件共用，避免各改各的。
