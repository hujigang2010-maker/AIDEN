# 星火社区 OPC 申请材料（修订稿）

正式提交只上传两份：

- `output/星火社区_02_个人简介.pdf`（或 `.docx`）
- `output/星火社区_03_业务计划书.pdf`（或 `.docx`）

`01` 填写说明和 `04` 字段粘贴稿留给自己填表，不要整份上传。不再生成「00全套材料」。

## 产品主线

四类智能体：产业研究、政策研究、企业画像与招商匹配、城市更新案例库。  
**首期只做城市更新案例库 RAG 原型（正在搭建）**，其余为后续拓展。

## 申请表最终勾选

| 字段 | 填写 |
| --- | --- |
| 赛道 | AI智能体开发 |
| 是否已注册 | 否 |
| 盈利模式 | 技术开发、服务收费 |
| 预计第一年营收 | 50万以下（预测，不是限额经营） |
| 团队 | 1人 |

## 生成

```bash
python3 scripts/generate_all.py
python3 scripts/validate_materials.py
```

口径源：`scripts/content.py`。仓库不保存证件号码和详细住址，填系统时按原件录入。
