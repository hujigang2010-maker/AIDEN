# 上海学区板块差异化选房 / 融合总表

基于「避开新上海人集中新区、选择人口空心化老板块」的选房纪要，对全市主要板块做学区竞争与策略契合度标记，并与《上海板块学区融合分析》双源整合。

## 生成方式

```bash
python3 scripts/generate_shanghai_school_district_map.py
python3 scripts/generate_shanghai_school_district_fusion.py
```

## 交付物

| 文件 | 说明 |
|------|------|
| `output/上海板块学区融合总表.xlsx` | **主交付**：双源融合商务总表（融合总表 / 入选清单 / 十六区 / 图例 / 校准说明） |
| `output/上海学区板块差异化选房地图.xlsx` | 纪要策略地图（五工作表） |
| `output/上海学区板块差异化选房地图.html` | 可筛选交互页 |

## 融合总表要点

- 底座：融合分析表的街道、对口校、五维评分（约 100 板块）
- 校准：差异化地图的纪要标记、入选结论、政策提示
- 视觉：深蓝商务配色 + 等级色标 + 冻结窗格/筛选

> 对口学校与入户年限以各区教育局当年文件为准；本表为决策辅助，非官方承诺。
