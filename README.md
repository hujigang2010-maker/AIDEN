# 复旦科技园创业孵化基地 · 2026 年度工作报告 PPT

面向领导汇报的年度工作报告演示文稿。内容依据《复旦科技园创业孵化基地2026年度工作报告》，版式与视觉参考 2023 年上海市创业孵化示范基地（复旦科技园）工作报告，Logo 与部分现场照片自原 PDF 提取。

## 交付物

- `dist/复旦科技园创业孵化基地_2026年度工作报告.pptx`（24 页，16:9）

## 重新生成

```bash
python3 scripts/build_2026_annual_report_ppt.py
```

依赖：`python-pptx`、`Pillow`（素材处理可选 `pymupdf`）。

## 结构概览

1. 封面 / 目录 / 导语  
2. 载体基本情况（定位、空间、荣誉、产业）  
3. 2025 年工作成效（指标总览、孵化、就业、政策金融、服务、概念验证、活动、赛事、宣传）  
4. 特色与亮点（品牌、成果转化体系与波达医疗案例、区域协同与国际化）  
5. 综合效益、阶段评价、下一步方向与封底  

## 素材来源

- `source_docs/`：原始年度报告 DOCX 与 2023 评审 PDF  
- `assets/`：自 PDF 提取的 FDUSP Logo、园区建筑与活动照片
