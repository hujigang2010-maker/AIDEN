# 青岛红枫路交通事故：伤情、伤残与处理

`main` 无应用。本分支根据 2026-08-15 至 08-19 得到大脑通话/转写，以及用户提供的齐鲁医院云影像检查列表，整理内部处理材料。已归档《沟通记录合集-2026年8月15日至18日.md》并另写口径对照：17 份里 1、3–15、17 是同一起事故，记录 16 是远洋工伤另一案。3D 复原视频留作待用，本次不重做。

## 结论（先看这里）

- **谁受伤**：64 岁男性胡某（云影像脱敏为胡**）。三份 CT 都是他的。
- **伤了什么**：右胫骨远端骨折、腓骨近端骨折、右踝关节半脱位、距骨内缘及外踝撕脱骨折。2026-08-15 已在山东大学齐鲁医院（青岛）手足与显微重建外科做内外固定。
- **什么不是这次伤的**：右足组成骨完整；跟骨骨刺、退变不要写成跟骨粉碎骨折。
- **谁伤残**：**现在谁都还没有伤残等级。** 云影像是影像诊断，不是伤残鉴定书。评残须治疗终结后由司法鉴定机构做。
- **医院怎么选**：不转其他三甲。首选能回齐鲁就回。齐鲁收不回且美团险确认人民医院可赔，才暂留二甲。今天先结束没有住院号的空窗。
- **本周**：人已到市北区人民医院，齐鲁出院未办。医保能报 ≠ 美团险能报。术后两天不是康复期。
- **过程补充（8/19 确认）**：地点为抚顺路批发市场、抚顺路与哈尔滨路交叉口。认定书尚未出具。人民医院可以赔、比例待定。驾驶人有驾驶资格证书。乔刘记商贸/刘孝春雇佣无合同，工伤排除，已垫付 3 万须写收据。
- **现阶段不谈总账**：先固定监控和用工证据、书面认定、保险与医院资格、核清费用；病情稳定并鉴定后再算交通事故赔偿和雇员受害/车主过错。工伤不走。详见 `deliverables/现阶段办理顺序_紧急程度.md`。

## 网页总览（思维树）

```bash
cd web
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`。三个页签：

1. **思维树**：点树枝看「做什么 / 怎么推进 / 会得到什么」
