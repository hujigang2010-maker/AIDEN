## 关键里程碑（M1 ~ M8）

| 节点 | 时间 | 关键交付 |
|---|---|---|
| **M1** 启动 | T+1 月底 | 4 人核心团队到位 |
| **M2** 定位 | T+3 月底 | 产业定位 + 政策包 v1.0 |

| **M8** 复盘 | T+12 月底 | 一周年复盘 + 二期定调 |

## 文档使用与说明

1. 文档面向**冠松汽车董事会、招商团队、政府对接、客户/中介**等多方使用，不同角色可按 Phase 章节抽取所需。
2. 所有数字（租金、面积、入驻率、政策金额等）为**方案占位/测算值**，正式商务谈判与对外披露须以官方批复 + 测绘出图 + 法务定稿为准。
3. 文档版本 v1.0，建议节奏：**月度滚动 + 季度复盘 + 年度迭代**。
4. 涉及客户/政府名称的部分仅用于内部攻坚目标设定，外发材料须删除或脱敏。
