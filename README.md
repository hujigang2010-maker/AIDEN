# 东方枢纽 × 复旦大学 × 上海市科技企业联合会 —— 下半年单场活动立项计划

面向东方枢纽集团 **A 片区整体办公项目**（约 30 万㎡，非“133 万方”）的下半年合作方案。
**每场活动单独成案、单独报价、单独走 OA 立项。**

## 排期原则
- **7 月不排场**（预留流程时间）
- **8–12 月每月 2 场**，共 **10 场**
- 围绕东方枢纽既定 **六大产业板块**（高端服务业、国际贸易、民用航空含供应链、生物医药药械贸易、工业互联网含数据中心、绿色能源）

## 交付物

| 文件 | 说明 |
| --- | --- |
| `东方枢纽三方合作计划_汇报PPT.pptx` | 汇报演示（含 10 页单场立项页） |
| `东方枢纽三方合作计划_明细表.xlsx` | 总览 + 月度排期 + 报价 + 招商标的 + **10 张单场 OA 立项表** |

### Excel 工作表
1. `1-10场总览`
2. `2-月度排期`
3. `3-报价体系`
4. `4-招商标的与资源`
5. `立项01-8 月` … `立项10-12 月` —— **每场一张，可直接附 OA**

### 报价（初步）
- A 档小而美闭门（≤30 人）：**3.6 万元/场**
- B 档市区专场（≤80 人）：**8.8 万元/场**
- 全年 10 场合计约 **62.0 万元**（单场立项累加）

## 单场独立 PPT（10 份）
目录：`单场立项PPT/`  
每场 5 页：封面 → OA 要件 → 内容策划 → 预算明细 → 执行下一步。

```bash
python build_single_pptx.py   # 生成 10 份单场 PPT
```

## 复现
```bash
pip install python-pptx openpyxl
python build_xlsx.py
python build_pptx.py
python build_single_pptx.py
```
