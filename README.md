# 杨浦五角场 5km 商办竞品地图

基于**高德地图 JS API** 的商办竞品调研可视化网页 — 顶部总览看板、左侧交互地图（支持**卫星图**）、右侧【项目概览】/【企业明细】双 Tab，地图与表格全双向联动。可一键调用 **天眼查 / 企查查** API 补充企业电话与工商信息。

> **基准点：** 上海市五角场创新创业学院（杨浦区国权路18号）
> **半径：** 5 km · 分层：1 km / 1–2 km / 2–3 km / 3–5 km
> **数据：** 39 个项目 · **171** 家代表企业

## 📞 给企业表格补充电话（两种方式）

### 方式 A：手动录入（无需任何 Key）

打开【企业明细】Tab,点击表格 `📞 电话` 列任意单元格 → 弹出对话框 → 录入号码 → 保存。
数据存放在浏览器 **localStorage**,刷新页面后仍在,且会被 CSV 一并导出。

### 方式 B：调用 天眼查 / 企查查 API 批量补全（推荐做调研时）

为什么要本地代理？浏览器**无法**直接调天眼查/企查查（CORS + Key 泄漏风险）,因此本项目自带零依赖代理：

#### 1. 申请 API（任选其一）

| 平台 | 申请地址 |
| --- | --- |
| **天眼查开放平台**（推荐,接口最简洁） | <https://open.tianyancha.com> |
| 企查查开放平台 | <https://openapi.qcc.com> |

#### 2. 启动代理

```bash
export TYC_TOKEN="你申请到的 Bearer Token"   # 或 企查查的 QCC_KEY/QCC_SECRET
node server/qcc-proxy.js
# → 监听 http://localhost:3001
```

> 详见 [`server/README.md`](./server/README.md)。代理是**零依赖**的纯 Node.js,不需要 `npm install`。

#### 3. 在网页里配置一次

页面右上角【**⚙ API 配置**】 → 代理地址填 `http://localhost:3001` → 保存（会显示连通状态）。

#### 4. 一键同步

切到【企业明细】Tab → 点 **🔄 同步电话** → 逐条调用代理,补全可见行的电话 + 法人 + 注册资本 + 统一信用代码。
（默认每条间隔 800ms,避免触发对方限流。）

## ⏳ 剩余租期是怎么算的？

每个企业记录包含：

```js
{
  leaseStart: '2023-06-01',  // 租约开始
  leaseTerm:  5              // 期限（年）
}
```

页面在加载时算出 `leaseEnd = leaseStart + leaseTerm`,然后用 `(end - now)` 推出 **剩余月数**：

| 状态 | 触发条件 | 颜色 |
| --- | --- | --- |
| 在租 | 剩余 > 6 月 | 🟢 绿 |
| 即将到期 | 0 < 剩余 ≤ 6 月 | 🟠 橙 |
| 已到期 | 剩余 ≤ 0 | 🔴 红 |
| 未知 | 缺少租约字段 | 灰 — |

字段缺失时按 `dealYear` 自动补默认（关键字哈希到月份,3 / 5 年期）。在 CSV 导出中包含完整 `租约开始 / 到期日期 / 剩余(月)`。

## 关于"项目里所有已注册公司"的覆盖度

要真正穷举每个园区/楼宇内的**所有**注册企业,只能调用付费的天眼查 / 企查查 API（按地址反查）：
- **天眼查 高级版 API**：`/services/open/ic/locationSearch/2.0?province=...&city=...&address=...`
- **企查查 SearchByLocation**

本项目已内置 171 家**代表性 + 锚定**企业（涵盖 创智天地、长阳创谷、上海湾谷、复旦科技园、INNO 等核心园区）。要继续扩展：

1. 在 `data/extra-tenants.js` 中按 `parkId` 追加企业（无需改 `competitors.js`,启动时自动合并）
2. 或在代理的 `qcc-proxy.js` 中加 `/api/by-address?address=XXX` 路由,调用上述地址反查接口
3. 再用同步按钮把返回的企业批量塞入表格

## 数据结构

`data/competitors.js`：

```js
{
  id: 'A01',
  name: '合生国际广场',
  category: '商办写字楼',
  address: '上海市杨浦区淞沪路18号',
  lng: 121.5076, lat: 31.2984,
  drive, transit, developer, area, year, subs, tags, note,

  propertyFee: 28,                  // 物业费（元/㎡/月）
  nature: '民营 · 甲级写字楼',       // 性质说明

  tenants: [
    {
      name: '招商银行 杨浦支行',
      industry: '金融 / 银行',
      area: 3200,                    // 办公体量（㎡）
      rent: 5.8,                     // 成交租金（元/㎡/天）
      rentFreeMonths: 3,             // 免租期（月）
      leaseStart: '2023-04-15',      // 租约开始
      leaseTerm: 5,                  // 期限（年）→ 用于剩余租期
      dealYear: 2023,                // 成交年份
      phone: null                    // 留空,可手动 / API 补充
    },
    // ...
  ]
}
```

`data/extra-tenants.js`：

```js
window.EXTRA_TENANTS = {
  'C01': [ /* 长阳创谷 的扩充企业 */ ],
  'C02': [ /* 上海湾谷 的扩充企业 */ ]
};
```

启动时 `app.js` 自动把 `EXTRA_TENANTS[parkId]` 合并到对应 `park.tenants` 末尾。

## 已知限制

- 公开发布数据是基于公开资料整理的代表性样本;以实际调研数据为准时请按结构替换
- 部分"合并条目"（如 `长阳创谷孵化器入驻团队合计`）代表园区内同类长尾租户的聚合
- 驾车/公交时长字段为估算;如需实时计算可调用 `AMap.Driving` / `AMap.Transfer`
- 工商信息（电话/法人/注册资本等）调用是付费 API,商业使用请取得天眼查/企查查授权
