## 二、核心商业逻辑（一页纸）

**「基金 + 基地 + 活动」三轮驱动 × 「轻资产 + 强运营」合资公司模式。**

| 维度 | 输入 (胡教授团队带来的核心资源) | 输出 (合资公司向森马交付的价值) | 收入对应 |
|------|------|------|------|
| 国际化 | 北欧创新国际会客厅（首站平移至 4# 楼潮玩艺术中心 / 直播中心） | 海外 IP 与技术进入中国的首站、潮玩国际策源点 | 月费 + 挂牌奖项激励 |
| 品牌势能 | 福布斯系列奖项 / 中国百货商业协会 / 中国动漫集团 牌照 | "AI 潮玩产业基地"等两大产业牌照落地 | 专项奖项激励（按挂牌数） |
| 持续运营 | 科技开放麦、全国潮玩设计大赛 | 园区级 IP 活动 → 租赁粘性 + 政府补贴/赞助 | 单场活动执行利润分成 |
| 招商引擎 | 仲量联行爬楼大数据（已购买，2.6 万元） | 头部科技 / 潮玩企业精准画像与转化 | 招商佣金（年租金 1–2.5 个月） |
| 资本招商 | 追觅科技基金 + AI 腾讯引进 | "返投落地"模式锁定 40% 小型 + 20% 中型潮玩企业 | 返投奖励 + 股权分红 |

## 三、收入结构总览（与森马对话锚点）

1. **保底月费 (Retainer)** — 覆盖团队核心支出，确保胡教授稳定投入。
2. **专项奖项激励** — 福布斯 / 行业牌照 / 科技小镇相关挂牌，按数量奖励。
3. **活动运营收入** — 科技开放麦 + 潮玩大赛 + 北欧会客厅外事，单场结算。
4. **招商佣金 (Commission)** — 实际成交年租金的 1–2.5 个月，分档计提。
5. **股权分红** — 合资公司增值服务（直播中心 / 选品中心 / 共享设计中心）按持股比例。

详细测算见 `02_测算模型/合作收益测算模型.xlsx`。

## 四、与森马洽谈的「四个必须确认」

1. **合资公司架构**：注册资本、股比、董事席位、首席战略运营官（CSO）由胡教授担任。
2. **月费金额**：建议 30–50 万元/月（覆盖 5–8 人核心团队 + 顾问费），见测算模型 Sheet1。
3. **佣金阶梯**：≤2,000㎡ 计 1 个月、2,001–5,000㎡ 计 1.5 个月、>5,000㎡ 计 2.5 个月。
4. **基金返投绑定**：追觅基金返投比例（建议 1:1.5）、AI 腾讯导入企业的封闭期与佣金归属。
