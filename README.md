# CGC · 国家会客厅 —— 三方战略合作策划案

总领事俱乐部（CGC）× 长三角：城市开放与企业出海合作计划。本仓库用脚本一键生成可直接
对外使用的 **PPT 策划案**、**Excel 收费与测算表格** 以及 **Markdown 文稿**。

## 合作对象

- **总领事俱乐部（CGC, Shanghai Consul Generals Club）**：2023 年落户上海·金茂大厦 86 层，
  驻沪 70 多国总领事支持、领团团长（斐济驻沪总领事陈玉茹博士）主导的非正式组织；
  领区覆盖上海、江苏、浙江、安徽。
- 运营承办方：**郡邦（上海）文化交流发展有限公司**（公众号 `gh_79ebe44ac3d2`）。

## 合作三方

- **复旦大学政党建设研究中心**（或相关政策研究中心）—— 学术与政策背书
- **上海市杨浦区科技企业联合会** —— 企业资源与产业落地
- **郡邦 / 总领事俱乐部（CGC）** —— 领事资源与活动落地

## 交付物（`output/`）

| 文件 | 说明 |
| --- | --- |
| `CGC-国家会客厅-三方战略合作策划案.pptx` | PPT 策划案（含 8 张数据表页） |
| `CGC-国家会客厅-收费与测算表格.xlsx` | 9 个工作表的收费、分润、路线图与收入测算 |
| `CGC-国家会客厅-策划案.md` | 便于阅读与二次编辑的 Markdown 文稿 |

## 核心内容

1. **合作对象 CGC** —— 组织、选址、领导、运营与既有品牌资产。
2. **既有品牌升级变现** —— 午餐会、文化慈善之夜、企业家对话会、CG Band、公众号。
3. **长三角领区** —— 沪苏浙皖，把领事资源转化为招商抓手。
4. **价值闭环** —— 活动获客 → 会籍沉淀 → 出海·招商 → 政企复购。
5. **六大产品线** —— 国家会客厅、领事专题活动、出海深度游、企业出海对接、会员体系、文化传播·智库·培训。
6. **国家会客厅（旗舰）** —— “某某国家会客厅”空间命名 + 企业会籍 + 园区/政府招商。
7. **收费体系与测算** —— 八张表给出现有品牌升级、活动、会客厅、出海、会员定价，
   三方分润、12 个月路线图与第一年收入测算。
8. **合规与风险** —— 外事纪律、内容中立、财务与品牌风险管理。

> 所有金额均为人民币，用于商业测算示意，最终以三方框架协议及单项目合同为准。

## 重新生成

依赖：`python-pptx`、`openpyxl`。

```bash
pip install python-pptx openpyxl

python3 scripts/generate_ppt.py     # 生成 PPT
python3 scripts/generate_tables.py  # 生成 Excel
python3 scripts/generate_md.py      # 生成 Markdown
```

全部结构化内容集中在 `scripts/content.py`，修改后重新运行即可同步更新三份交付物。
