# 上海学区板块差异化选房 / 融合总表

基于「避开新上海人集中新区、选择人口空心化老板块」的选房纪要，对全市主要板块做学区竞争与策略契合度标记，并与《上海板块学区融合分析》双源整合。

## 生成方式

```bash
python3 scripts/generate_shanghai_school_district_map.py
python3 scripts/generate_shanghai_school_district_fusion.py
python3 scripts/enrich_shanghai_education_policies.py
```

## 交付物

| 文件 | 说明 |
|------|------|
| `output/上海板块学区融合总表.xlsx` | **主交付**：融合总表 + 升学政策（幼升小/小升初/中考）+ 入选清单等 |
| `output/上海学区板块差异化选房地图.xlsx` | 纪要策略地图 |
| `output/上海学区板块差异化选房地图.html` | 可筛选交互页 |

## 政策页（已写入融合总表）

1. **升学政策总览** — 三阶段对照与购房检查清单  
2. **幼升小政策** — 人户一致、公民办二选一、验证统筹、时间线  
3. **小升初政策** — 对口/派位、十六区方式对照、回户籍  
4. **中考政策** — 750 分构成、自招/名额分配/统一招生批次  

> 政策口径依据市教委实施意见与考试院公开规则；具体日期、对口、年限以各区当年文件为准。
