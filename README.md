# 赴宁波港及宁波经济技术开发区考察交流策划案

面向 **宁波经济技术开发区投资促进局** 的正式策划案，由以下双方联合组织提交：

- 复旦大学住房政策研究中心
- 上海市杨浦区科技企业联合会

考察人员为复旦大学校友及上海市科技企业家，拟于 **2026年8–10月择一两日** 赴宁波港及当地特色企业开展参访与投促交流，围绕招商引资、科技孵化、产业导入、PE/VC 与 CVC 投资等事项建立长效合作。

## 交付物

| 文件 | 说明 |
| --- | --- |
| `output/赴宁波港及宁波经济技术开发区考察交流策划案.docx` | 正式 Word 策划案（可直接发送贵局） |
| `output/赴宁波港及宁波经济技术开发区考察交流策划案.pptx` | 汇报版 PPT（14 页） |
| `output/赴宁波港及宁波经济技术开发区考察交流策划案.md` | Markdown 便于阅读与二次编辑 |

## 内容结构

1. 项目背景与目的  
2. 组织方与接待单位分工  
3. 考察人员构成（建议 15–30 人）  
4. 四大合作方向：招商引资与产业导入 / 科技孵化 / 宁波港与临港产业 / PE·VC·CVC 投洽  
5. 时间安排：一日精华行 / 两日深度行（推荐）  
6. 建议行程与参访点位  
7. 预期成果与长效合作机制  
8. 恳请投促局支持事项  
9. 费用原则与下一步工作  

## 生成方式

```bash
pip install python-pptx python-docx
python3 generate_word.py
python3 generate_ppt.py
python3 generate_md.py
```

所有文案集中在 `content.py`，三份交付物共享，保证内容一致。
