## 1. 使用说明与模型整体架构

**估值对象和口径必须先统一。** 先明确估值日、主体、合并范围、币种、股权类别、估值目的（IFRS 13公允价值／投资定价／并购交易／IPO市场资本化）、估值为企业价值(EV)、全部股权价值(Equity Value)还是某一类优先股的公允价值。三者不可混称。

```text
数据采集（经审计历史、订单、客户、研发、合同、股权条款）
  ↓
会计与口径调整（经常性收入、研发资本化、净债务、表外义务、币种）
  ↓
产业经营驱动：用户/订阅/Token/出货量/产能/订单/临床里程碑
  ↓
三表预测：利润表、资产负债表、现金流量表；月度流动性
  ↓
DCF（FCFF/WACC） + 市场法（EV/Sales、EV/GP、EV/EBITDA等）
  + 交易法 + 阶段概率法（rNPV/PWERM）+ 资产法（按条件适用）
  ↓
质量检查 → 市场校准 → 情景和敏感性 → EV转全部股权价值
  ↓
优先权/转换/反稀释/期权池分配 → 融资前后每股价值
  ↓
18C合规性与IPO市值门槛测试（单独输出，不替代估值）
  ↓
估值区间、回调建议、触发条件、证据链和审批记录
```

建议同时输出以下六种指标：

| 输出代码 | 输出 | 口径 |
|---|---|---|
| VAL_EV | 企业经营价值 | 经营性资产价值，不等于市值 |
| VAL_EQ_PRE | 融资前全部股权价值 | 扣净债务等后，未加本轮新资金 |
| VAL_EQ_POST | 融资后全部股权价值 | 需明确是否包含IPO/增资现金及相应成本 |
| VAL_SHARE | 完全摊薄普通股等价每股价值 | 处理优先股转换、期权、认股权证 |
| VAL_RANGE | 悲观/基准/乐观估值区间 | 条件/概率和方法权重均留痕 |
| HK18C_GATE | 港交所18C适用性诊断 | `PASS / CONDITIONAL / FAIL / NOT-ASSESSABLE` |

> **原则**：不能倒推“达到40亿或80亿港元所以估值合理”；不能把融资前后估值、上市市值门槛、总企业价值和发行所得混用。

## 2. 18C及18A规则准入核验

### 2.1 18C关键门槛（截至2026-11-06）

依据港交所2026年官方说明、18C章、上市申请人指引第2.5章和2024年临时修订公告，模型应使用下表：

| 核验项 | 已商业化 Commercial | 未商业化 Pre-Commercial | 逻辑和证据 |
|---|---|---|---|
| 最近一会计年度经审计合资格特专科技业务收入 | **≥2.5亿港元** | **<2.5亿港元** | 只核实特专科技业务分部收入，剔除不相关业务、内部交易和非经营性收益；[HKEX-1][HKEX-2] |
| 上市预期最低市值 | **40亿港元** | **80亿港元** | 2024-09-01至2027-08-31临时降至该门槛；规则正文原为60亿／100亿，临时适用条件以公告为准；[HKEX-3] |
| 研发支出/总经营支出 | **≥15%** | 最近经审计年收入≥1.5亿但<2.5亿港元：**≥30%**；收入<1.5亿港元：**≥50%** | 在上市前3个财政年度中至少2年各自达标，且3年合计达标；[HKEX-4] |
| 经营记录 | 原则上现有业务相同管理团队至少3个财政年度 | 同左 | 特定例外需交易所判断；[HKEX-2] |
| 特专技术研发历史 | 至少3个财政年度 | 同左 | [HKEX-4] |
| 独立资深投资者 | 需要有实质性投资 | 同左 | 详见第2.3节；[HKEX-5] |
| 商业化路径 | 核验持续性与披露 | 必须披露可信的商业化路径及潜在融资缺口 | [HKEX-6] |
| 营运资金 | 适用一般及其他要求 | 至少覆盖上市文件刊发日起12个月相关成本的**125%**，考虑IPO所得 | [HKEX-7] |
| IPO配售 | 至少**50%**发售股份由独立定价投资者在配售部分认购（含合资格基石） | 同左 | [HKEX-8] |

**重要：18C收入测试不是营业总收入测试。** 例如有传统系统集成业务+自研AI平台的公司，须分部识别符合18C的收入。暂不把“合同额、在手订单、年度经常性收入ARR、GMV、未确认订阅款”直接算作收入。

### 2.2 港交所认可领域与本文件六个研究模块的映射

| 本文件研究模块 | 18C官方可能对应的产业/领域 | 边界问题 |
|---|---|---|
| AI企业（重点） | 新一代信息技术：AI、云服务；先进硬件及软件 | 普通外包/转售算力、无核心研发技术的集成服务不当然适用 |
| 硬科技 | 先进硬件/软件、半导体、先进材料等 | 仅贸易或代工须审查科技实质 |
| 新能源 | 新能源与节能环保：新能源生产、储存、输配与绿色技术 | 传统能源项目的资产运营与核心技术研发要区分 |
| 生物医药 | 研发型受规管药物通常优先评估18A；AI药研平台或生物材料等可能涉及18C | 看收入来源、核心产品是否属受规管临床产品；不可把18A和18C门槛混用 |
| 高端装备 | 机器人、自动化、先进制造、航空航天等 | 传统机加工不因为“高端装备”标签自动合格 |
| 专精特新 | **不是港交所18C独立产业分类** | 先回归对应的AI、半导体、装备、新材料、新能源等具体技术领域；可能走一般主板规则 |

### 2.3 18C独立资深投资者的模型核验字段

在`18C_Compliance`页设置：投资者独立性、资深资格证据、投资结算日期、投资金额、12个月持续持股、申请日权益、上市时权益、投资者汇总占比。

港交所指引给出的**指示性基准**包括：通常有2–5名Pathfinder资深独立投资者，至少在申请前12个月投资；合计持有申请日股本10%以上或合计投资额达15亿港元；其中至少两名分别持股3%以上或分别投入4.5亿港元。另有全部资深独立投资者持股比例基准，因预计市值与商业化阶段而异；不能只用单一比例替代完整规则判断。详见[HKEX-5]。

### 2.4 研发占比的正确计算口径

指引第2.5章将`总经营支出`定义为：**财务报表期间总费用（剔除销售成本和融资性质费用）＋未费用化、但符合条件的研发成本**；研发支出也需根据具体规则，调整资本化开发费用及相关摊销，避免重复计算。最终以港交所指引原文及发行人财务政策为准。

```text
18C_符合资格研发支出_t
  = 当期符合要求的费用化研发
  + 符合要求的资本化研发开发成本
  + 其他按指引可计入的研发项
  - 已在本期费用中重复计入的相关摊销/折旧等

18C_总经营支出_t
  = 当期财报总费用 - 销售成本 - 融资性质费用
  + 符合要求且未在总费用中确认的研发成本
  ± 其他按指引所需调整

18C_R&D比例_t = 合资格研发支出_t / 18C_总经营支出_t
3年合计比例 = SUM(3年合资格研发支出) / SUM(3年总经营支出)
```

**模型严禁直接以“研发费用/全部营业成本与费用”替代法定比率。** 见[HKEX-5]指引及附录演算。

### 2.5 生物医药18A/18C分流

- **18A**：面向符合资格、未满足一般上市财务测试的生物科技公司；初始市值至少**15亿港元**、原则上至少两个财政年度相关业务记录、至少一项核心产品超过概念阶段，以及12个月相关成本125%营运资金覆盖等。核心产品通常涉及需临床试验批准的受监管产品；以[HKEX-9]核验。
- **18C**：如企业核心价值在AI药物发现平台、智能研发自动化、算法/软件平台或符合列举领域的技术，而非自身受监管药物作为主要上市基础，可能进入18C分析。实际需按公司业务结构、监管属性和港交所意见判断；晶泰科技2024年招股书提供了AI药研平台按18C界定业务的公开案例。[CASE-1]
- **不能**只因企业使用AI技术，就把传统药物研发项目从18A切换到18C；也不能把18A最低市值15亿港元套用于18C。

## 3. 通用估值方法及公式库

### 3.1 方法选择总览

| 方法 | 主要用途 | 核心公式 | 注意事项 |
|---|---|---|---|
| FCFF-DCF | 有可建模经营收入、成本、CAPEX和资金周转的企业 | `EV = Σ FCFF_t/(1+WACC)^t + TV/(1+WACC)^N` | 未商业化企业需更长预测期，避免终值主导 |
| FCFE-DCF | 稳定股权现金流与明确债务政策 | `Equity = Σ FCFE_t/(1+Ke)^t + TV_equity/(1+Ke)^N` | FCFE必须与Ke配对，不能用WACC |
| 上市可比公司法 GPC | 18C市场定价、IPO比较 | `EV = 财务或经营指标 × 可比企业调整后倍数` | 同期、同币种、同会计定义、同成长阶段 |
| 可比交易法 | 收购控制权/并购定价 | `EV = 交易标的指标 × 交易倍数` | 处理控制权、协同和交易时间差异 |
| 最近融资轮次校准 | 创投、Pre-IPO、复杂股权 | 从真实交易价格重现当时各类证券价值后更新输入 | 融资价格**不自动等于**当前公允价值 |
| rNPV | 创新药、未成熟科学商业化项目 | 逐期风险调整现金流的现值 | 研发支出与成功概率必须匹配；避免重复风险扣减 |
| 里程碑/情景法 PWERM | 前商业化、IPO/并购/清算路径 | `证券价值 = Σ p_s × 该情景证券回款的现值` | 场景概率与证券优先权条款一起计算 |
| OPM期权定价 | 多轮优先股、复杂清算优先权 | 按股权价值、波动率、退出年限、分配断点定价 | 不是直接用公司EV替代每类股份价值 |
| 调整净资产 NAV | 资产密集或清算情形、下限检验 | `调整资产公允价值 - 调整负债公允价值` | 对无形资产与未来利润易低估；不能机械相加 |
| VC退出法 | 极早期定价交叉检验 | `融资后估值 = 退出股权价值/(1+目标回报率)^n` | 显式考虑后续稀释及生存概率，避免双重扣减 |
| SOTP分部加总 | AI软件+硬件+产业项目混合业务 | `Σ分部EV ± 中央费用现值 - 净债务` | 避免内部交易、共享成本和协同价值重复计算 |

### 3.2 DCF（Excel可落地）

**A. 经营预测**

```text
Revenue_t = Revenue_(t-1) × (1 + Growth_t)
GrossProfit_t = Revenue_t × GrossMargin_t
EBITDA_t = GrossProfit_t - 现金研发费用_t - 销售费用_t - 管理费用_t
EBIT_t = EBITDA_t - D&A_t
Tax_t = MAX(0, 应纳税所得额_t) × TaxRate_t  （正式模型应补税损结转）
NOPAT_t = EBIT_t - 经营税额_t
FCFF_t = NOPAT_t + D&A_t - CAPEX_t - ΔNWC_t
ΔNWC_t = NWC_t - NWC_(t-1)
```

说明：研发如果是费用化则已影响EBIT；资本化研发的现金开支须在对应CAPEX/开发支出现金流中反映，不能遗漏或重复扣减。经营负债、递延收入、存货、应收和应付均须驱动营运资金预测；税损结转要单独跟踪。

**B. 折现率**

```text
Ke = Rf + Beta_Levered × ERP + CountryRiskPremium + SpecificRiskPremium
Kd_aftertax = Kd × (1 - TaxRate_Applicable)
WACC = [E/(D+E)]×Ke + [D/(D+E)]×Kd_aftertax
```

以**估值币种对应的无风险利率**、公司风险和真实目标资本结构构造。若预期FCFF以人民币生成，折现率和终值增长率也须采用一致的名义人民币口径；若以港币计价，应在币种转换、通胀和折现率之间保持一致。不要把KPMG成熟公司统计WACC不加修正地用于亏损前商业化AI初创企业。

**C. 终值**

```text
TV_Gordon = FCFF_(N+1) / (WACC - g)
FCFF_(N+1) = FCFF_N × (1+g)  # 仅在企业达到可持续稳态时
TV_Exit = EBITDA_N × Exit_EV_EBITDA_Multiple
EV_DCF = SUM(FCFF_t/(1+WACC)^t) + TV/(1+WACC)^N
```

必须满足`WACC > g`，且稳态增长、利润率、研发投入、重置CAPEX、营运资金不能互相矛盾。若2031年仍在高速扩张且现金流尚未成熟，应把预测期拉长至8–12年，或使用分阶段终值，而非以单一年最后现金流永久外推。

**D. EV到全部股权价值**

```text
OperatingEV
+ 非经营性现金/可动用超额现金（区分已在预测中的经营性现金）
+ 非经营性可出售资产公允价值
- 有息负债及债务类项目
- 租赁负债（仅在EV和FCFF口径与租赁会计处理一致时）
- 少数股东权益/其他索取权（按对应分部估值口径）
- 未纳入预测的或有负债、优先索取权
= 全部股权价值（需先明确普通股/优先股权益的对应分配口径）
```

### 3.3 市场法：指标和倍数必须配套

```text
EV/Sales_NTM = EV_public / Revenue_NTM
EV/GP_NTM = EV_public / GrossProfit_NTM
EV/EBITDA_NTM = EV_public / EBITDA_NTM
P/E = OrdinaryEquityMarketCap / NetIncomeToOrdinaryEquity
EV_target = TargetMetric_same_period × AdjustedPeerMultiple
```

- 可比池通常至少包含足够数量的业务相似公司；不足时明确小样本问题，不机械规定“必须五家”。纳入地域、增长率、毛利率、营收质量、研发密度、财务状况、币种及会计政策。
- 用估值日前收盘/平均市值和债务、现金计算EV，剔除一次性事项；明确`LTM/NTM/FY+2`。未上市对象不能盲目对标高波动上市公司的某一天高点。
- 业务可比性差时可从`EV/Revenue`升级至`EV/GrossProfit`，降低低毛利的算力转售/设备集成收入对估值的扭曲。
- **估值调整**可表达为`调整倍数 = 基准倍数 × (1 + 有依据的调整比例)`，但调整比例必须是证据支持的差异归因，不是固定“一级市场一律打七折”。
- 不要把并购交易所含控制权及协同溢价自动转用到少数股权定价。

### 3.4 反向DCF/隐含参数

给定交易价格/期望IPO市值`EV_target`，让求解器反求`Revenue_CAGR`、`EBITDA_margin_steady`、`WACC`、`g`中**一个**参数（其他参数固定），并判断反推出的经营目标是否合理。建议同时反推出收入目标、付费客户数、Token调用规模及人均收入，而非只给出“估值偏高”。

### 3.5 方法加权的纪律

只有当各方法的**价值口径一致、均已校准、均有可辨认的有效信息**时，才进行加权。权重不构成会计准则、监管规则或四大通用固定比例。对明显无效的方法（例如亏损期P/E、终值异常的DCF）应剔除或标注仅供交叉检验，不能为了“得出目标估值”而赋权。

## 4. AI企业（重点）：18C专用底层经营模型

### 4.1 AI企业必须先分型

| AI类型 | 收入核心驱动 | 核心风险 | 一线估值方法 | 辅助验证 |
|---|---|---|---|---|
| 基础模型/API/模型即服务 MaaS | 付费Token、每百万Token单价、模型/云端订阅 | 推理成本、模型替代、价格战、算力依赖、监管 | 单位经济模型 + 多阶段DCF；EV/毛利 | NTM EV/收入、最近融资校准、PWERM |

### 4.3 SaaS/Agent经营逻辑（不要重复计算NRR与流失）

```text
期末老客ARR_t = 期初ARR_t × NRR_t
期末总ARR_t = 期末老客ARR_t + 新客ARR_t
平均ARR_t ≈ (期初ARR_t + 期末ARR_t)/2
已确认订阅收入_t = 平均ARR_t × 履约确认因子_t

付费Token收入_t
  = Σ模型/客户档位(实际计费Token数/1,000,000 × 实现售价/百万Token)

AI当期收入_t = 订阅确认收入 + Token调用已确认收入
          + 符合收入准则的授权/集成/硬件/服务收入
```

注意：若“净收入留存NRR”已经包含客户增购与流失，则禁止再对老客ARR额外扣一次Churn。试用量、非约束订单、免费调用量不得等同已确认收入。多年的收入预测应按客户群（金融、政企、制造、消费）、产品、地区拆分。

### 4.4 推理成本/模型单位经济的详细公式

```text
单位实现收入R_token = 实际Token净收入 / 实际计费Token数
单位推理成本C_token = 推理GPU计算+云资源+数据传输+第三方模型调用/实际服务Token数
Token贡献毛利率 = (R_token - C_token)/R_token

推理总成本 = Σ(推理Token_百万 × 单位推理成本)
          + 与推理相关的其他直接服务成本

云与托管成本 = 实际GPU小时 × 小时租赁成本 × 计费调整
自建算力 = 设备现金CAPEX（现金流）+ 会计折旧（利润表COGS）
```

**禁止把自有GPU设备支出同时全部计入COGS并在FCFF里再次全额扣CAPEX。** 若为租赁算力，按租赁/服务实际合同辨别会计处理。若收入主要来自低毛利转售，应优先使用毛利质量和客户经济性，谨慎套用纯SaaS收入倍数。

**AI经营质量校验**：`毛利率`、`有效Token单价`、`单位推理成本`、`推理毛利趋势`、`ARR与已确认收入桥表`、`新客CAC回收期`、`产品留存`、`大客户集中度`、`订单履约能力`、`训练和微调费用`、`模型安全/数据许可/出口管制`。

### 4.5 虚构AI企业五年DCF完整算例

**演示设定**：某虚构企业2026年度收入为**2.14亿元人民币**。例如，其订阅业务年初ARR为1.20亿元、NRR为115%、新增ARR为0.80亿元，则年末ARR为`1.20×115%+0.80=2.18亿元`；简化采用年初、年末ARR算术平均值`(1.20+2.18)/2=1.69亿元`估算订阅确认收入，再假设当年合资格Token/API已确认收入为0.45亿元，得到合计收入2.14亿元。实际确认收入必须逐合同、履约义务和使用量核验，不能因ARR变动线性就机械确认。2027–2031年度经营预测如下。研发支出与销售管理费率均以收入比例表示；税按25%且**暂未计入可利用税亏结转**；`D&A=收入×3%`、`ΔNWC=当年增量收入×4%`。所有数值均为演示，并非任何真实18C发行人数据。

| 年度 | 收入增长 | 收入（亿RMB） | 毛利率 | 费用化研发/收入 | 销管/收入 | EBITDA（亿） | FCFF（亿） |
|---|---:|---:|---:|---:|---:|---:|---:|
| 2027 | 60% | 3.424 | 50% | 42% | 32% | -0.822 | -1.147 |
| 2028 | 45% | 4.965 | 56% | 35% | 26% | -0.248 | -0.707 |
| 2029 | 30% | 6.454 | 61% | 28% | 23% | 0.645 | 0.021 |
| 2030 | 20% | 7.745 | 65% | 23% | 20% | 1.704 | 0.820 |
| 2031 | 12% | 8.674 | 68% | 20% | 18% | 2.602 | 1.546 |

资本开支占收入比分别为8%/8%/7%/6%/5%。以`WACC=16%`、`g=3%`计算：

```text
2027 EBITDA = 3.424 × (50%-42%-32%) = -0.82176亿元
2027 D&A   = 3.424×3% = 0.10272亿元
2027 EBIT  = -0.92448亿元
2027 经营现金税 = 0（本例暂忽略往年税损和递延税）
2027 CAPEX = 3.424×8% = 0.27392亿元
2027 ΔNWC  = (3.424-2.14)×4% = 0.05136亿元
2027 FCFF  = -0.92448 + 0.10272 - 0.27392 - 0.05136
            = -1.14704亿元

2031 TV = 1.5459195648×(1+3%)/(16%-3%) = 12.2484亿元
2027–2031 FCFF现值之和 = -0.3120亿元
2031 TV折现至估值时点 = 5.8316亿元
演示经营EV = 5.5196亿元人民币（约5.52亿元）
```

**重要诊断**：本例终值现值`5.8316亿元`竟高于全部EV`5.5196亿元`，说明短期现金消耗大、模型高度依赖远期盈利，不能直接把5.52亿元当作可投可用的确定性定价；必须延长预测期、调整稳态资本开支并与可比公司校准。这个演示估值与18C的**40亿/80亿港元门槛不是同一货币/口径，也不能反向强行拉高以过门槛**。

**折现率和终值增长率二维敏感性：**

| WACC \ 终值g | 2% | 3% | 4% |
|---|---:|---:|---:|
| 14% | 6.58 | 7.27 | 8.10 |
| 16% | 5.05 | **5.52** | 6.07 |
| 18% | 3.94 | 4.27 | 4.65 |

单位均为亿元RMB，按照上述演示经营预测重算。可见模型对终值和资本成本有较大弹性，业务尚未成熟时应将此敏感性直接呈现给投资委员会。

### 4.6 AI企业市场法、上市回调示例

设演示2027年预测收入`3.424亿元RMB`；**假设**根据估值日同类业务可比样本分析，保守选择`EV/NTM收入=3.0x`（纯演示，非AI行业实际倍数），且有充分证据支持相对同业`-20%`经营质量调整：

```text
上市可比原始指示EV = 3.424 × 3.0 = 10.272亿元
调整后指示EV = 10.272 × (1-20%) = 8.2176亿元
DCF指示EV = 5.5196亿元
```

**不能直接在8.2176亿元上再随意贴一个“IPO折价20%”**；应说明20%的调整到底反映了增长、利润、风险、流动性还是发行交易定价，并检查这些风险是否已包含在DCF/WACC和可比调整中。两种方法差额`2.6980亿元`须通过增长质量、推理单位经济、正常化毛利、折现率、上市可比口径和预期利润率解释，而非人为加权掩盖。

对18C未商业化AI企业需另外构建：

1. **达到2.5亿港元合资格科技业务收入的时间表**：逐月已签合同、预计落地日、确认收入与回款时间、未约束意向订单概率；所有RMB数据用估值日指定汇率转换，不将ARR误作为收入。
2. **12个月125%营运资金覆盖表**：合格现金及有约束力资金来源+预计IPO净所得，对照12个月相关成本；按交易所定义调整资本支出与债务现金支出。
3. **上市后稀释和融资需求**：模型区分融资本金进入企业的现金与融资后股数；不要把拟融资资金同时加进预融资DCF和Post-Money股权桥表。
4. **融资与失败情景**：若销售/研发里程碑未达成，分别反映延期、追加融资、下轮估值下调、优先股转换条件，而非统一上调WACC。
5. **客户与算力数据室**：基础模型性能、推理负载、单token成本、客户留存、监管合规、知识产权及真实付款/开票证据。

## 5. 硬科技：半导体、先进材料、算力硬件

### 5.1 估值选型

- **商业化设计公司/先进材料厂商**：出货量驱动DCF为主，`FY+1/FY+2 EV/收入`、`EV/毛利`为辅；稳定盈利后加入`EV/EBITDA`。
- **未量产的芯片公司**：里程碑（Tape-out、流片、良率、客户认证、量产）×场景DCF/PWERM及最近融资校准；不可对负利润使用P/E。
- **自有晶圆产线/重资产**：FCFF-DCF与调整资产法交叉验证，真实维护CAPEX和产能利用率是估值关键。

### 5.2 经营模型

```text
可售芯片量_t = 晶圆投片量_t × 每片理论裸片数 × 可售良率_t × 交付率_t
芯片收入_t = 可售芯片量_t × 订单加权ASP_t
设计授权/IP收入_t = 合同里程碑确认收入 + 符合准则的授权收入
毛利_t = 收入_t - 晶圆代工/封测/材料/物流/质量保证及其他COGS
FCFF_t = EBIT税后 + D&A - 流片及设备CAPEX - Δ应收应付存货及预付款
```

**需调参数（全为待校准情景变量）**：客户Design-in成功率、流片成功率、从验证到量产周期、晶圆良率、ASP降价、晶圆/材料采购价格、产能良率爬坡、研发人员成本、出口许可与客户认证、存货跌价准备。演示压力测试可设“量产延期0/6/12个月、ASP变化±15%、良率变化±10个百分点、关键客户订单实现率40%/70%/90%”；这**不是**行业典型值。

**回调顺序**：先下调客户认证/流片成功概率及延后收入，再更新单位生产成本与CAPEX/运营现金消耗，随后重算可比倍数和退出时间；避免同时上调所有风险溢价造成双重折减。

## 6. 新能源：储能、光储、能源技术

### 6.1 分类与匹配

| 子赛道 | 主方法 | 交叉核查 |
|---|---|---|
| 储能系统集成与电芯 | 产量/订单驱动DCF | EV/毛利、稳定后EV/EBITDA |
| 电力电子/逆变器/关键设备 | 订单现金流DCF | EV/EBITDA、可比交易 |
| 电池材料与新工艺 | 产能×良率×ASP DCF | EV/收入、调整净资产 |
| 持有长期能源项目的公司 | 各项目分期现金流DCF/SOTP | 合同期限、WACC、项目剩余寿命，勿直接用永续高增长 |

### 6.2 单位经济驱动

```text
电芯出货量(MWh) = 产能(MWh) × 利用率 × 合格品率 × 销售实现率
设备/系统营业收入 = 已交付确认MWh × 合同实现单价(元/MWh)
材料毛利 = 销量 × (产品ASP - 原料单耗×采购价 - 制造及质量成本)
订单收入 = 期初有效订单 × 按期交付率 + 年内新增订单经确认部分
项目经营现金流 = 实际电费/服务费收入 - 运维 - 税费 - 周期性更换/维护资本开支
```

**需调参数**：订单取消与执行率、储能系统/电芯ASP、碳酸锂等上游成本传导速度、产能利用率、项目并网/验收、补贴真实回款、保修索赔、售后储能衰减、营运资金、国际贸易限制及本币/外币。演示压力测试：ASP±10%、产能利用率±15个百分点、原料价格±20%、回款周期延长90天，均需按实际合同覆盖率重设。

**回调顺序**：价格与原料成本分开（避免将收入增速变化误当成本变化），再改变订单交付与回款，确认对利润和现金流的不同影响；长期项目适当以项目级DCF分部汇总。

## 7. 生物医药：18A/18C分流与rNPV

### 7.1 主要估值方法

- 有商业化药物和稳定销售的企业：药品逐产品DCF、必要时EV/销售、EV/EBITDA。
- 在研药物：**风险调整净现值rNPV**，明确临床分期、监管批准、上市时间、保护期、渗透率、竞争格局、销售峰值、授权里程碑。
- AI药物发现平台/生物技术工具：项目服务和平台收入DCF + AI软件/研发外包可比倍数，严格区分**自有药物管线的rNPV**与**提供药研服务的收入**；不重复计入共同知识产权收益。
- 18A申报前先审查核心产品监管属性及超过概念阶段要求；18C见2.5节。

### 7.2 rNPV公式（管线逐项建模）

```text
Expected_FCF_t = P_活跃或销售成功,t × 商业化FCF_成功,t
               - Σ(P_进入当期研发阶段,i,t × 研发现金支出_i,t)
               + 已签且符合预测条件的授权/里程碑净现金流（按条款、概率）

rNPV_pipeline = Σ(Expected_FCF_t / (1+r)^t)
Company_EV = Σ(rNPV_pipeline) + 平台服务经营EV
          + 其他独立可辨识资产价值 - 未列支中央成本现值 - 重复归属收益
```

若已经按逐阶段成功概率调整未来商业化现金流，折现率应按适当口径构造，**不要再对相同临床失败风险加一次大额项目风险折现**。允许根据市场风险、时间价值和剩余不确定性调整，但必须披露风险归属。

**纯演示**：单项管线若“在全部成功情形下未来商业化净现金流的当前现值”为12亿元，整个项目成功概率按公司材料/专家确定的演示输入为15%，且已按不同研发阶段概率加权后的开发支出现值为1.5亿元，则：

`rNPV = 12×15% - 1.5 = 0.30亿元RMB`。

这不代表任何临床阶段真实成功率。需要逐步拆解原理、毒理、I/II/III期、注册、上市后退出概率；避免用一个全流程概率掩盖每阶段费用发生与失败停止条件。

**关键回调**：临床数据/终点达成概率、获批时间、竞争产品、适应症可治疗人数、医保支付/净价、峰值渗透率、专利期限、研发追加现金、授权分成、监管要求。盈利公司的传统P/E并不适用于亏损药企。

## 8. 高端装备：机器人、自动化、精密设备

### 8.1 估值方法

量产稳定后以`订单驱动DCF + EV/EBITDA`为主，`EV/收入/毛利`为辅；研发型机器人则采用里程碑情景+DCF。软件授权、耗材、维保和设备销售应分别建模，可采用SOTP以识别重复性收入价值。

### 8.2 经营公式

```text
新设备收入 = Σ(产品型号出货台数 × 实现售价) × 验收/收入确认系数
期末订单 = 期初在手订单 + 新签有效订单 - 已确认交付订单 - 取消订单
维护及耗材收入 = 已安装设备保有量 × 服务渗透率 × 年度ARPU
营业毛利 = 设备收入×设备毛利率 + 软件收入×软件毛利率 + 服务收入×服务毛利率
FCFF = EBITDA - 经营税额 - 现金净资本开支 - ΔNWC（加回D&A影响按通用口径）
```

**核心参数**：订单转化、产能、关键零部件采购、出厂良品率、安装验收延迟、维保收入附着率、海外认证、供应商集中度和客户账期。建议模拟“验收延迟3/6/9个月、核心客户流失、质保费用上升、服务渗透率下降”对自由现金流的影响，不能只调整销售额。

## 9. 专精特新：细分市场龙头与中小制造企业

“专精特新”不是一种独立商业模式，也不是18C法定行业类别。先判断其所属技术领域与是否具有可持续核心技术，再决定方法：

| 类型 | 主方法 | 补充方法 | 调整重点 |
|---|---|---|---|
| 盈利稳定的细分零部件冠军 | FCFF-DCF / EV/EBITDA | 可比交易 | 客户集中、毛利韧性、营运资金 |
| 单一大客户依赖的制造企业 | 情景DCF | 资产法或有序清算下限 | 大客户续约、应收、质量索赔 |
| 关键材料/特殊工艺 | 产品ASP+良率DCF | EV/毛利 | 配方/专利、进口替代和真实订单 |
| 高研发未盈利的专精特新企业 | 阶段DCF+最近融资校准 | EV/收入/毛利、PWERM | 技术商业化概率、下一轮融资及控制权 |

```text
细分品类收入 = 客户产量或采购预算 × 公司份额 × 有效售价
毛利 = Σ(品类收入 × 对应毛利率)
正常化EBITDA = 报告EBITDA ± 有证据支持的一次性/非经常调整
FCFF = EBIT×(1-现金税率) + D&A - 维护/扩张CAPEX - ΔNWC
```

**专精特新企业常见估值陷阱**：把政府资质认定直接转换为估值溢价；把专利数量当作创造现金流的专利质量；忽略高客户集中与应收账款；将账面净利润、净现金和资本化研发重复计价。

## 10. 估值回调、再校准与反向估值

### 10.1 四种“估值回调”要分开

1. **经济估值再校准（mark-to-market）**：估值日后有新订单、现金流、融资、可比交易或宏观变化，修订企业价值；这是本手册重点。
2. **交易定价回调（down round / price revision）**：投资者与发行人重新谈融资价格、认购数量、分期交割；需更新融资前后股权与摊薄。
3. **证券合同上的反稀释/估值调整条款**：如加权平均反稀释、特殊对赌或清算优先权，需由合同和法律顾问确定，不可用单一估值折让公式替代。
4. **IPO簿记发行价调整**：在投资者需求和上市门槛下确定发行价格与发行数量，是市场发行过程；不能把目标市值当成DCF硬约束。

### 10.2 每次估值更新的可执行流程

| 步骤 | 操作 | 需要更新的输入 | 必须保留的证据/控制 |
|---|---|---|---|
| 0 | 锁定前期版本 | `VALUATION_DATE_OLD`、`VAL_PREVIOUS` | 上期批准模型及估值报告 |
| 1 | 核对新财务实际值 | 历史收入/毛利/研发/CAPEX/现金/负债 | 新审计报表、总账、银行流水和财务差异桥 |
| 2 | 经营驱动差异归因 | ARR、Token、订单、ASP、毛利、客户流失、验收/临床概率 | 订单合同、客户分群、工程/临床报告 |
| 3 | 时间表和资金需求 | 商业化时间、下一轮融资、12个月跑道 | 现金流月报、薪酬与云资源/研发预算 |
| 4 | 同期市场重新抽样 | 可比池、LTM/NTM指标、EV/GP/收入/EBITDA | 截止日行情、净债务、原始数据链接 |
| 5 | 更新资本成本和终值 | 无风险利率、ERP、Beta、债务利率、g、稳态利润 | 市场观测值和假设委员会批准 |
| 6 | 重算和检验 | DCF、市场法、PWERM/rNPV、SOTP | 自动校验和异常项解释 |
| 7 | 拆解变化 | 经营、市场倍数、汇率、时间流逝、净债务、优先权 | 估值变动桥（见下） |
| 8 | 出具最终结论 | 估值区间、每股值、回调建议与触发条件 | 签核人、复核人、最终版本与数据日 |

### 10.3 估值变动桥（必须算得通）

```text
本期全部股权价值
= 上期全部股权价值
+ 仅因期间推移的价值展开（unwind）
+ 新经营数据/商业化概率变化
+ 可比估值倍数/资本市场变化
+ WACC/终值参数变化
+ 净现金、股权发行、稀释及证券条款影响
+ 汇率及其他有证据的调整
+ 未分配残差（应为零或有解释）
```

`Check_Bridge = 本期估值 - 上期估值 - SUM(各驱动解释)`，原则上须为0（容许极小数值舍入误差）。

### 10.4 “回调哪些参数”：统一调整优先级

| 触发事实 | 首要调整 | 第二步 | 通常不要先做的事 |
|---|---|---|---|
| AI模型调用激增但收费率下降 | 净收费Token、实现单价、免费量 | GPU单位成本和毛利 | 直接提高PS倍数 |
| AI竞争导致客户流失 | NRR、CAC、平均合同额 | 长期利润率、可比池 | 只上调WACC而不改收入 |
| 新一轮独立市场化融资 | 证券条款、融资价格和摊薄 | 回测当前DCF/倍数隐含假设 | 把优先股价格当普通股价格 |
| 半导体流片失败/延迟 | 量产里程碑概率及时间 | 流片追加研发和现金跑道 | 使用永久不变增长率 |
| 新能源产品降价 | ASP与原材料成本 | 库存、应收和质量保证 | 直接把利润按降价幅度等比例下降 |
| 创新药临床试验失利 | 对应阶段概率和路径 | 增加/延后研发、授权及定价 | 重复叠加同一失败概率与风险溢价 |
| 装备客户验收延期 | 发货/验收/收入确认时间 | 回款、质保与营运资金 | 仍用签单额作为当期收入 |
| 利率/资本市场估值下移 | 同期可比倍数、Rf、ERP | IPO窗口、现金筹措情景 | 不经证据一律打7折 |
| 估值与18C门槛差额大 | 判断估值结论、上市阶段和融资策略 | 模型延期、商业化及其他上市路径 | 用门槛倒推估值/调高TV |

### 10.5 估值回调演示：同一家AI公司

假设旧估值8.00亿元、新估值需回调，经证据拆解：

```text
旧股权估值                  8.00
经营增长下修               -1.10
算力毛利恶化               -0.45
可比同业市场倍数下降       -0.80
融资净现金及其他              +0.25
新股权估值（演示）          5.90 亿元
```

每项变动须来自“**冻结其他因素，仅替换该因素后重算模型**”的桥接法，且约定调整先后顺序（顺序改变时交互项分配需要披露）。上表只是结构演示，不代表可对任何AI公司直接减去上述金额。

### 10.6 方法校准（Calibration）

根据IPEV 2025版指引，若进入投资时的有序交易价格可视作公允价值，需用**投资当时**的市场和经营输入对后续将持续使用的估值技术进行校准；后续每个估值日用**当期**输入重新估值并解释变化。[IPEV-1][KPMG-2]

```text
入场时隐含EV/收入 = 当时EV / 当时可比口径收入
入场时相对同行倍数比 = 入场时隐含倍数 / 当时同业可比篮子倍数
当前校准倍数（可作起点） = 当前同业可比篮子倍数 × 可论证的当前相对差异
```

`相对差异`不应自动冻结：应依据留存、利润率、增长、研发实力、治理、流动性和风险变化更新。对有清算优先权的融资轮次，首先把“交易证券价格”分配为各类权益价值后再校准。

## 11. 资本结构、融资稀释与IPO市值联动

### 11.1 普通股融资演示

假设融资前公司全部普通股股权价值8亿元，增资2亿元，且没有优先权、认股权证、交易费用等复杂因素：

```text
Pre-money = 8亿元
新投入现金 = 2亿元
Post-money = 10亿元
新投资者持股 = 2/10 = 20%
原股东融资后持股 = 80%
```

若融资定价回调到融资前6亿元，同样投入2亿元，则融资后8亿元，新投资者持股25%。**原股东稀释增加5个百分点**；若有优先权/ESOP增池/反稀释条款，实际分配会不同。

### 11.2 IPO每股值与门槛核验

```text
IPO前等价股数 = 已发行普通股 + 合理预计转换优先股 + 期权/权证（按适用口径）
IPO新发股份数 = 募资总额 / 发行价
IPO后等价股数 = IPO前等价股数 + 新发股份数 + 其他转换/调整股数
IPO发行市值 = 发行价 × IPO后等价总股份数
IPO净募集额 = 发行总额 - 发行费用及其他相关现金开支
```

**前提**：折股、优先股转股、期权稀释、不同投票权及超额配售须与上市方案对应。若估值模型已按IPO后现金流和融资现金计算Post-money，不可再加一次完整IPO募集额。将港股市值转为港元，统一估值时点汇率。对于上市门槛取值及临时规定适用，还需核验申报与预期上市日期。

### 11.3 优先股和复杂资本结构

若存在1×不参与清算优先权、参与型优先权、累积股息、反稀释、可转债、SAFE、赎回权：

1. 建立每轮证券`优先受偿本金/股息/转换比率/上限/认股比例/赎回条件`条款表；
2. 针对上市、并购、清算、下一轮融资，逐情景建立分配瀑布（waterfall）；
3. 使用`PWERM/OPM/混合法`计算每类证券价值；
4. 优先股价格不能简单除以发行总股数得普通股公允价值；
5. 对合约的法律可执行性、适用港股上市前终止或转股条款进行律师核查。

**流动性折让、非控制权折让、IPO发行折价等可能并非可叠加的独立折扣。** 按估值对象、已含特征和市场证据分别识别，避免多次折减同一风险。

### 13.1 公开资料筛选结论

### 13.3 正式对外估值报告的推荐目录（借鉴公开专业材料，不冒称四大格式）

1. 封面、委托范围、评估目的、估值日及限定事项。
2. 执行摘要：企业价值、全部股权价值、每股指示值、区间和适用性。
3. 公司与业务：持股、商业化阶段、产品、核心知识产权及技术成熟度。
4. 行业与市场：细分赛道、经营驱动、核心客户和竞争。
5. 18C规则及风险披露：法律门槛单独附录，不替代财务估值。
6. 历史财务复核：收入确认、研发、资本化、现金、净债务调整。
7. 方法论：为何采用DCF、市场法、融资/里程碑及为何排除其他方法。
8. 预测依据：分产品/客户经营驱动、研发/算力/CAPEX/应收应付。
9. 折现率、终值和可比企业：逐项来源、币种和市场日。
10. 各方法计算表：EV、Equity Bridge及股份分配瀑布。
11. 敏感性及情景：下行现金跑道、技术/监管/商业化里程碑。
12. 估值回调：新旧版本变动桥、关键风险与触发阈值。
13. 结论及局限：未能确认事项、限制、依赖资料、复核签字。
14. 附录：财报明细、合同样本、可比企业行情、监管及行业资料链接。

### 建模落地优先级

若资源有限，优先完成：**① 18C规则合规表 → ② AI经营驱动和单位毛利 → ③ DCF及融资现金跑道 → ④ 可比公司和融资轮次校准 → ⑤ IPO发行后权益分配和估值回调桥 → ⑥ 其他五行业差异化模块。**

对于面向港股18C的AI企业，核心不是“给一个热门科技倍数”，而是把**特专科技收入的真实性、研发持续性、模型推理单位经济、商业化证据、资金需求、股权优先权和国际投资者可接受的定价**落实到同一套可审阅的计算链条。
