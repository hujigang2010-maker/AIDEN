- `下载版本/WAIC2026人工智能产业空间白皮书-A4.pdf`：**A4（210×297mm）精排版**，封面使用陆家嘴配图与 RCHP 正式组合标，内文每页页眉为校徽 + 红底 RCHP 字标。
- `下载版本/WAIC2026人工智能产业空间白皮书.docx`：A4 Word 可编辑稿（页眉同样为 RCHP 组合标）
- `下载版本/WAIC2026人工智能产业空间白皮书.pdf`：由 Word 导出的 A4 PDF

重新生成 A4 精排版：

```bash
python3 scripts/build_rchp_logo.py
python3 scripts/build_a4_report.py
python3 scripts/build_whitepaper_docx.py
```
