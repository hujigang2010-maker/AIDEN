# 2026康博会专题分论坛交付说明

本目录是 2026 年 11 月 28 日专题分论坛的执行文件。嘉宾、联合承办单位和赞助在书面确认前，一律按拟邀、拟议处理。

## 内部使用，不要发给赞助商

| 文件 | 用途 |
| --- | --- |
| `01-内部-承办决策与执行策划.pptx` | 18 页。用于内部决策，以及与组委会讨论定位、授权和议程。其中商务比例只作谈判口径。 |
| `02-内部-活动执行策划案.docx` | 可提交组委会的执行文本，含圆桌脚本、预算上限、倒排和对外口径。 |
| `03-内部-执行管理台账.xlsx` | 每天更新的工作簿。黄底单元格手填，结论、结余和总览数字由公式生成。 |

台账打开后，决策检查默认全部为“未满足”，总览会显示不宜独立承办。每落实一项，就把判定改成“已满足”或“部分满足”。

## 可以发给合作企业

发出前先完成两件事：组委会批准可销售的权益；需要出现的单位已经书面授权。联系人留白，填写授权联系人后再发。

| 文件 | 用途 |
| --- | --- |
| `04-对外-赞助及产业合作方案.docx` | 正式赞助方案，含权益、议程、边界和待填联系表。 |
| `05-对外-赞助合作介绍.pptx` | 13 页口头介绍。不包含内部预算、分成和垫资安排。 |

## 重新生成

在仓库根目录执行：

```bash
PYTHONPATH=scripts/kangbohui python3 scripts/kangbohui/build_all.py
```
