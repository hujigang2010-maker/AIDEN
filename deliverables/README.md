# 泰隆银行 × 腾讯云 Work Buddy · V3.0 作战包

基于《战略合作实施方案 V2.0 落地版》升级，形成可汇报、可决策、可执行的配套交付。

## 交付物

| 文件 | 用途 |
|------|------|
| `泰隆银行x腾讯云WorkBuddy_战略合作实施方案_V3.0.pptx` | 高层决策会 / 启动会汇报稿 |
| `泰隆银行x腾讯云WorkBuddy_落地执行作战表_V3.0.xlsx` | 联合 PMO 周度运转操作系统 |

## V3.0 相对 V2.0 的升级点

1. **决策前置**：三项决策卡、建议结论句、会后 15 个工作日动作清单可直接进纪要。
2. **执行到岗**：W0–W13 周计划含验收标准与状态列；RACI 扩展到卡中心/跨境/财务。
3. **计量闭环**：漏斗三情景、六变量仪表盘、预算 burn-down、KPI 红绿灯看板。
4. **产品可落**：场景卡填空表、权益控本与反套利、对账字段草案、月结底稿。
5. **合规可审**：字段正负面清单、审批路径时点、话术禁区、准出/止损勾选表。
6. **跨境样本化**：服务包货架 + 样本客户评分表（≥70 纳入接洽）。

## 重新生成

```bash
python3 scripts/generate_tailong_workbuddy_ppt.py
python3 scripts/generate_tailong_workbuddy_excel.py
```

## 使用建议

- **首轮高层会**：只讲 PPT 决策卡、双闭环、关键数字、止损与会后动作。
- **联合 PMO 启动会**：以 Excel `01/04/05/11/14` 表开工会。
- **每周例会**：更新 `04-周计划`、`10-KPI看板`、`12-风险登记` 状态列。
- **闸门评审**：`15-准出门槛` 勾选 W5 / W8 / W13。

说明：所有金额、比例、转化率为测算假设，不构成承诺；正式条款以双方协议为准。
