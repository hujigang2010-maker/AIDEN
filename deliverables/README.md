## 工作表

1. **营销验收单**：封面，18 张全部按五级嵌入，**一级至三级集中排在最前**
2. **按重要顺序分类**：同序大图，前三级集中前置
3. **权益核验清单**：报价单四模块对照，各模块全部对应照片嵌在表内
4. **效果评估表**：绿城中国策划活动类效果评估表结构
5. **赞助权益执行回执**：供绿城复核签字盖章
6. **绿城·潮鸣外滩露出**：18 张精华大图（与分级同序）
7. **照片索引**：重要等级、拍摄时间、模块对照
