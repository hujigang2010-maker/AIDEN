# 交付物

运行 `python3 scripts/build_all.py` 生成全部文件；`python3 scripts/validate_deliverables.py` 做结构校验。

- 备忘录 Word：给家属和律师做事实底稿
- 简报 PPT：面谈前十分钟过一遍
- 伤情工作簿 Excel：贴发票、勾待办、改口径
- 肇事方沟通方案 Word / PDF：影像分析 + 开场稿 + 12 步流程 + 律师决策 + 三套方案
- 肇事方沟通流程表 Excel：12 步可勾选、对方接话、出示清单、通话记录
- 网页总览（普通 HTML，不用安装、不用 React）：`hongfeng-guide.html`（推荐用这个英文名链接）以及 `青岛红枫路交通事故_处理总览.html`
- 公网预览请用能按网页打开的地址（不要点 GitHub 源码页）。生成命令：`python3 scripts/generate_guide_html.py`
