## 核心要点

1. **晚宴冠名权**：晚宴 KV、席卡（由主办加）+ 桌卡 / 菜单 logo 植入（由活动公司印刷）；主持人开场 + 川总宣讲引荐 + 散场再次鸣谢共 3 段口播。
2. **主会场植入**：钻石级 logo、议程手册整版、500 份手拎袋夹「285/310 户型折页」、宣传片轮播。
3. **现场 2 处展位**：电梯口 + 展场内，各派销售 2 人；保底易拉宝 + 项目纸质物料；时间允许升级 KT 板背景墙。
4. **晚宴前 15 分钟川总专场宣讲**：1080P 16:9 PPT；话筒×2 + 切换器。
5. **项目参观**：因议程内 17:55–18:10 无空余时间，方案中给出 3 个解决方案，推荐 **方案 A（20:30 晚宴结束后的「会后专场」+ 尊界 8–10 辆 + 考斯特补位）**。
6. **物料尺寸建议**：
   - 主会场宣传片 16:9 1920×1080；
   - 川总宣讲 PPT 16:9 1920×1080；
   - 晚宴 LED 视频 16:9 1920×1080（条屏另出 6144×1080）— **像素比待场地方确认**；
   - 项目易拉宝 800×2000mm；户型折页 297×210mm 三折页。
7. **宣发**：媒体通稿、朋友圈九宫格、白皮书扉页联合署名、回顾视频片头鸣谢，双校长三角校友产业联盟战略合作伙伴永久入册。
