## 传播建议（发布事件化）

1. **一次发布会、四个传播物**：白皮书全文 + TOP50 榜单 + 十大场景 + 十大趋势分波次发布，延长传播周期；
2. **榜单先行**：TOP50 榜单最具媒体标题感，建议提前 1 周开启"入围企业申报/公示"制造悬念；
3. **案例拆条**：100 个案例可拆成 10 期行业系列图文/短视频（每期一个领域），适配公众号与视频号连载；
4. **联动入选企业**：向 50 家入选企业与 100 个案例企业发送"入选通知 + 授权转发物料"，撬动企业官方账号二次传播。
