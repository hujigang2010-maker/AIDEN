## 合并原则(内容级合并,非表格拼接)

- **统一项目名称**:全文收敛到“广州黄埔区九佛TOD‘全球自贸365街区’项目”,不再区分两个项目。
- **内容去重与融合**:将原知识城材料(进博会/领事馆外延等)融入黄埔九佛TOD材料(TOD/综保区/自贸区等),提资清单由两份各12项合并去重为13项详细条目。
- **详细表述**:概念、产业方向、服务模块、提资清单说明均细化,便于直接对外提供。
- 商务大气版式:深藏青+金色主题、色块横幅、表头底纹与斑马纹表格、冻结窗格。
