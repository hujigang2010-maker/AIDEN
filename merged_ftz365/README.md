# 全球自贸365街区项目群 — 合并版交付文件

将两个项目(广州知识城 + 广州黄埔九佛TOD)的服务建议书与 Excel 表格合并、扩充,
并升级为更商务、更大气的版式。提供方:复旦大学住房政策研究中心、上海市杨浦区科技企业联合会。

## 交付文件(`deliverables/`)

| 文件 | 格式 | 内容 |
| --- | --- | --- |
| 全球自贸365街区项目群_策划服务建议书_合并版.docx | Word | 封面横幅、目录、前言、第一篇(知识城)、第二篇(黄埔九佛TOD)各含项目概要/服务范围/成果交付/提资清单/报价,第三篇附件(出口TOP20、消费类TOP20、楼层布局)、服务团队 |
| 全球自贸365街区项目群_提资清单报价与市场数据_合并版.xlsx | Excel(7表) | 项目总览、提资清单(合并24项)、报价汇总(两项目合计278万元)、服务模块对照、附件一出口TOP20、附件二消费类TOP20、附件三楼层功能布局 |

## 合并与扩充说明

- **Word**:合并两个项目的服务建议书(提资清单+服务报价),追加附件市场数据;统一商务大气版式(深藏青+金色主题、色块编号标题、色块横幅封面、表头底纹与斑马纹表格)。
- **Excel**:将两个 Excel 表(知识城提资清单与报价 + 黄埔附件数据表)合并扩充为7个工作表;新增项目总览对比、提资清单合并(含"适用项目"列)、报价汇总(分项目小计+两项目总计)、服务模块两项目对照。

## 重新生成

```bash
pip install python-docx openpyxl
cd scripts
python3 generate_merged_word.py
python3 generate_merged_excel.py
```

文案数据来源于三个源项目模块:`content_zsc.py`(知识城)、`content_hp.py`(黄埔九佛TOD)、`content_cgc.py`(市场数据附件)。
