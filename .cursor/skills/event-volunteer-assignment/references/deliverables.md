# 交付物清单

## 文件命名

- `{活动简称}_志愿者分工方案.pptx`
- `{活动简称}_志愿者分工表.xlsx`

本仓库示例：`2026峰会_志愿者分工方案.pptx`、`2026峰会_志愿者分工表.xlsx`。

## PPT 建议页（可增删）

| 顺序 | 页面 | 目的 |
|------|------|------|
| 1 | 封面 | 品牌/活动名 + 日期场地 |
| 2 | 目录 | 一页导航 |
| 3 | 指挥架构 | 总策划与双总监 |
| 4 | 七组总览 | 代码/人数/一句话职责 |
| 5–11 | 各组详页 | 子职责 + 本组人员 |
| 12 | 实际人员分配 | 全员一表 |
| 13 | 议程责任矩阵 | 时段 × 责任组 |
| 14 | 阶段作战 | 签到/演讲/晚宴等相位 |
| 15 | AB 角 | 关键岗备份 |
| 16 | 应急预案 | 情景 SOP |
| 17 | 里程碑 | D-7→D-day |
| 18 | 到场时间 | 分组到场 |
| 19 | 物资清单 | 品类/数量/责任人 |
| 20 | 外部对接人 | 供应商/场地/主办 |
| 21 | 外部沟通群 | 群用途与管理员 |
| 22 | 晚宴流程 | 若有闭门宴 |
| 23 | C 组对接矩阵 | 环节主对接 |
| 24 | 建议筛选 | 采纳/调整/暂缓 |
| 25 | 会议决议总览 | 各次会议结论 |

## 再生与校验

```bash
python3 build_volunteer_assignment.py
```

打开 PPT/Excel 抽查：封面信息、人员总数、某一关键岗 AB 角、一条应急是否与数据一致。
