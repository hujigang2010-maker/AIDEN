# 七组架构模板（可缩放）

默认总指挥之下：执行总监①统筹 + 执行总监②会务。规模小时可合并 D+E 或 F+G，但职责名目不要丢。

## A 统筹协调组（建议 2–4 人）

- 总指挥：最高决策、主办/协办对外
- 执行总监①：脚本、会议记录、各组协调、对讲中枢、复盘
- 执行总监②：流程/舞台/设备/制作（可兼 C 组长）
- 嘉宾邀约 + 赞助资源落位（可单列一人）

## B 嘉宾接待组（建议 3–6 人）

- VIP 1V1 陪同（主旨/主持/特邀）
- 机场酒店接送与车辆
- 分级签到（VVIP / 演讲 / 机构 / 普通）
- 动线引导、休息室、名片与合影需求登记

## C 会务执行组（建议 6–10 人，演讲型峰会最重）

- 舞台上下场、主持对接
- 圆桌座次与麦序
- 计时、颁奖主导、席卡
- 各演讲/圆桌「主对接」一人

## D 媒体传播组（建议 2–4 人）

- 活动摄影摄像、直播协同
- 合影区与物料露出
- 不与 E 组抢控台，需明确「拍」与「播」边界

## E 技术保障组（建议 3–5 人）

- PPT 收集主责 + 播放/微调
- 麦克风、返听、灯光、视频切换
- 与场地 AV 供应商对接

## F 后勤保障组（建议 3–5 人）

- 物资采买与现场分发（手环、胸花、对讲机、席卡等）
- 茶歇、晚宴餐叙、场地后勤
- 可承接媒体组转来的非拍摄事务

## G 应急机动组（建议 2–4 人）

- 安保/物业对接、人员缺席顶岗
- 医疗与突发客诉
- 敏感信息与舆情一线阻断后上报 A

## 阶段负荷提示

| 阶段 | 加重组 |
|------|--------|
| 签到入场 | B、C、D |
| 演讲/圆桌 | C、E |
| 演出/茶歇 | C、F、D |
| 颁奖闭幕 | C、F、D |
| VIP 晚宴 | B、F、G |
