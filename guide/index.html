只从本指南写明的官网，或手机上的官方应用商店获取软件。安装前看清产品名称、开发商和数字签名。对不上，就先不要装。不要用网盘、聊天群或来历不明的安装包。

即使准备安装，这三件事也不要做
  • 不要装到医院内网、诊疗电脑，或存有患者信息的设备上。
  • 不要在看清价格、续费和退款之前付款，也不要替别人付款或保管支付信息。
  • 不要认为连上 VPN，ChatGPT 等平台就会允许注册。中国大陆不在 ChatGPT 当前支持地区名单中。

三项都写出来，并且上面三件都不碰，才看本机步骤

Windows

  1. 用 Chrome 或 Edge 打开上方链接。
  2. 右键安装包，打开“属性”，查看“数字签名”。
  3. 发布者要和开发商一致。没有签名，就不要运行。
  4. 确认可信后，在允许的情况下安装，并用自己的账号登录。

Mac

  1. 用 Safari 或 Chrome 打开链接。
  2. 确认页面有 macOS 版本，再下载。
  3. 安装时看系统提示的开发者。说不清，就先不要装。
  4. 按说明放进“应用程序”，登录并允许必要权限。

手机

  1. 优先到官方应用商店搜索。
  2. 商店里的开发商要和页面写的是同一家。
  3. 不安装来历不明的 IPA、APK 或描述文件。
  4. 不要为了安装而关闭手机的安全检查。

Perplexity

perplexity.ai
  1. 按官网方式登录。
  2. 在搜索框输入科研问题。
  3. 查看列出的网页和论文。

Elicit

elicit.com
  1. 在允许使用的地区打开并注册。
  2. 选择文献检索。

consensus.app
  1. 登录后进入搜索。
  2. 输入英文医学问题。
  3. 可按权限筛选临床研究或系统评价。
  4. 查看证据并核对原始出处。

岳阳医院针灸科12　现场常见问题

遇到这些情况，按下面做

不要临时改用来路不明的安装包，也不要使用他人身份。

1

软件下载了，但打不开

检查系统版本是否支持，安装包是否来自官网，以及这台电脑是否受到医院设备管理限制。

2

网站能打开，但不能注册

检查邮箱、验证码、账号资格和服务地区。不要使用他人身份，也不要填写不真实的注册信息。

3

已经有 VPN，国外 AI 还是不能用

可能是服务地区、账号状态、网络配置或平台规则。VPN 不能解决全部问题。当前位置不提供服务时，改演示可以合法使用的工具。

4

软件提示需要付款

先确认免费或试用功能是否够用。现场培训优先使用免费功能。不要代为购买，也不要保管他人的支付信息。

5

AI 给出了不存在的医学文献

回到 PubMed、期刊官网或 DOI 解析页面核对。不存在或无法核查的参考文献，不能用于学术论文。
