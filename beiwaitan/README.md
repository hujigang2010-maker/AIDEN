## 一页看懂（One-Pager）

- **品牌一句话**：在时代变化中寻找生命的意义与智慧
- **品牌命名**：北外滩 · 一滴水 · 人文思想之夜
- **落地空间**：上海北外滩 · 一滴水（虹口区北外滩东大名路 501 号）
- **主办联合体**：复旦大学住房政策研究中心 + 首乾书院 + 上海市杨浦区科技企业联合会
- **形式**：下午思想分享（14:00–17:30）+ 晚间人文私享晚宴（18:00–21:00）
- **邀请对象**：高校学者 / 企业家 / 科技创新人士 / 文化领域嘉宾 / 城市发展关注者
- **首场预算**：14–21 万元（含场地/晚宴/物料/摄影/传播/接待）
- **三年愿景**：Y1 首场 + 第二场 → Y2 全年 4 场 → Y3 形成"北外滩思想系列"品牌矩阵
