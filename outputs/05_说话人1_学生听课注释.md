## 第一节：宏观——三大成果与"小牛拉货车"

### 1.1 关于"特朗普访华三大成果"

🎤 **老师说**
> 关税战基本结束（进入震荡）；国家间外交 < 企业间外交，开启新时代；帮扶选举，因为美国面临三大难题（美联储换帅、QE→QT、通胀高企）。

📒 **学生笔记**
- **关税战逻辑**：老师所说"基本结束"应理解为"上行已封顶，进入区间震荡"，并非完全取消。需要持续关注美国新一轮对华关税与中方反制清单。
- **QE / QT 概念回顾**：
  - QE（Quantitative Easing）= 央行扩表买入资产、释放流动性；
  - QT（Quantitative Tightening）= 央行缩表、回收流动性；
  - QT 周期 + 通胀高企 → 美股估值（尤其是高 PE 科技股）受压。
- **"换帅"含义**：美联储主席的更替往往伴随政策框架重置，市场会提前博弈"鸽派/鹰派"组合。
- **"企业间外交"**：实际指向是马斯克级别的企业家访华、签订生态/采购协议。背后对应中国新质生产力相关供应链订单。
- ⚠️ 这一节属于宏观叙事，听课时**重点抓"传导路径"**而不是政治判断：QT → 美股下跌 → A 股短期跟跌 → 4000 点是潜在再起跳点。

### 1.2 关于"A 股第三次倒车接人"

🎤 **老师说**
> 这次是第三次倒车接人，不会跌破 4000，4000 将构成再次起跳的起点。

📒 **学生笔记**
- **"倒车接人"** 是 A 股社区俗语：指主力先打压股价、把散户洗出去，再把价格拉起来重新"接人"上车。在大盘语境里指**指数性的回调买点**。
- 4000 点位为老师的**经验判断**，并非市场共识，应记下来作为参考坐标，不应作为入场唯一依据。
- 实战上更稳妥的方式：**设置分批建仓的网格**，例如 4100 / 4000 / 3900 各放一档仓位，而不是赌单一点位。
- ⚠️ 历史上"打死不破某点"的判断屡有失误，须配合趋势线、成交量和估值分位综合看。

### 1.3 关于"小牛拉货车"与三辆车

🎤 **老师说**
> "小牛拉货车"——小牛 = 美国科技巨头。原 7 巨头分化为三辆车，只看 3 个公司。

📒 **学生笔记**
- 传统"美股七巨头（Magnificent 7）"：Apple、Microsoft、Alphabet、Amazon、Meta、NVIDIA、Tesla。
- 老师未点名"三辆车"具体是谁，结合后文逻辑可推：
  1. **NVIDIA**（AI/算力核心，提到"英伟达将在美国建 3 个厂"）；
  2. **Tesla**（被单列出来讲四大赛道）；
  3. 第三家从后文线索看可能指向 **Microsoft 之外的**——老师明确说"微软都没来"，并提及"苹果 CEO 辞职"，所以第三家可能指向 **以 AI 模型平台为主的公司**（Alphabet/Anthropic/OpenAI 系），具体留待复习时再确认。
- ⚠️ 不要把"三辆车"当成铁律，技术革命中头部公司分化极快。

## 第二节：核心方法论——四重溢价与四次穿透

### 2.1 关于"巴菲特批判"与赛道价值

🎤 **老师说**
> 我们学的价值投资理论从根上就错了；价值投资的价值是赛道价值，不是基本面价值。

📒 **学生笔记**
- 这是老师**最具争议**的立论，需要客观记录：
  - 传统价值投资（巴菲特/格雷厄姆体系）核心：**安全边际 + 自由现金流折现**。
  - 老师的"赛道价值"核心：**未来 3–5 年的产业渗透率 × 龙头排序**。
- 两者并不完全互斥：
  - "基本面价值是地基的钢筋"——老师其实承认基本面是底层；
  - 真正的分歧在于"何处获利"：传统派靠**估值修复**，老师派靠**赛道贝塔 + 龙头阿尔法**。
- ⚠️ **反方观点**：当赛道叙事崩塌时（例如 2021 年中概互联网 / 2022 年新能源车），缺乏现金流支撑的"赛道公司"会跌得最惨。所以方法论需要叠加**赛道生命周期判断**。

### 2.2 关于"四重溢价"

🎤 **老师说**
> 基本面（≤20）→ 赛道（20-30）→ 成长/创新/领先/海外四叠加（30-60，赚钱核心区）→ 情绪价值（60-100）。

📒 **学生笔记**
- **每一重溢价 = 一个估值阶梯**，可以类比"PEG 模型 + 主题溢价"。
- 第三重的四个子项可以理解为乘数：
  - **成长性**：营收/利润增速；
  - **创新性**：研发投入、专利、新品；
  - **领先性**：市占率/技术代差；
  - **海外业务**：出口占比与增速。
- 老师强调"**赚钱核心区 30–60**"——意思是：等所有人都接受赛道时进场太晚，要在"第二重→第三重"之间布局。
- ⚠️ 第四重"情绪价值（60–100）"= 泡沫区，**这就是老师所谓"在泡沫中兑现财富"**。所以这套模型有明确的"卖出纪律"假设——大多数学员往往学了买入忘了卖出。

### 2.3 关于"四次穿透"

🎤 **老师说**
> 穿透股价看企业 → 穿透产业看创新 → 穿透创新看企业家 → 穿透企业家看其选择的中国生态伙伴。

📒 **学生笔记**
- **第四层是整套方法的"灵魂"**：跟踪标准不是中国 A 股自己的赛道，而是**美国三巨头亲手挑的"中国供应商名单"**。
- 这其实是一种"反向 due diligence"——把"全球链主筛选过的供应链"当成自己的研究池。
- 实操路径：
  1. 关注 NVIDIA / Tesla / 等的供应商更新（如 Tier-1 名单、季报 capex 流向）；
  2. 对照中国上市公司的客户结构披露；
  3. 命中即纳入跟踪池。
- ⚠️ 这种方法有滞后性——美国巨头公开认证名单时，股价往往已经反应过一波。所以老师还要叠加"赛道含科率"等先行指标。

### 2.4 关于"含科率"

🎤 **老师说**
> A 股含科率：25% 以下=垃圾；30% 第一里程碑；40% 即将推出 A 股七巨头。

📒 **学生笔记**
- "含科率"= 科技股市值占总市值比重，是**结构性指标**：
  - 越高 → 资金风险偏好越高、估值天花板越高；
  - 越低 → 防御板块主导，新经济很难独立行情。
- 这与海外学术中的 "Tech-heavy index weight" 思路一致（参考纳指 100 中 IT 行业权重 ~ 50%+ 的事实）。
- 📒 学生自己要做的事：**每季度记录一次 A 股含科率**，自己画一张曲线，看看老师说的 25→30→40 是否真实形成趋势。

### 2.5 关于"3–5 个月中线"

🎤 **老师说**
> 短线干不过量化，长线干不过国家队，只做中间 3–5 个月。

📒 **学生笔记**
- 这是一个**清晰的能力圈划定**：
  - 短线 = 日内/周内的高频，机器+算法+数据通道完胜个人；
  - 长线 = 5 年以上的产业资本/汇金/保险/社保，账户结构与资金成本天然占优；
  - 中线 = 介于两者之间，是**散户结合赛道研究最容易获利的窗口**。
- 推论：仓位管理上建议"金字塔"——一只票分 2-3 次买入、分 2-3 次卖出，避开短线情绪冲击和长线估值消化。

## 第四节：重点股票（学生听课式深度注释）

### 4.1 三安光电（600703）—— 周一买入 · "现在站在光里"

🎤 **老师说**
> 周一买一只票，三安光电，不要问为什么；磷化铟芯片，后面有 8 个万亿级市场（都是领袖）；磷化铟产业缺口 30%，中国只有 8 家公司；董事长 + CEO 被留置创造了机会；福建国资委想抢这块肥肉。

📒 **学生笔记**（关键注释）
- **公司画像**：A 股化合物半导体（GaAs/GaN/SiC/InP）龙头，传统主业 LED + 新业务化合物半导体（碳化硅、磷化铟、滤波器、Mini/Micro LED）。
- **磷化铟（InP）的产业地位**：
  - 是 **光通信激光器、CW 光源、光模块**的核心衬底；
  - 也是 **数据中心 1.6T / 3.2T 光模块、硅光、CPO** 的关键材料；
  - 是 **AI 时代电信号→光信号** 的"咽喉材料"——这就是老师说的"站在光里"。
  - 全球玩家集中：日 **住友电工 / JX 金属 / Mitsubishi**，加 **AXT**；中国具备成规模产能的公司有限，**三安+其子公司 InPACT** 是国内核心。
- 📒 **学生对照老师"3 月-4 月 留置"事件——补充三重打击**（用户提供的细节，建议作为听课笔记的对照）：

  **🌪️ 第一重打击：核心管理层动荡与实控人风险**
  - **核心人物被查**：2026 年 3–4 月，实际控制人 **林秀成**、副董事长兼总经理 **林科闯** 相继被国家及地方监察委员会留置调查。
  - **林科闯也是重庆碳化硅项目的核心主导者**——市场担忧重大项目进度。
  - 高管动荡冲击投资者信心 + 引发项目执行担忧。

  **🔗 第二重打击：控股股东股份危机与"被动减持"**
  - **股权全线冻结**：控股股东厦门三安电子有限公司及其一致行动人持有的 100% 股份被司法冻结。
  - **司法强制卖出**：因合同纠纷，2026 年 4 月中旬起，约 5972.01 万股股份在 15 天内被司法强制执行（即被动减持），套现约 8.45 亿元。
  - 这是**纯供给端冲击**——并非基本面恶化，但情绪上极度负面。

  **📉 第三重打击：经营困境与业绩"首亏"**
  - **上市 18 年首次年度亏损**：2025 年归母净利润 -3.53 亿元（自 2006 上市以来首亏）。
  - **2026 Q1**：营收同比 -32.59%，归母净利润同比 -68.15%。
  - 利润下滑原因：

## 学后反思

1. 老师的整体框架是**自上而下"赛道 → 龙头 → 生态伙伴"**，比传统价值派更注重产业 β。
2. 老师的"代号股"机制（几连法 / 东光华 / 尚西安 等）是必要的合规设计，但**也要求听众有较强的产业知识储备**——学生要建立自己的"代号库"。
3. 老师对部分公司（华为、比亚迪、东山精密、国企）**情绪化用词较多**，学生需要**剥离情绪、保留事实判断**。
4. 老师对**三安光电的"逆势看多"**是本节课最值得反复推敲的案例：把"治理风险+被动减持+首亏"重塑为"机会"，背后的判断逻辑是**"治理崩塌触发国资接盘 + 资产基本面未损"**——这是 A 股很多事件驱动机会的经典剧本（**回顾华锐风电、ST 长油、ST 中安……**）。
5. **本份注释不构成任何投资建议**，仅作学习与课后复盘使用。
