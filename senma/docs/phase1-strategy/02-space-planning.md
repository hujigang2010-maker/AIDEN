### 1# 主楼 · 时尚总部（"中国童装时尚灯塔"）

- **目标客户**：巴拉巴拉中国童装研发中心 / 江南布衣 / 之禾 / MO&Co. / 安踏儿童 上海中心 / 外资童装中国总部（如 Carter's、GAP Kids）。
- **空间策略**：每层约 2,400 ㎡，可整层出租或分割（每层 1–2 家）；
- **配套**：1F 大堂集合店、9F 屋顶花园 + T 台彩排空间、地下专属车队入口。
- **签约组合**：长租 5–8 年、装补 800–1,200 元/㎡、免租 12–18 个月、楼层冠名权（"XXX · MODE Hub"）。

### 2# 设计师楼（"中国独立设计师集群"）

- **目标客户**：100+ 独立设计师工作室（从国内一线到海归）+ WGSN/POP 趋势平台 + 面料图书馆。
- **户型**：80 / 150 / 300 / 500 ㎡ 多层组合；可"工位制 + 独立工作室"叠加。
- **共享配套**：每层中部"共享展示橱窗 + Showroom + 茶水 + 接待"模块。
- **特色服务**：
  - 设计师孵化加速（含投资对接）
  - 面料图书馆（5,000+ 面料样品 / 季度更新）
  - 3D 打样间 + 数码印花 + 小批量打版
  - 设计师集合店 + 联名快闪
- **签约组合**：3+3+1 年合同、最高 6 个月免租、装补 300–500 元/㎡。

### 3# 电商基地（"直播 + 跨境双发动机"）

- **目标客户**：抖音/视频号/快手 服饰类目头部 MCN、SHEIN/TEMU/TikTok Shop 商家、网红/主播工作室。
- **产品形态**：
  - 标准直播间 30 ㎡（10 个 / 层）
  - 大型直播 100 ㎡（4 个 / 层）
  - 跨境运营房 200–500 ㎡
  - 网红工位 500 元 / 工位 / 月（共享化妆间 + 拍摄棚）
- **特色实验室（入驻即用）**：
  - 直播一键开播间（多平台分发）
  - 跨境合规中心（关务 + 税务 + 知识产权）
  - 网红培训学院（与院校合作）
  - 数据中台（流量分析 + 投放优化）

### 4# T 台秀场 + 拍摄棚（"中国时装周分赛场"）

- **主秀场**：500–800 人 T 台（可办品牌大秀、买手会）
- **SHOWROOM**：200–250 人 / 多功能（小型发布、订货会、Trunk Show）
- **拍摄棚 ×10**：含 800 ㎡ 大棚 1 个、400 ㎡ 中棚 4 个、200 ㎡ 小棚 5 个
- **配套**：化妆间 / 后台 / 服装存放 / 道具仓 / 媒体直播间
- **商业模式**：会员制（链主免费）/ 按场次（设计师 5,000–30,000 元/场）/ 拍摄棚月卡

### 5# 配套商业 + 童装亲子（差异化卖点）

- **集合店**：50–80 个独立设计师品牌 / 国潮 IP 集合
- **童装亲子区**：巴拉巴拉旗舰 + 亲子餐饮 + 儿童体验 + 早教 / 摄影
- **咖啡 + Lounge**：5 间精品咖啡 + 设计师社交空间
- **酒店式服务**：高端短租 + 海外品牌方驻华办事处

## 四、机电与弱电关键参数（招商话术口径）

- 净层高 ≥ 4.0 m（设计师楼 ≥ 4.5 m；T 台秀场 ≥ 9 m，含吊挂结构）
- 电商直播间预留 ≥ 600 W/㎡ + 单层独立分电箱 + 灯光预留 30A 三相
- 拍摄棚 ≥ 12 m 净高（800 ㎡ 大棚），含吊车与无影屏吊点
- 双路市电 + UPS + 柴油发电机后备 ≥ 8 小时
- 全光网到桌面（POL）+ 5G-A 室分 + Wi-Fi 6E + 直播专线
- 智能门禁 + 人脸 + 车牌识别全覆盖
- 屋面光伏预留 ≥ 800 kW；超充桩 ≥ 50 个
