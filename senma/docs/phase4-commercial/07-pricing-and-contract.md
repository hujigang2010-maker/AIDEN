> 输出：四档收费方案（报价单）+ 合同框架草案 + 三年财务测算模型

### 3.6 风险与对冲

- 入驻率不达预期 → 启动丁档冠名+对赌；释放整楼或 T 台主秀场冠名权
- 政策返还延迟兑现 → 与区财政签确认函 + 改分期口径
- 直播 GMV 收窄 → 转向跨境运营 + 海外仓；引入 SHEIN/TEMU 流量
- 资金紧张 → 集团内信用借款 / Y3 后视入驻率推进 REITs 化

## 五、签约前法务校验清单

- [ ] 用途相符性：与区规划 / 区文旅预先就园区主导业态备案
- [ ] 装修限制：拍摄棚电力 / 直播间隔音 / 童装亲子区安全规范
- [ ] 履约担保：母公司或第三方担保
- [ ] 装补支付：分期 + 资金来源 + 税务处理
- [ ] 政策返还：兑现路径 / 财政确认函 / 不构成独立担保
- [ ] 对赌（丁档）：会计 / 税务影响审查
- [ ] 童模合规 / 直播内容合规 / 跨境数据合规 一并校验
