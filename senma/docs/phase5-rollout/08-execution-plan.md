## 五、运营体系搭建（启动 SOP 一览）

1. **CRM**：飞书多维 / 钉钉智能表 / Salesforce（择一）；上线 SLA：M2 内
2. **客户报备 / 中介佣金**：标准化表单 + 自动化结算
3. **客户成功 NPS**：季度 NPS 调研，评分 < 7 立刻进入挽留 SOP
4. **T 台 / 拍摄 / 直播间预约系统**：会员制 + 在线预约 + 设备调度
5. **直播合规中心**：与市市监 / 网信办对接，备案绿通
6. **跨境合规中心**：海关 + 税务 + 知识产权一站式
7. **数据中台**：流量分析 + 投放 + GMV 看板（与抖音/视频号/快手对接）
8. **财务系统**：用友 / Oracle，分户分摊 + 政策返还专户
9. **品牌运营**：官网 + 微信公众号 + 视频号 + 抖音 + 小红书 + 海外站
10. **复盘机制**：周漏斗、月运营、季董事会、年战略
