## 五、"一企一策"政策包模板（节选）

> 适用于链主级别的总部 / 区域中心。

```
一、租赁权益
- 楼层冠名权
- 起始租金 X 元/㎡·天，X 年一调
- 免租 12–18 个月，装补 800–1,200 元/㎡

二、财税返还
- 区级留成 80% 三年返
- 一次性落户奖励 [金额]
- 研发投入加计扣除政策对接

三、人才
- 人才公寓 X 套
- 落户绿通 X 个/年
- 国际时尚人才工作居留快速通道

四、产业资源
- T 台秀场免费会员
- 拍摄棚 ≥ X 场次/年免费
- 设计师集合店冠名 / 童装亲子区协同

五、跨境与出海
- 跨境合规一站式
- 海外秀场 / 时装周参展补贴
- 海外仓 / 跨境物流补贴

六、品牌与活动
- 年度时装秀主秀场冠名 + 媒体首发权
- 年度站台 ≥ 2 次
- 国际时尚峰会优先位

签署：
甲方（项目方）：
乙方（链主企业）：
丙方（区政府专班）：
```
