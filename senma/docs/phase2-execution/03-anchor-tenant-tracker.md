## 三、统一打法（Playbook）

1. **决策人优先**：能见 CEO/总裁，绝不止步于事业部 GM；BD 总监负责把"行业协会/时尚 KOL"接口排进议程。
2. **首轮拜访 = 先送 4 件礼**：定制提案（一页纸）+ T 台秀场参观券 + 设计师集合店探班 + 童装亲子体验。
3. **闭环动作**：每次拜访后 24 小时内出会议纪要并发对方法务/品牌部确认。
4. **季度复盘**：链主签约里程碑滚动调整，未达标自动触发"集团董事长 + 行业协会"双层升级。
5. **保密**：链主谈判信息按"内部知悉范围最小化"管理，提案分发用水印 PDF。
