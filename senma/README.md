## 顶层逻辑（One-Pager · 给决策人）

- **项目载体（待实测）**：5 万方综合体 · 1# 主楼 + 2# 设计师楼 + 3# 电商基地 + 4# T 台秀场 + 5# 配套商业
- **客群三圈层**：链主品牌总部 → 设计师 + 电商 → 服务+童装亲子（含 T 台与拍摄棚）
- **差异化壁垒**：① 森马童装生态龙头势能；② 设计师 + 直播 + 跨境一站式；③ T 台 + SHOWROOM + 拍摄棚 ×10；④ 童装家庭场景独家；⑤ 政府时尚产业政策包
- **TOP5 链主**：江南布衣 / 之禾 / 安踏儿童 / Carter's GAP Kids / SHEIN 设计中心
- **300 家生态库**：5 家中介 + 9 类来源；线索→签约 17% 转化模型
- **9 月时装秀**：3,000 人次 · 5+ 家签约 · "MODE Hub 时尚 10 条"政策包发布
- **四档商业**：甲(链主月费+政策返还) / 乙(设计师月费+服务) / 丙(电商月费+佣金) / 丁(冠名+对赌)
- **三年目标**：入驻率 92% · 链主 ≥ 3 · 设计师 55 个 · 直播间 90% 使用率 · Y3 EBITDA 转正约 1.35 亿元
