⚙ 企查查 / 天眼查 代理配置

浏览器不能直接调天眼查/企查查（CORS + Key 泄漏）,需要先启动 server/qcc-proxy.js 本地代理, 然后把代理地址填到下方即可。详情见 server/README.md。

📖 启动代理的步骤
  1. 在 天眼查开放平台 申请 API Token。
  2. 设置环境变量并启动代理： 
    export TYC_TOKEN="你的 Bearer Token"
node server/qcc-proxy.js
  3. 把上面的输入框填成 http://localhost:3001 并保存。
  4. 到【企业明细】Tab,点 🔄 同步电话,会逐条补充可见行的电话/法人/统一信用代码等。
✏️ 不想用 API？可以手动录入

在【企业明细】表格中,点击任意电话单元格即可手动录入, 数据会保存到浏览器本地（localStorage）,刷新页面后仍在,也会一并被 CSV 导出。
