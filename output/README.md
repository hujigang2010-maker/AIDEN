# WAIC 2026 全量资源整合总表

## 交付物

- `WAIC2026_全量资源整合总表.xlsx`：把上传的 27 份资料（含大量重复副本）去重后整合而成的统一工作簿。

## 如何重新生成

```bash
python3 scripts/build_waic2026_master_workbook.py
```

脚本默认读取 Cloud Agent 上传目录中的源文件，输出到本目录。

## 工作表怎么用

| 需求 | 打开 |
| --- | --- |
| 看规模与入口 | `01_数据总览` |
| 查源文件去哪了 | `02_资料索引` |
| 查 WAIC 展商/展位/行业 | `03_WAIC参展商` |
| 查品牌评分与优先级 | `05_品牌主库` |
| 查邮箱联系人 | `06_联系人库` / `07_分级联系执行` |
| 查论坛 | `09_论坛日程` |
| 查演讲视频 | `11_演讲视频` |
| 推进会后活动 | `12_活动项目池` + `13_品牌转化台账` |

图像类文档（完整议程长图、高清展位图）无法表格化，已在 `02_资料索引` 标注，请继续使用原 DOCX。
