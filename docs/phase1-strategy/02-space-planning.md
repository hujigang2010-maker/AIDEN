### 总览

| **C 栋** | 共享研发 | 12,000 | 1,200 | 地上 10F + 地下 1F | 仿真 / 数据 / 早期算法团队 + 联合实验室 | 8.0–8.5 + 工位制 |
| **D 栋** | 产业服务 | 10,000 | 1,000 | 地上 10F + 地下 1F | 测试认证 / 投资 / 政府窗口 / 法律 IP | 7.0–8.5（含会议路演） |

| 合计 |  | **70,000 ㎡（地上 60,000 + 地下 10,000）** |  |  |  |  |

### A 栋 · 链主独栋（"链主灯塔"）

- **目标客户**：华为车 BU 上海中心 / 百度 Apollo 华东总部 / Momenta 总部级研发 / 小鹏城市 NOA 中心。
- **空间策略**：可整栋出租 = 1 家；可竖切上下 = 2 家（5F 分隔，独立大堂电梯）。
- **配套**：独立礼宾大堂、CEO 楼层（10F 含露台）、屋顶停机坪/光伏车顶、地下专属车队入口。
- **签约组合**：长租 8–10 年、装补 1,000–1,500 元/㎡、免租 18–24 个月、定制冠名权（"XXX · iDrive Tower"）。

### B 栋 · 生态联办（"产业堆栈层"）

- **目标客户**：地平线区域中心、禾赛工程中心、商汤绝影、轻舟智航、四维图新、经纬恒润。
- **户型**：500 / 800 / 1,500 / 2,500 ㎡ 多层组合（每层最多 3 家）。
- **共享配套**：每层中部"共享路演 + 茶水 + 接待会议"模块，节省企业内部硬装成本。
- **签约组合**：3+3+1 年合同、最高 12 个月免租、装补 500 元/㎡。

### C 栋 · 共享研发（"算法加速器"）

- **目标客户**：早期算法团队、高校转化项目、外地企业上海研发飞地、博士后工作站。
- **产品形态**：
  - 工位制（10–30 工位）8,000 元/月起
  - 小独间 100–300 ㎡ 月付制
  - "共享 GPU 算力 + 仿真平台"会员（外采 + 园区采购共建）
- **特色实验室（入驻即用）**：
  - 数据闭环实验室（脱敏标注/4D 标注）
  - 仿真验证实验室（HiL/SiL/MiL 工位 ≥ 30）
  - 端到端模型联合训练间（与算力厂商共建）

### D 栋 · 产业服务（"一站式办事大楼"）

- **入驻"政企服务窗口"**：
  - 静安区投促办派驻工位 + 一窗通办（注册、变更、补贴申报）
  - 上海市经信委智能网联政策咨询点
  - 公安局交警支队"路测受理点"
  - 海关 / 税务 / 知识产权快速通道
- **第三方服务集群**：中汽研华东、TüV 上海、CATARC 检测、毕马威/普华、君合/方达智驾业务组、专利代理。
- **路演与发布**：1F 设 600 ㎡ 多功能厅 + 媒体直播间（用于 9 月发布会与年度活动）。

### E 栋 · 冠松总部 + 后市场超级体验店

- **B1–1F**：智驾后市场体验店（保险定损、改装、数据上链、二手智驾车）
- **2–3F**：冠松车队 + 4S 联动指挥中心（接入园区企业测试车队）
- **4–8F**：冠松集团总部办公
- **9–10F**：冠松产业基金 + 战略投资部 + 高管接待
- **战略意义**：把"冠松汽车后市场"做成园区企业的真实数据/场景接口，独家差异化壁垒。

## 三、户外自动驾驶测试区方案

### 3.1 选址与红线

- 用地：园区西南角，**1.2 万㎡** 独立围合
- 与 D 栋路演中心相邻，便于发布会"路演 + 实车演示"联动
- 周界 3m 实体围墙 + 电子围栏 + 24h 安保

### 3.2 测试场景设计（"小而精"）

| 场景模块 | 面积 (㎡) | 关键要素 | 适用等级 |
| --- | --- | --- | --- |
| 城市道路缩比环线 | 4,500 | 双车道 + 两个信号灯交叉口 + 公交站 + 斑马线 | L2++ / L3 / 城市 NOA |
| 极限场景区 | 1,800 | Cut-in / 鬼探头 / 加塞 / 异型障碍 | 算法回归测试 |
| 泊车与召唤区 | 1,500 | 立体车位、机械车位、地下/室外混合 | 记忆泊车 / AVP |
| 雨/雾/夜模拟区 | 1,200 | 喷淋系统 + 雾发生器 + 可调照明 | 感知鲁棒性 |
| 路侧 V2X 试验段 | 600 | RSU × 4、5G-A 基站 × 2、边缘计算 | 车路云一体化 |
| 充/换电与维保区 | 800 | 超充 8 位 + 换电站 1 座 + 维修工位 4 | 实车保障 |
| 监控指挥塔 + 数据机房 | 600 | 4D 全景监控、Wi-Fi6E、本地数据中心 100 TB | 数据合规 |
| 备用发布/路演区 | 1,000 | 大屏 + 看台 (200 人) + 媒体位 | 大型活动 |

### 3.3 资质与合规路径

1. 与上海市经信委 / 静安区经委对接，**申请封闭测试场备案**。
2. 与公安交警支队备案 → 园区周边 1.5 km 道路申请 **"测试延伸路段"**（夜间/低峰时段）。
3. 与中汽研华东共建第三方"上路前自评"流程。
4. 数据出境合规：与冠松法务/上海数交所共建数据沙盒。

### 3.4 商业模式

- **会员制**：年费档（链主免费）/ 按场次（生态企业 6,000–20,000 元/场）/ 工程包月。
- **联合冠名**：路侧设备/RSU 由地平线/华为合作冠名。
- **数据反哺**：园区企业测试数据脱敏后入"GS 数据共享池"，权益换权益。

## 六、装修与机电关键参数（招商话术口径）

- 净层高 ≥ 4.0 m（B/C 栋核心区）；A 栋首层挑空 6.0 m
- 楼面荷载 ≥ 4.5 kN/㎡（C 栋实验区 ≥ 7.5 kN/㎡）
- 双路市电 + 柴油发电机后备 ≥ 8 小时
- 单层供电预留 ≥ 200 W/㎡（C 栋 ≥ 350 W/㎡，含算力机柜）
- 全光网到桌面（POL）+ 5G-A 室分 + Wi-Fi 6E 无缝
- 智能门禁 + 人脸 + 车牌识别全覆盖；数据机房 Tier III 等同
- 屋面光伏预留 ≥ 800 kW；超充桩 ≥ 80 个、换电站 1 座
