## 四、客户分群与楼层落位策略（按真实 9F 单楼）

### 4.1 三类客户 · 三段楼层

| 客户分群 | 落位楼层 | 典型客户 | 拟租面积 / 户 | 户数 |
| --- | --- | --- | --- | --- |

| **核心研发企业**（硬件偏重） | 3–4F | 域控 / 座舱 / 传感器 Tier1 / 联合实验室 | 600–1,400 ㎡ | 4–6 家 |
| **算法 / 软件 / 数据** | 6–7F | L4 算法 / 仿真 / 数据闭环 / 高校转化 | 300–800 ㎡ | 6–10 家 |

### 4.2 总目标 · 入驻 12–18 家企业

- 链主级 1–2 家（占 8–9F 整层）
- 核心研发 4–6 家（占 3–4F）
- 算法/软件 6–10 家（占 6–7F）
- 1F+2F 公共展厅与路演中心，整体冠名 1 家（"XX · iDrive Hall"）

### 4.3 客户类型与 C6 用地的合规性

> ⚠️ **C6 教育科研设计用地** 决定了入驻企业必须以"研发设计/中试"属性为主。

- **优先收纳**：研发型企业（含车企城市 NOA 研发部门）、设计公司、第三方测试认证、博士后/产学研基地
- **谨慎收纳**：纯商务总部（需确认行业准入），不得用于纯生产、仓储、零售
- **不得收纳**：制造、物流仓储、教培（K12）、不符合 C6 主导功能的业态
- **建议**：与静安区规划局/经委预先就关键租户主体做"用途相符性"备案

## 五、户外场地（修正认知）

> 此前文档中"1.2 万㎡ 户外封闭智驾测试区"是策划阶段的设想方案，**本地块用地范围内并不具备建设大型封闭测试场的红线条件**。本次规划改为：

### 5.1 户外可用场景（基于 PDF 总平面与车行流线）

- **地块入口区域**：1 进 1 出车行口，可用于发布日的智驾车演示陈列（非常态测试）
- **建筑南侧/东侧硬质广场**：可用作小型动态展示（≤ 200 ㎡，限速 20 km/h 以下）
- **B2 停车层 105 个机械车位中**：可协调 30–50 位作为**智驾测试车专用车位**（含充电、合规标识）

### 5.2 替代「测试场」的解决方案 · 三段式

```
┌──────────────────────────────────────────────────────────┐
│  段 1 · 园区内：静态展示 + 数据中心 + 仿真实验室            │
│   (3–4F 高层高研发 + B2 测试车专用车位 + C 栋?…无 → 改为 4F)│
├──────────────────────────────────────────────────────────┤
│  段 2 · 静安区：申请 1.5 km 周边低峰时段路测延伸路段       │
│   (与区交警支队 + 市公安交警协同 → "iDrive 静安路测专项")  │
├──────────────────────────────────────────────────────────┤
│  段 3 · 嘉定 / 临港 / 临虹桥：与国家级封闭测试场共建会员通道│
│   (与上海智能网联汽车创新中心 / 临港 AI 创新港 签战略合作)  │
└──────────────────────────────────────────────────────────┘
```

> 这一"轻测试场 + 三段联动"策略将我们从"重资产建测试场"中解放出来，**符合"轻资产运营"的操盘思路**，同时保持"测试服务"作为招商话术的强卖点。
