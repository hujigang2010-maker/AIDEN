# 任务2 ｜ 空间功能规划：楼栋分配平面图 + 面积表

> **项目名称**：冠松静安智能驾驶研发中心
> **文档类型**：空间功能规划方案（A~E 栋 + 户外测试区）
> **版本**：v1.0｜状态：草案待评审

## 一、规划总则

### 1.1 规划原则

1. **垂直分层**：每栋楼承担清晰的产业链层级，避免功能混淆。
2. **链主优先**：A 栋整栋专属链主独栋，确保大客户落位的"独立形象 + 独立标识 + 独立动线"。
3. **共享降本**：C 栋设共享研发设施（仿真实验室、数据中心、暗室、EMC 等），降低生态企业自建成本。
4. **闭环测试**：户外测试区与园区主入口形成"展示-体验-签约"动线闭环。
5. **冠松总部作为压舱石**：E 栋承载冠松汽车自身业务，既是基本盘，又是产业应用方。

### 1.2 总体定位

> "5 栋写字楼 + 1 个户外测试区"——每栋楼有"产业角色"，每个角色有"招商目标"，每个目标有"对应客群"。

## 五、户外自动驾驶测试区方案

### 5.1 设计目标

打造**"上海中心城区唯一可办园区内闭环测试 + 数据接入"**的微型测试场，为入驻链主与生态企业提供：

- **算法早期验证**：早于嘉定/临港路测许可前的"内场闭环验证"
- **客户演示 / 媒体直播**：缩短"算法-展示-签约"链路
- **真实场景沉淀**：与冠松 4S 网络车队联动，沉淀维保、置换、二手车真实数据

### 5.2 场景清单

| 场景类别 | 子场景 | 用途 |
|---|---|---|
| 城市道路 | 双向四车道 + 标线 | 车道保持、自适应巡航 |
| 复杂路口 | 十字 + T 字 + 环岛 | 无保护左转、感知融合 |
| 隧道 | 80 米暗光段 | 视觉退化 / GPS 失锁 |
| 雨雾棚 | 30 米可控降雨 | 感知鲁棒性 |
| 坡道 | 8% / 12% | 起步、停车、AEB |
| 弯道 | 半径 30 / 50 m | 极限工况 |
| 障碍物 | 假人 / 假车 / 锥桶 | AEB / FCW |
| 路侧 V2X | 12 个 RSU | 协同感知 |

### 5.3 联动机制（核心创新）

> **"内场预演 → 路侧数据 → 临港/嘉定真实路测"** 三段式协同
> - 园区内验证 → 转报临港路测许可 → 数据回流园区私有云
