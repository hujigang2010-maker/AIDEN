- 区级留成 80% 三年返

## 六、风控与合规边界

- 所有承诺以**书面**形式经区政府专班 / 市级部门确认后方可向客户披露
- 任何"一企一策"未经合规审批前不得进入合同附件
- 严禁以政府名义做无依据的口头承诺
- 政府关系信息按"知悉范围最小化"管理，纪要分发名单受限
