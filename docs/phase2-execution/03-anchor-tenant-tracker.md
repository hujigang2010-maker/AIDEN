### 提案 #1 · 华为车 BU

**主题**：`华为 · 静安智能驾驶上海第二中心 — 城市 NOA 与车路云一体化的"中心城区样板"`

**为什么是华为**

- 鸿蒙智行 + 引望 = 中国智驾最具号召力的链主
- 上海中心已落地金桥，需要中心城区"展示 + 客户接待 + 政府协同"第二极

**华为正缺什么 / 我们独家解决**

| 痛点 | 静安 + 冠松独家供给 |
| --- | --- |
| 中心城区客户接待与政商展示 | A 栋独栋冠名权（"华为 iDrive Tower"），南京西路 30min 直达 |
| 城市 NOA 路测延伸路段 | 联合静安区交警申请 1.5 km 测试延伸路段 + 户外封闭测试区 |
| 鸿蒙生态后市场闭环 | 冠松集团 4S 网络 = 鸿蒙智行华东最大经销/售后协同伙伴 |
| 政企协同 | 静安区"一区一策"——区委书记直接对接 |

**报价与权益（草案）**

- 整栋 18,000 ㎡，签约 10 年
- 起始租金 4.8 元/㎡·天，3 年一调（CPI+0.5%）
- 免租 24 个月 + 装补 1,500 元/㎡（封顶 2,700 万）
- 税收返还属地化"区级留成 80% 三年返"
- 户外测试区免费会员（永久）
- 静安区人才公寓 200 套配额

**下一步**

- T0+15d：陈余承东、王军，约见 上海中心负责人 30min
- T0+30d：上海中心负责人 + 静安区委书记互访
- T0+90d：意向条款书 (Term Sheet) 签署

## 三、统一打法（Playbook）

1. **决策人优先**：能见 CEO/总裁，绝不止步于事业部 GM；GR 总监负责把"区领导/市领导"接口排进议程。
2. **首轮拜访 = 先送 4 件礼**：定制提案（一页纸）+ 户外测试区参观券 + 静安区政策口袋书 + 冠松后市场数据样本。
3. **闭环动作**：每次拜访后 24 小时内出会议纪要并发对方法务/政府事务确认。
4. **季度复盘**：链主签约里程碑滚动调整，未达标自动触发"集团董事长 + 区委书记"双层升级。
5. **保密**：链主谈判信息按"内部知悉范围最小化"管理，提案分发用水印 PDF。
