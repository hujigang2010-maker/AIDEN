## 二、为什么选冠松？

1. **B 栋 12F 整层（1,500 ㎡） + 选项升级**：未来 18 个月内可优先认筹 A 栋 5-9F 一整组（约 5,000 ㎡）。
2. **算法早期闭环**：户外测试区 1.2 km + 12 套 V2X，**XNGP 城区算法可在园内做"小步快跑"回归**。
3. **冠松与上汽 / 大众 / 通用渠道**：可联合开展面向 OEM 的 ADAS 解决方案推介；冠松 4S 网络可承担小鹏售后试点合作。
4. **数据合规**：与静安区网信办联合建立**车载数据合规试验区**，是国内中心城区少有的政策窗口。
5. **人才公寓 / 子女教育**：可申请 30~50 套人才公寓 + 静安重点学区指标对接。
