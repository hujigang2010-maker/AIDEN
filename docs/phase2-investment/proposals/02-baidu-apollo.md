## 一、为什么选静安？

| 维度 | Apollo 关切点 | 静安区匹配度 |
|---|---|---|
| 城市运营 | Robotaxi 上海运营基地 / 商业化展示 | 静安是**上海最具城市感、最适合做 Robotaxi 体验/媒体直播的中心城区** |
| 人才 | 工程团队扩张 | 中心城区研发总部对一线工程师吸引力 > 远郊基地 |
| 政策 | 智能网联牌照 / 数据出境 | 静安区可联动市经信委、网信办，争取"市级 Robotaxi 中心城区试点" |
| 客户 | 上汽 / 北汽 / 一汽合作 | 上海主机厂 / 出行平台密度全国第一 |
| 资本 | 战投合作机会 | 静安金融与跨国总部资源密度高，便于资本/合作对接 |

## 二、为什么选冠松？

1. **B 栋整层升级 A 栋方案**：起步 1 整层（约 2,800 ㎡），24 个月后可优先升级到 A 栋部分楼层做"上海运营中心"。
2. **Robotaxi 友好型户外测试区**：园内 1.2 km 闭环 + 12 套 V2X，可在不依赖临港远郊的情况下做**早期算法回归 + 客户演示 + 媒体直播**。
3. **冠松汽车的整车 / 维保 / 客户资源**：与 Apollo 整车合作伙伴形成"研发-验证-应用"三方联动；冠松可作为 Apollo 平台的车队侧应用方（4S 网络置换车辆批量上 Apollo 平台试运行）。
4. **可争取"中心城区 Robotaxi 体验线"**：联合静安区交通委争取**静安寺-苏河湾-愚园路** 5~8 km 体验线路。
5. **政府背书签约**：分管副区长 + 市经信委智驾处一同站台，提升 Apollo 在上海的政策能见度。
