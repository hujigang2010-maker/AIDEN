## 二、为什么选冠松？

1. **B 栋整层 1,200 ㎡ + C 栋共享 EMC**：起步精装一整层，**共享 EMC / HIL / 暗室**，无需自建昂贵实验室。
2. **车规联合实验室**：与冠松联合建立"征程系列车规级联合实验室"，**绑定冠松 4S 网络真实车辆数据回流**。
3. **客户拜访场所**：静安中心城区"征程方案中心"——主机厂客户拜访方便、媒体直播友好。
4. **路侧 V2X 资源**：园内 12 套 RSU 已预留接口，可作为地平线"车路云一体化"的城市样板间。
5. **政府背书**：可联动静安区委 + 市集成电路专项办公室共同站台。
