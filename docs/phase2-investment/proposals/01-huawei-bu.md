## 二、为什么选冠松？

1. **A 栋整栋独栋（12,000 ㎡）**：华东独家"华为智驾大厦"形象，独立大堂、独立标识、独立动线。
2. **户外自动驾驶测试区**：1.2 km 闭环、12 套 V2X 路侧、雨雾棚 / 隧道 / 复杂路口——**算法早期验证可在园内完成，免去外赴路测的搬运成本**。
3. **冠松场景应用方资源**：
   - 上海 30+ 家 4S 网络的真实维保/置换/二手车数据
   - 与上汽通用、上汽大众等主机厂的现成关系
   - 可与车 BU 解决方案做"应用 + 验证 + GTM"三方联合
4. **政府背书**：静安区委区政府将本项目列为"智能驾驶产业升级重点项目"，**可由分管副区长带队签约 + 媒体发布会**。
5. **临港 / 嘉定双地协同**：园内闭环 → 路侧数据 → 临港开放路测，全链路打通。
