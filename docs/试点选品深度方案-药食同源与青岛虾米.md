# 试点选品深度方案：药食同源饮品 × 青岛虾米

> 对应纪要两大重点方向 | 可直接用于供应商洽谈

---

## 一、药食同源饮品

### 1.1 市场信号

| 信号 | 说明 |
| --- | --- |
| 已验证爆款 | 生姜柠檬饮曾火爆，但保质期仅 7 天 |
| 趋势延续 | 石斛饮、黄精饮等「中式养生 + 即饮化」持续升温 |
| 山姆逻辑 | 饮品区仅约 10 个坑位，5 个为甜饮 → **健康替代**是主路径 |
| 用户画像 | 中产家庭、注重成分、愿意为「功能明确」付溢价 |

### 1.2 产品定义建议

#### 方案 A：生姜柠檬冷压饮（短保，高差异化）

| 维度 | 标准 |
| --- | --- |
| 核心成分 | 生姜汁 ≥8%、鲜柠檬汁 ≥12%、无添加糖 |
| 保质期 | 7–14 天（冷链 0–4℃） |
| 规格 | 330ml × 6 瓶/箱 |
| 目标零售价 | ¥49.9–59.9/箱 |
| 盲测目标 | 口味评分 ≥4.3/5，复购意愿 ≥65% |

#### 方案 B：石斛即饮植物饮（相对长保）

| 维度 | 标准 |
| --- | --- |
| 核心成分 | 石斛多糖 ≥200mg/100ml、赤藓糖醇调味 |
| 保质期 | 6–9 个月（常温） |
| 规格 | 240ml × 10 瓶/箱 |
| 目标零售价 | ¥69.9–79.9/箱 |
| 合规 | 普通食品，避免医疗功效表述 |

### 1.3 供应商画像

| 类型 | 代表 | 优势 | 劣势 | 适配度 |
| --- | --- | --- | --- | --- |
| 新消费品牌 | 好望水、一甸园 | 产品力强、包装成熟 | 产能/价格谈判空间小 | ★★★ |
| 传统药企延伸 | 同仁堂健康、广药 | 背书强、合规好 | 创新速度慢 | ★★☆ |
| 区域冷压工厂 | 华东/华南 HPP 工厂 | 成本低、定制灵活 | 品牌力弱，需我方贴牌 | ★★★ |
| 代工龙头 | 东鹏、华彬（定制线） | 产能大、验厂经验丰富 | MOQ 高 | ★★☆ |

### 1.4 供应链 checklist

- [ ] SC 食品生产许可
- [ ] HACCP / ISO22000
- [ ] 冷链物流能力（短保方案必须）
- [ ] 日产能 ≥3 万瓶（区域试点）/ ≥10 万瓶（全国贴牌）
- [ ] 第三方盲测配合意愿
- [ ] 山姆包装规范（简约、大字体、中英文）

### 1.5 财务测算（方案 A，区域试点 3 个月）

| 项目 | 金额 |
| --- | --- |
| 准入费用 | ~15 万 |
| 首批铺货（华东 15 店） | ~300 万 |
| 冷链物流（月） | ~8 万 |
| 损耗预算（7 天保，5%） | ~15 万/月 |
| 预期月 GMV（保守） | ~200 万 |
| 厂家净取（77%） | ~154 万/月 |

### 1.6 关键风险与对策

| 风险 | 对策 |
| --- | --- |
| 短保损耗高 | 先做华东区域 3 个月，每日补货模式 |
| 盲测不过 | 提前做 3 轮内部盲测 + 200 人外部测试 |
| 功效合规 | 只用「传统食材」「清爽解腻」等表述 |
| 坑位竞争 | 强调「替代甜饮」而非新增品类 |

## 二、青岛优质虾米

### 2.1 机会背景

- 会议纪要**明确点名**：需协助联系山东青岛方面获取优质虾米资源
- 山姆生鲜区已有大米、大闸蟹等成功案例
- 干货海产属于**高客单 + 高信任**品类，符合会员店逻辑

### 2.2 产品定义建议

| 维度 | 标准 |
| --- | --- |
| 品类 | 淡干虾米（南美白对虾或本地海捕小虾） |
| 等级 | 一级（体长 ≥2.5cm，完整率 ≥95%） |
| 产地 | 山东青岛/胶州湾周边，可溯源 |
| 规格 | 500g 真空装（主推）、1kg 家庭装 |
| 目标零售价 | ¥89.9（500g）/ ¥159.9（1kg） |
| 包装 | Member's Mark 风格：简约白底 + 产地大字 |

### 2.3 供应商画像

#### 理想供应商特征

| 维度 | 要求 |
| --- | --- |
| 位置 | 青岛城阳、黄岛、胶州湾周边 |
| 资质 | SC + 出口备案（HACCP 优先） |
| 产能 | 月供应 ≥20 吨，旺季可扩至 50 吨 |
| 工艺 | 传统淡干 / 低温烘干，含盐量 ≤5% |
| 检测 | 可提供农残、重金属、二氧化硫残留报告 |
| 合作意愿 | 接受山姆验厂、账期 45–60 天 |

#### 寻源路径

| 路径 | 动作 | 优先级 |
| --- | --- | --- |
| 纪要指定渠道 | 通过会议资源联系青岛方面对接人 | ★★★ |
| 产地走访 | 城阳水产批发市场 → 加工厂 | ★★☆ |
| 行业平台 | 1688 超级工厂、青岛海产品协会 | ★★☆ |
| 已有合作商 | 国联水产、獐子岛（青岛基地） | ★★☆ |

### 2.4 供应商评估表

| 评估项 | 权重 | 评分标准（1–5） |
| --- | --- | --- |
| 品质稳定性 | 25% | 批次间差异、完整率 |
| 产能与弹性 | 20% | 月产能、旺季扩产能力 |
| 价格竞争力 | 20% | 对比福建、浙江产地 |
| 资质完备度 | 15% | SC、出口、HACCP |
| 验厂配合度 | 10% | 历史山姆/Costco 供货经验 |
| 账期承受力 | 10% | 是否接受 45–60 天 |

### 2.5 财务测算（全国 60 店，稳态）

| 项目 | 金额 |
| --- | --- |
| 准入费用 | ~15 万 |
| 贴牌费（若转 Member's Mark） | +15 万 |
| 首批铺货 | ~600 万 |
| 预期月 GMV（保守，单店 500 包） | ~270 万 |
| 厂家净取（77%） | ~208 万/月 |
| 年化 GMV 潜力 | ~3200 万 |

### 2.6 物流与仓储

| 环节 | 方案 |
| --- | --- |
| 包装 | 在山姆华东仓（嘉兴/天津）周边设简易分装线，或青岛工厂直发 |
| 储运 | 常温干燥，防虫防潮 |
| 周转 | 干货无短保压力，适合首批试点验证流程 |

### 2.7 青岛寻源行动清单

- [ ] **D1–D2**：通过纪要渠道获取青岛对接人联系方式
- [ ] **D3–D5**：远程索取 3 家供应商资质 + 样品
- [ ] **D7**：样品盲测（外观、泡发率、鲜味、含盐量）
- [ ] **D10**：实地考察 1–2 家优选工厂
- [ ] **D14**：输出供应商短名单（3 家）+ 报价对比表
- [ ] **D21**：与中介/山姆方确认品类准入可行性

## 三、两品类对比与试点建议

| 维度 | 药食同源饮品 | 青岛虾米 |
| --- | --- | --- |
| 风口热度 | ★★★★★ | ★★★ |
| 运营难度 | 高（短保/冷链） | 低（常温干货） |
| 流程验证价值 | 高（考验全链条） | 高（验厂/铺货/资金） |
| 资金需求 | 中（~300 万区域） | 中（~600 万全国） |
| 纪要优先级 | 趋势方向 | **明确点名** |
| **建议** | 第二批试点 | **第一批试点** |

### 推荐推进顺序

```
Week 1–2：青岛虾米寻源 + 品牌名单
Week 3–4：三方见面，确定虾米为试点 #1
Month 2–6：虾米跑通盲测/验厂/上架
Month 3 起：并行启动药食同源饮品盲测准备
Month 6+：虾米转贴牌 + 饮品区域试点
```
