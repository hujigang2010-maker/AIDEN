> 有效期：自签发日起 30 天，逾期甲方有权重新核价。

### 1.5 丁档 · 对赌（低租 + 收益分成）

> 用于"高潜力链主级合作 / 战略合资"——本质是把租金部分转化为类股权回报。

| 条款 | 标准 |
| --- | --- |
| 折扣租金 | 标准甲/乙档 60%~70% |
| 业绩对赌 | 3 年累计 / 年度 营收 / 利润 / 估值 / 招聘人数 任一组合（一事一议） |
| 收益分成 | 如对赌达成：按"超额营收 5%–10%"返现给运营公司，封顶 (3 年累计租金减免额 × 200%) |
| 跟投权 | 园区基金享 1%–3% 跟投权（Pro-rata） |
| 退出 | 未达对赌：差额按等额租金或股权补偿，两选一 |
| 履约 | 母公司担保 + 可担保第三方 |
| 适用人 | 链主、Pre-IPO、明星初创 |

> 实务要点：
> 1. 对赌设计**单向**（达不到补偿）+ **双向上限**，避免被动股权风险
> 2. 任何"股权 / Token / 收益权"安排须经集团法务 + 税务 + 投决会审核
> 3. 不得与实控人个人签对赌（须公司主体）

- 资金紧张 → 集团内信用借款 / REITs 化（Y3 后视入驻率推进）
