> 用于"高潜力链主级合作"——把租金部分转化为类股权回报 + 把 1F+2F 公共展厅/大堂转化为冠名资产。

| --- | --- |

| **冠名资产** | 1F 大堂主背景墙 / 2F 展厅 / 屋顶花园 / 楼宇 LED 屏 任组合 |
| 业绩对赌 | 3 年累计 / 年度 营收 / 利润 / 估值 / 招聘人数 任一组合 |
| 收益分成 | 对赌达成：超额营收 5%–10% 返现，封顶 (3 年累计租金减免 × 200%) |
| 跟投权 | 园区基金享 1%–3% 跟投权（Pro-rata） |
| 退出 | 未达对赌：差额按等额租金或股权补偿，二选一 |
| 履约 | 母公司担保 + 可担保第三方 |

> 实务要点：
> 1. 对赌设计**单向**（达不到补偿）+ **双向上限**
> 2. 任何"股权 / Token / 收益权"安排须经集团法务 + 税务 + 投决会审核
> 3. 不得与实控人个人签对赌（须公司主体）
