## 鉴于条款

1. 甲方为冠松静安智能驾驶研发中心项目（以下简称"项目"）的合法运营管理方；

7.3 期满交还时，按附件4《装修恢复约定》执行。

## 第八条 服务承诺（甲方）

8.1 项目运营期内，甲方提供：

   - 物业管理（24 × 7 安保 / 保洁 / 维修响应 ≤ 2 小时）
   - 智能化平台（园区门禁 / 工位预约 / 会议预约）
   - 共享设施（按价目表）
   - 政策落地一站式协助（落户、税务、补贴、人才公寓）
   - 户外测试区接入服务（按使用时段计）

## 第九条 智能驾驶专项条款（特殊约定）

9.1 **测试场使用**：乙方有权按价目表使用园区户外自动驾驶测试区；高峰时段优先级见附件5。
9.2 **数据合规**：乙方在园区内开展数据采集 / 处理活动，应遵守《数据安全法》《个人信息保护法》等法律法规；如因乙方违规导致合规风险，由乙方独立承担。
9.3 **车辆出入管理**：自动驾驶车辆 / 测试车辆出入园区须按附件6《测试车辆管理规则》执行。
9.4 **联合品牌**：乙方有权在所租楼层及指定外立面位置悬挂企业 LOGO；具体方案需经甲方与园区品牌委员会共同审定。
9.5 **联合实验室**（可选）：双方如约定共建联合实验室，按附件7《联合实验室合作协议》单独签订。

   - 房租补贴 / 研发投入加计 / 集成电路或软件专项
   - 人才公寓 ____ 套
   - 智能网联汽车测试牌照 / 路测许可
