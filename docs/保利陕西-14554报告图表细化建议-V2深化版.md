## 一、触点图颗粒度标尺（V2 硬约束复述）

触点图 = **阶段坐标 + 条线泳道 + 点类型分色 + 点下标签 + 跨线竖连线 + 里程碑三角 + 持续性会议横条**。以下四条为全册制图宪法，任何单图规格书均不得突破。

### 1.1 坐标轴

```
横轴（7 阶段，缩写见第二节）：
立项(LX) → 定位(DW) → 首开备货(SK) → 开盘(KP) → 现场施工(SG) → 竣备交付(JF) → 持续服务(CX)

纵轴（5 条线）：
客关线(KG) → 营销线(YX) → 签约线(QY) → 物业线(WY) → 生产线(SC)
```

**术语对齐**：蓝图“五链”为客关/营销/物业/签约/维修；触点图纵轴含生产线。陕西版总图采用 **5 条线 + 维修动作并入物业线褐点区**（交付后维修密集区单列附表 C7），避免主图纵轴 6 行挤压。

### 1.2 点类型与图例

### 1.3 连线、标签、分区

- **竖向连线**：同一时间截面跨线协同；实线=硬交接（成果物移交），虚线=软协同（信息对齐）。
- **点下标签**：禁用“xx”；格式=`编码` 或 `《工具简称》`，字号不小于 7pt。
- **双幅分区**：上幅 LX—KP（45 点）；下幅 SG—CX（59 点）；幅间横条=`月度回顾会、满意度会等会议持续进行`。
- **页眉**：`保利发展陕西平台公司 · 服务品质流程触点图（V__）`；**页脚**：`完整 104 点见附录 D｜来源：赛普研究院`。

### 2.3 分配依据说明（可核对逻辑）

1. **客关线 30 点（最多）**：对应报告“客关定期巡检 16 动作 + 会签 6 节点”的监管属性；上幅偏前置风险（LX/DW/SK 共 11 点），下幅偏交付督导与满意度经营（JF/CX 共 11 点）。
2. **首开备货 SK 20 点（单阶段最多）**：对齐触点图“首开备货长条”视觉权重；汇聚开盘前联合风险检查、样板区销项、合同预审等高密度动作。
3. **竣备交付 JF 20 点 + 持续服务 CX 21 点**：对齐报告下幅 59 点中“交付后痛点”叙述；WY+SC 在 CX 合计 13 点，承接维修重塑与物业日常。
4. **签约线 QY 10 点（最少）**：动作高度集中在 SK/KP/JF 三阶段接口，LX/SG/CX 仅保留衔接点。
5. **点类型建议配比（全 104，制图时校验）**：监管红 ● 约 28%（29）｜业务褐 ● 约 52%（54）｜持续金 ■ 约 12%（13）｜协同 ○ 约 8%（8）。持续点主要分布在 SK 后期、SG 全程横条、CX 月会区。
