本目录存放与"森马（上海）国际运营中心 · Semir Group's Global Headquarter"项目相关的可分发文档。

## 文件清单

| 文件 | 类型 | 用途 |
| ---- | ---- | ---- |
| `森马国际运营中心-项目介绍.pptx` | PowerPoint · 16:9 · 24 页 | 用于会议 / 路演 / 招商现场展示 |

## PPT 设计说明

- **主题**：暗色「潮玩元宇宙」视觉系统，magenta（#FF4F8B）/ violet（#8B5CF6）/ cyan（#06B6D4）三主色 + amber、green 辅助色
- **结构**：封面 → 目录 → 四章节（每章首页 + 内容页）→ 核心价值 → 战略愿景 → THANKS
- **章节覆盖**：
  - **01 项目概况篇**：战略定位 / 宏观区位 / 交通辐射 / 立足周边（数据 + 品牌云）/ 六栋楼宇程序
  - **02 产业规划篇**：产业定位（3 目标 + 5 优势 + 双轮驱动）/ 五层产业金字塔 / 双牌照 / 6 大配套 / 三轨服务
  - **03 商业规划篇**：Z·世代大字标语 / 业态垂直落位表 / 5 大主力业态
  - **04 运营合作篇**：三大旗舰活动 / 拟合作品牌矩阵 / 核心价值六维 / 战略愿景
- **可二次编辑**：所有元素均为可编辑形状与文本框，未使用图片或位图，便于客户根据自身 VI 调整配色

## 重新生成

文档由 Python 脚本生成，可在源数据变化后一键重建：

```bash
pip install python-pptx python-docx
python3 scripts/build_ppt.py      # 重建 PPT
python3 scripts/build_docx.py     # 重建 Word
```

脚本位于仓库根目录 `scripts/` 文件夹下，所有视觉风格、字体、配色、文案均可在脚本顶部统一调整。
