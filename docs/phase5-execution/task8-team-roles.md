## 二、4 人核心团队岗位说明书

### 2.1 项目总监（Project Director）

| 项 | 内容 |
|---|---|
| 直接汇报 | 冠松汽车董事会指定董事 |
| 核心职责 | 1) 项目整体战略、节奏、风险总控；2) 链主企业一线攻坚的"双人组"成员；3) 与政府主要领导层级对话；4) 重大商务条款决策；5) 预算与人事最终审批 |
| 关键 KPI | M1~M8 完整达成；T+12 累计签约 ≥ 12 家、入驻面积 ≥ 22,000 ㎡ |
| 任职要求 | 10 年以上产业园 / 商业地产 / 大型 ToB 项目操盘经验；对汽车 / 智驾产业有基本认知；有政府关系驾驭能力 |
| 薪酬带宽（方向性） | 现金 100~150 万元/年 + 项目奖金 + 股权/分红 |

### 2.2 招商总监（Investment Director）

| 项 | 内容 |
|---|---|
| 直接汇报 | 项目总监 |
| 核心职责 | 1) 漏斗管理（300/150/60/25/12）；2) 链主攻坚日常推进；3) 中介渠道签约与考核；4) 报价单 / 合同条款一线谈判；5) 招商团队建设 |
| 关键 KPI | 300 家库 / 60 家意向 / 12 家签约；中介签约 5 家 |
| 任职要求 | 8 年以上 ToB 销售 / 产业招商经验；CRM 能力；强谈判力 |
| 薪酬带宽 | 现金 80~120 万元/年 + 招商奖金 |

### 2.3 GR 总监（Government Relations Director）

| 项 | 内容 |
|---|---|
| 直接汇报 | 项目总监 |
| 核心职责 | 1) 政府对接路径与汇报；2) 政策包打包与申报；3) 牌照 / 路测 / 数据合规试点；4) 9 月发布会政府层级邀请 |
| 关键 KPI | 政策包 v1.0 落地；区领导级见证 ≥ 3 次；落户 / 房租 / 总部经济三类政策可兑付 ≥ 1,500 万元/年 |
| 任职要求 | 8 年以上政府事务经验，熟悉静安区与市经信委系统者优先；有产业基地申报经验 |
| 薪酬带宽 | 现金 70~110 万元/年 + 项目奖金 |

### 2.4 财务/运营总监（Finance & Operations Director）

| 项 | 内容 |
|---|---|
| 直接汇报 | 项目总监 |
| 核心职责 | 1) 预算 / 财务模型 / 商业模式；2) 物业 / 智能化平台 / 户外测试区运维；3) 装修补贴、押金、税务；4) 入驻服务一站式 |
| 关键 KPI | 三年累计净利达基线 +2,000 万元目标；物业满意度 ≥ 90%；测试场使用率 ≥ 60% |
| 任职要求 | 财务 + 运营复合背景，10 年以上；有大型园区运营经验 |
| 薪酬带宽 | 现金 80~120 万元/年 + 项目奖金 |

## 五、KPI 与激励机制

### 5.1 团队整体 KPI

- **签约面积**（占比 40%）：T+12 月累计 ≥ 22,000 ㎡
- **签约客户数**（25%）：≥ 12 家
- **链主签约**（15%）：TOP5 中 ≥ 1 家
- **政策兑付**（10%）：≥ 1,500 万元/年
- **现金流 / 财务**（10%）：基线达成

### 5.2 个人激励

| 角色 | 激励 |
|---|---|
| 项目总监 | 现金 + 项目分红 + 长期股权 |
| 招商总监 | 现金 + 签约提成（按签约面积阶梯） |
| GR 总监 | 现金 + 政策落地奖金（按兑付额阶梯） |
| 财运总监 | 现金 + 现金流改善奖金（财务对赌） |
| 招商经理 | 底薪 + 个人提成（线索-意向-签约三段） |
| 中介渠道 | 见任务4 模板 |

## 六、运营体系搭建（Run-Operations）

### 6.1 三大平台

1. **CRM 平台**：管理 300 家目标库、漏斗、客户接触记录（建议销售易 / HubSpot / 飞书多维表格）
2. **园区智能化平台**：门禁、工位、会议室、停车、能耗、智能巡检
3. **测试场调度平台**：闭环道路 / V2X / 雨雾棚预约、车辆调度、数据回流

### 6.2 五大手册（运营 SOP）

- 招商工作手册（含话术 / 报价权限 / 漏斗规则）
- 政府对接手册（含汇报模板 / 政策清单）
- 客户入驻手册（合同 / 装修 / 政策办理 / 入驻仪式）
- 园区物业手册（标准 + 智能化）
- 测试场运营手册（含安全 / 数据 / 应急）

### 6.3 三大复盘机制

- 周例会（招商）
- 月度复盘（项目）
- 季度董事会（战略）
