## 一、月度和成功佣金是不是高了？

**是，叠在一起高了。单独看成功佣金并不高。**

上一版建议是：启动费 15 万 + 月度 8 万 + 首年租金 8%（链主 12%）。问题不在「8%」这个数，而在三笔同时收：

| | 上一版（90 天） | 业主实际感受 |
| --- | --- | --- |
| 启动 + 月度 | 15 万 + 8 万 × 3 = **39 万** | 还没人来租，先付一笔顾问费 |
| 成功佣金 | 首年租金 8% | 「8%」听着像切走利润；和中介费又对不上 |
| 中介成交 | 中介拿满佣，我们再拿成功佣金的 50% | 同一单付了两份 |

对照我们自己写过的中介协议（02 号）：常规是 **成交首月不含税净租金 × 100%**，链主最高 150%。这是上海商办听得懂的尺。

上一版 8% × 首年（扣 3 个月免租）≈ 0.7 个月面租金，其实略低于 1 个月。但 **再加 8 万/月**，董事长只会记「又是顾问 + 还要抽成」。

### 对齐后的口径（建议会上就用这个）

| 项 | 新建议 | 对齐逻辑 |
| --- | --- | --- |
| **90 天包干** | **8 万**一次性，含人、材料、带看 | 试跑期 **不另收月度**。相对旧口径 39 万，先砍掉 31 万 |
| **成功佣金 · 自拓** | **首月不含税净租金 × 100%** | 和中介同一把尺，不说 8% |
| **成功佣金 · 锚定** | 单户 ≥ 1,500 ㎡ 或整层：**× 150%** | 与 02 号中介链主档一致 |
| **中介成交** | 业主 **只付一套**：合计不超过该档（100% 或 150%）。中介 70% + 我们 30% | 不再「中介满佣 + 我们再抽 50%」 |
| **甲方自有未报备** | 不付成功佣金 | 不变 |
| **转正后月度** | **4 万/月** | 90 天后再谈。当月若有成功佣金，**月度从该笔佣金抵扣**，避免双计 |
| **包干抵扣** | 8 万包干可抵扣后续成功佣金 | 招到了等于试跑费退回 |

试跑 90 天，业主最大现金支出就是 **8 万**（没有成交的话）。有成交，再按「一个点佣金」付，和请仲量带客同一量级。

转正后一年，若仍按旧口径 8 万 × 12 + 佣金，确实偏贵；新口径大约是 **4 万 × 12 = 48 万**（有成交的月份还被抵掉）+ 按首月计的佣金。

## 二、未来 90 天大概怎么做

原则：人少、动作实、不办发布会、不装修样板间。旧材料里能用的用上，编过的园区梦先放下。

### 90 天要交出来的（必须 / 冲刺）

| | 必须看见 | 冲刺（有更好，没有也能复盘） |
| --- | --- | --- |
| 库 | ≥ 150 家，决策人到人 | 200 家 |
| 接触 | 深度接触 ≥ 8 家 | 12 家 |
| 带看 | ≥ 5 场，每场 48 小时纪要 | 8 场 |
| 意向 | 有效书面意向 ≥ 3 份 | 累计意向面积 ≥ 1,500 ㎡ |
| 渠道 | 中介 2 家签上报备 | 第 3 家 |
| 复盘 | 第 90 天董事长 90 分钟漏斗会 | 1 份锚定 Term Sheet |

达不到「必须」，建议不转正。锚定 TS 放在冲刺，不绑死 90 天，避免为了过关乱承诺。

### 第一段 · D1–30 进场对齐

吸收：实测指标、红黄绿报价、生态库字段、市北同区对标。

- 确认栏填完：对接人、绿区能否直接报、钥匙/图纸/面积表
- 一页楼书（不叫 iDrive Hub，除非他们要）：C6、地上 15,152.75 ㎡、层高 1F 5.7 / 2F 6.3 / 3F 5.7 / 4F 5.4、停车 108、绿建二星、装配式 100%
- 看房动线：1F 接待 → 3–4F 高层高 → 8–9F；1F+2F 自留，不按整车展厅讲
- 目标库种子：顾问材料里的 30 家 + 冠松 4S / 配件 / 保险供应商名录（他们自己就有）+ 市北、西岸同类型搬迁户
- 中介先开 **2 家**（1 家国际行 + 1 家本地），30 天首报；不要一上来五家一起烧
- 每周五周报，字段沿用全稿附件 D

### 第二段 · D31–60 见客户

吸收：谈判绿区、闭门会代替 200 人发布会、案例只当话术不当时长。

- 深接触名单优先从种子里打（地平线、Momenta、禾赛、黑芝麻、联影、微创研发分部、德赛西威、经纬恒润）
- 带看话术三句：中心城区招人、3–4F 层高能进设备、C6 合规做研发；**不讲全国首个智驾总部**
- 需要「别人做过」时，只提 **市北高新（同区）** 和 **西岸 AI 大厦（单栋）**，不陪跑 8 个园区
- 一场 15 人闭门（用 1F/2F 层高），预算甲方出场地茶歇，我们出名单和主持
- 投促办只做项目备案、要材料清单，不口头加码政策

### 第三段 · D61–90 收口

吸收：Term Sheet 节奏、漏斗健康度、M6 杀招改成 90 天决策。

- 把能写的意向写成盖章或授权代表签字的一页纸
- 绿区内能定的定；黄区 48 小时请示，不替他让租金
- 第 85–90 天：漏斗红黄灯 + 带看纪要册 + 转正建议（转 12 个月 / 再试 90 天 / 停）
- 档案可移交，停了也不烂尾
