# 静安 + 上海：公寓 / 酒店相关成败案例（补充）

> 给董事会和政府预沟通用。只写能核对来源的项目与政策事实，并写清和 01#（C6 新建研发楼）的距离。  
> 没有检索到「静安某栋 C6 整栋改酒店已批并营业」的公开案例，不编。失败侧能点名的，多是商办「类住宅」、规划消防搁置、低效用地被收回——用来说明**不能走的路**，不是用来证明「静安没有公寓」。

---

## 先看完这一页

静安和上海**都有**公寓做成的项目，也**都有**改住宿改砸或被叫停的项目。  
做成的，几乎都不是「工业研发用地上，业主自己改成市场化酒店」；  
砸掉的，几乎都是「先按住的来装修、再补手续」或「商办当住宅卖」。

| 做成了，本质是 | 砸了 / 走不通，本质是 | 01# 能抄哪一句 |
| --- | --- | --- |
| 规划先改、政府或园区平台主导、整体持有只租不售 | 二次装修改成能住的、分割销售、未批先改 | 可以谈人才公寓 / 保租房配套 |
| 商办楼宇「商改保」 | 把商办、研发做成类住宅、公寓式办公 | 不能谈诺富特式持牌酒店硬上 |
| 工业升级成更高能级**研发**，旁边另配公寓 | 产业用地空置、产出不达标，政府收回收储 | 01# 已经是 C6，再往酒店走是反向 |

## 一、静安

### 成功（能点名）

**1. 市北高新人才公寓（西苑 / 北苑 / 东苑等）**

- 位置：万荣一路 89 弄（西苑）等，市北高新技术服务业园区内。  
- 谁做的：市北高新集团，2018 年起全市较早一批园区保租房，五个项目近 5000 套。  
- 结果：西苑 504 套，公开报道开售后看房订购踊跃；园区员工、企业包租都有。有住户从附近酒店搬来，租金大约便宜一半。  
- 对 01#：**产品接近董事长要的「能住」**，但土地和主体都不是 C6 业主自改——是园区平台在**租赁住房 / 保租房**用地上建的，只租不售。抄作业要抄「整体持有 + 服务园区人才」，不要抄「我把自己的研发楼改成酒店式公寓对外散租」。

**2. 供合家人才公寓（恒丰路 1 号）**

- 谁做的：上海市供销合作总社，原**商办**改建，静安区房管局支持。静安首家市级人才公寓。  
- 结果：约 310 套，公开报道入住率可到 97%，「房补联动」。这是上海「商改保」在静安的样板。  
- 对 01#：证明静安**认**「低效商办 → 保租房」。主语是商办，不是 C6。01# 要套这条，先要过「你是不是商务楼宇」这一关，默认过不去。

**3. 市北 N070501 单元两幅地：商业（规划酒店）→ R4 租赁住宅（2017）**

- 02-16-A、15-02 两幅，原规划商业、用途酒店，控规调整为四类住宅用地（R4），社会租赁住宅，近千套，服务园区就业人口。  
- 对 01#：静安产业板块里，政府更想要的是**租赁住宅配套产业**，不是再添一座市场化酒店。这是成功案例（租赁住房做成了），对「整栋酒店」叙事反而是冷水。

**4. 走马塘整体转型 + 上药信谊药厂（江场西路 165 号）**

- 中环北沿约 0.6 平方公里工业仓储更新；信谊从工业厂房改为**研发用地**，补地价、提高容积率，2021 年底开工。城建水务等地块走企业自主更新。  
- 对 01#：静安愿意帮「工业升级成研发」。01# **已经是 C6**，再改酒店是反向，难度高于信谊。

**5. 塘南村北块（彭浦）**

- 区收储、带方案出让，科研办公 + **人才公寓** + 绿地；公开报道有达产税收要求。  
- 对 01#：人才公寓写在**收储后再出让的方案**里。业主若走收储，地和主导权会重新谈。

### 失败 / 走不通（静安能讲清楚的）

静安很少把「某栋 C6 改酒店失败」写成新闻。能上桌的是下面几条，比虚构一个失败项目更硬。

**1. 政策红线本身就是「失败预案」**

- 静更新办〔2025〕5 号第 13 条：严禁商务楼宇违规调整为住宅。  
- 第 6 条：低效或产业功能缺失的园区，可收回再开发。  
- 第 7 条：园区内**违法违规用于商务功能**的楼宇，要分类整治。  
- 含义：空置不一定只是「招不满」，也可能变成「被评估、被收回」。先装修成酒店/商住，正好踩进第 7、13 条。

**2. 「酒店」在市北规划里被改掉（见上成功第 3 条）**

- 原规划酒店的商业用地，政府改成 R4 租赁住宅。  
- 含义：在静安北部产业板块，**酒店不是优先保留的产品**。拿「园区需要酒店」去敲门，和区里已经做过的规划方向是反的。

**3. 供合家 / 市北人才公寓不能反证 C6 能改酒店**

- 做成的都是保租房、商改保、R4，主体多为国企平台或商办产权。  
- 没有公开的「冠松这类产业业主在 C6 上开持牌酒店」对照。缺案例本身就是风险：01# 会变成静安的试错样本，董事长「不吃螃蟹」和这条是冲突的。

**4. 全市类住宅整顿在静安同样适用（2017 起）**

- 上海停止审批公寓式办公，出让合同写明不得建公寓式办公。中心城区执行同一套。  
- 「一人公司商住两用」如果滑向类住宅，走的是这条失败路径，不是供合家路径。

## 二、上海市

### 成功（能点名）

**1. 张江之尚（原张江水泥厂，浦东）**

- 存量工业用地更新；2023 年前后通过补地价转为 **C65 研发总部用地**；工业遗存改商业和文体配套；**周边另建** 3 栋保租房（416 户），不是把水泥厂主楼改成酒店。  
- 对 01#：全市样板是「工业 → 研发 + 旁边配公寓」，不是「研发楼改酒店」。补地价、国企平台、多年前期研究，周期以年计。

**2. 商改保：黄浦苏河美欣公寓**

- 原美欣大厦写字楼，空置高；申能与黄浦区属国企合作，整体改造为保租房。  
- 对 01#：成功前提是**商办产权、整体持有、改保租房**。消防和结构是明确堵点（见失败侧）。

**3. 商改保：静安供合家（见上）**

- 全市报道里的静安样本，入住率高。证明政策窗口在「商办兼容租赁住房」，不在 C6。

**4. 张江、嘉定等租赁住宅用地（只租不售）**

- 2017 年起产业板块推 R4 / 租赁宅地，服务就业人口。与市北两幅地同一逻辑。  
- 对 01#：政府给公寓的正规开口是**改规划供租赁住房**，不是业主在工业研发楼里开酒店。

**5. 工业上楼 / M0（作为对照成功）**

- 存量工业提高容积率可免补地价，但文件写明：坚持工业属性，**严防后续用途转变和炒楼炒地**。  
- 对 01#：工业政策在打开的是「更好做产业」，同时把「改成房地产」锁死。不能拿工业上楼当改酒店的依据。

### 失败 / 被叫停 / 高成本卡住

**1. 2017 类住宅清理（全市，有点名处罚）**

市规土公布典型案例，二次装修改居住功能、未整改到位：

| 项目 | 区 | 公开处理 |
| --- | --- | --- |
| 绿地峰尚汇 | 闵行 | 没收违法收入约 2968 万 + 罚款 |
| 驿优商务广场 | 闵行 | 没收约 1177 万 + 罚款 |
| D9 空间 | 嘉定 | 没收约 8741 万 + 罚款 101 万 |
| 明发商业广场 | 嘉定 | 插层、分隔厨卫，拟没收 + 罚款 |

同期：暂停约 148 个类住宅项目网签；拆除煤气、上下水、隔墙，恢复商办；**停止审批公寓式办公**。  
对 01#：这是上海对「办公当住宅做」的长期态度。2025 年楼宇更新允许商办**兼容租赁住房**，官方辟谣过「放开商改住、可分割销售」——产证不变、主体不变、不分割。01# 更不是商办。

**2. 杨浦宝龙旭辉 · 亚朵四号楼（9 月 2 日沟通口述）**

- 规划、消防未过，200 万保证金搁置。同地址另有楼栋后来有亚朵开业。  
- 对 01#：土地没说清、消防没过，钱会先砸进去。同一项目不同楼结果可以相反，不能拿「别人开了」证本栋。

**3. 商改保的公开堵点（成功项目自己说的）**

- 产权分割、小业主谈不拢。  
- 1990–2000 年代楼，大开间改小户型，结构 + 消防按现行标准，施工难、周期长。2000 年后高层改造，住建部门仍在强调审验，严禁打阴影逃避消防。  
- 对 01#：01# 是新建研发楼，消防专篇若按研发报，改住宿等于换一套规范，不是「新楼就一定好过」。

**4. 低效产业用地收回（工具箱 2.0，2025）**

- 闲置处置、单方解约、到期收回、违法整治、强制拆除违建。  
- 对 01#：C6 亩产要求高，长期空置或违规改经营，风险是失去地，不只是租不掉。

## 三、和 01# 对表（汇报时就用这四句）

1. 静安做成的公寓，是市北人才公寓、供合家这类 **保租房 / 商改保 / R4**，不是 C6 酒店。  
2. 静安产业更新做成的，是信谊那种 **工业变研发**；酒店规划在市北还被改成了租赁住宅。  
3. 全市做成的张江之尚，是 **补地价转研发 + 旁边另建公寓**。  
4. 全市砸掉的，是类住宅、先装修后手续、消防过不了。01# 若按诺富特硬上，走的是第 4 条，不是第 1 条。

主攻仍是：不改变 C6 主导功能，问人才公寓 / 专家公寓能否作科研配套；整栋酒店只做经济账。案例用来撑这个顺序，不用来向董事会保证「能改」。
