## 一、怎么看这件事

**该签的不是顾问协议，是「我们替你们招」的委托协议。**

顾问协议的完成标准是开会、出方案、出案例。董事长已经听过业态建议——再签顾问，就是兜圈子。楼要填满，只差一件事：谁在授权范围内把客户带到签约。

现有 01–04 号协议都是园区对外的（租户 / 中介 / 实验室 / 政府）。缺的是冠松把招商操盘委托给操盘方的这一份。05 号把这件事写死。

---

## 二、和另外两种合同的区别

| | 顾问咨询 | 中介居间（02 号） | **本委托（05 号）** |
| --- | --- | --- | --- |
| 谁来招 | 不出面招 | 带客户拿佣金 | **操盘方替业主招** |
| 完成标准 | 报告 / 会议 | 成交一单 | **入驻率节点 + 生效合同** |
| 对漏斗负责 | 否 | 只对自己的客户 | **全楼漏斗、中介统管、周报** |
| 收费 | 按项目或按月咨询 | 首月租金 100%–150% | **试跑包干 + 首月租金同一把尺，中介单不双计** |
| 排他 | 通常无 | 非独家 | **建议先 90 天，再转 12 个月独家** |
| 报价权 | 无 | 无 | **绿区可直接报，黄区 48h，红区董事长** |

## 三、协议骨架（四句话）

1. **谁**：甲方冠松（业主）独家委托乙方（操盘方）招 01# 楼。
2. **干什么**：建库、攻坚、带看、谈判、统管中介、协同政府、盯到盖章和保证金到账。出方案不算完成。
3. **招到什么算完成**：生效租赁合同。90 天必须：库 150、深接触 8、带看 5、书面意向 3。
4. **怎么付钱**：试跑只付包干 8 万；成交按首月净租金 100%（锚定 150%）；中介单业主只付一套。

---

## 四、乙方必须做 / 明确不做

**必须做**

- 目标库 ≥ 200 家，深度接触、带看、纪要
- 在红黄绿授权内报价、起草 TS 和合同商务条款
- 中介统一报备，避免一客多报
- 每周五周报、每月经营会，项目经理每周现场 ≥ 3 天
- 业态按合同执行：高新 + 汽车配套研发；禁止整车展厅

**明确不做（也不收费）**

- 只出 PPT / 案例 / 咨询纪要
- 替甲方盖租赁合同章（除非另有授权委托书）
- 口头加码政府政策、落户、人才公寓
- 向租户或中介收好处费

## 五、收费（v1.1 已对齐）

| 笔 | 建议数 | 为什么 |
| --- | --- | --- |
| 90 天包干 | **8 万**一次性 | 试跑期不另收月度。旧口径 90 天约 39 万，叠高了 |
| 自拓佣金 | 首月不含税净租金 × **100%** | 和 02 号中介协议同一把尺，不说 8% |
| 锚定佣金 | 同上 × **150%** | 单户 ≥ 1,500 ㎡ 或整层 |
| 中介成交 | 业主合计不超过该档 | 中介约 70% + 我们约 30%，不再叠半份满佣 |
| 转正后月度 | **4 万/月** | 第 91 天起；当月有佣金则抵扣 |

**甲方自有未报备客户**不付成功佣金。包干可抵扣后续佣金。

试跑无人成交，业主现金支出 **8 万**。4,000 ㎡ 空一年约少收 949 万。

## 六、授权（董事长不用每单都上桌）

| | 绿区 · 乙方可直接报 | 黄区 · 48 小时批复 | 红区 · 董事长 |
| --- | --- | --- | --- |
| 租金 元/㎡·天 | ≥ 6.5 | 5.8–6.5 | 底线 5.0 |
| 免租（月） | ≤ 9 | 9–15 | 底线 24 |
| 装补 元/㎡ | ≤ 600 | 600–1,000 | 底线 1,500 |

绝对禁止：回扣、未获政府书面文件的政策承诺、包牌照、保 GMV。

---

## 七、业主怎么被保护（不是把楼交给别人瞎承诺）

1. **90 天杀招**：必须项（库 150 / 接触 8 / 带看 5 / 意向 3）达不到，可以不转正，之后不付月度；包干不退。
2. **租赁合同甲方盖章**，乙方不能私自签。
3. **黄区逾期未批 = 不同意**，防止「默认授权」。
4. **虚假报备、收回扣、超授权承诺政策** → 可立即解除并追偿。
5. 业态禁止整车展厅、地上主业态公寓，写进合同。
6. **中介单不双计**：业主只付一套首月佣金。

---

## 八、今天请拍板的四件事

1. **同意走委托招商，先 90 天。**
2. **确认 05b 数字**：包干 8 万 / 首月 100%·150% / 转正后月度 4 万。
3. **指定唯一对接人** + 红区最终决策人（董事长或授权人）。
4. **书面确认绿区可直接报价**，否则每单都要开会，节奏会断。

法务只定稿表述和主体名称；商务结构不建议再改回「按月顾问、不对入驻率负责」。
