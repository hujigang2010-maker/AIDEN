## 详细清单

### 1. 姜黄/生姜柠檬冷压饮 ★★★

| 字段 | 内容 |
| --- | --- |
| **替代逻辑** | 替换饮品区 10 坑中的普通甜饮，健康升级 |
| **品牌候选** | 元气森林（子品牌延伸）、好望水、一甸园、每日鲜语（蒙牛） |
| **差异化卖点** | 0 添加糖、冷压工艺、7–14 天短保、姜辣素 + 维 C |
| **规格建议** | 6×330ml 或 4×500ml 家庭装 |
| **供应门槛** | 需 HACCP + 冷链，华东工厂优先 |
| **风险** | 保质期短，需区域试点控制损耗 |
| **预算** | 准入 ~15 万，铺货 ~800 万（区域） |

### 2. 黑猪肉马蹄丸 ★★★

| 字段 | 内容 |
| --- | --- |
| **替代逻辑** | 直接替代火锅牛肉丸坑位 |
| **品牌候选** | 海欣食品、安井（定制线）、潮汕手打丸品牌（如：潮庭） |
| **差异化卖点** | 黑猪前腿肉 ≥80%、马蹄颗粒、0 防腐剂 |
| **规格建议** | 1kg 大包装，约 40–50 颗 |
| **供应门槛** | 日产能 ≥5 吨，-18℃ 冷链 |
| **风险** | 成本需压到牛肉丸 85% 以下才有价格竞争力 |
| **预算** | 准入 ~15 万，铺货 ~1500 万（全国潜力大） |

### 3. 青岛干虾米（大规格） ★★★

| 字段 | 内容 |
| --- | --- |
| **替代逻辑** | 纪要点名资源，填补高端海产干货坑位 |
| **品牌候选** | 青岛本地加工厂（如：琅琊台周边、城阳水产）、国联水产（定制） |
| **差异化卖点** | 胶州湾溯源、淡干工艺、大规格 500g/1kg |
| **规格建议** | 500g 真空装，Member's Mark 风格简约包装 |
| **供应门槛** | 稳定月供应 ≥20 吨，SC + 出口备案优先 |
| **风险** | 季节波动，需建立多产地备份 |
| **预算** | 准入 ~15 万，铺货 ~600 万 |
| **行动** | **立即联系青岛方面锁定供应商** |

### 4. 石斛/黄精即饮植物饮 ★★☆

| 字段 | 内容 |
| --- | --- |
| **替代逻辑** | 药食同源风口，替代功能饮料 |
| **品牌候选** | 仙草集、同仁堂健康、广药王老吉（养生线） |
| **差异化卖点** | 石斛多糖标注、0 蔗糖、即饮便携 |
| **规格建议** | 10×240ml 或 6×300ml |
| **供应门槛** | 药食同源备案、盲测口味需 ≥4.2/5 |
| **风险** | 功效表述合规、消费者教育成本 |
| **预算** | 准入 ~15 万 |

| 试点 | 理由 |
