## 三、22 个岗位详细 JD

> 薪酬带宽口径：**上海地区年度税前包**（基本工资 + 绩效奖金，不含期权/项目奖）
> 等级口径：D（总监级）/ M（经理级）/ S（资深）/ E（普通）

### 3.1 项目办公室（1 人）

#### 1) 项目总监（GM · D）

- **职责**：全面统筹项目运营 / 链主与重大客户商务谈判 / 集团董事长直报 / 季度董事会复盘
- **画像**：10 年以上产业园 / 大宗租赁 / 智驾产业经验，具备链主级别商务谈判经验，**有上海政府人脉优先**
- **薪酬带宽**：**¥120–180 万** 年包（含 30%–40% 绩效）
- **KPI**：
  - Y1 总入驻率 ≥ 35% / Y2 ≥ 65% / Y3 ≥ 92%
  - Y1 链主 Term Sheet ≥ 1 份
  - 团队 NPS ≥ 70
  - 集团董事长满意度 ≥ 90%
- **直属上级**：集团董事长

### 3.2 GR / 政府事务部（2 人）

#### 2) GR 总监（D）

- **职责**：政府关系 / 政策包 / 合规 / 纪要 / 一企一策协调
- **画像**：政府工作或国企背景 8 年以上，**上海本地资源**，熟悉智能网联政策
- **薪酬带宽**：**¥80–130 万**
- **KPI**：
  - 区/市政府首轮汇报全覆盖（≤ M3）
  - "iDrive 静安 10 条" 落地（≤ M9）
  - 政策包兑现率 ≥ 90%
  - 月度政府对接次数 ≥ 4 次
- **直属上级**：项目总监

#### 3) 政府事务经理（M）

- **职责**：日常区投促办对接 / 纪要撰写 / 政策申报 / 9 月发布会政府嘉宾邀请
- **画像**：5 年以上 GR / 政府公关经验，**有静安/上海中心城区人脉**
- **薪酬带宽**：**¥40–60 万**
- **KPI**：纪要 100% 24h 内出件 / 政策申报通过率 ≥ 80%
- **直属上级**：GR 总监

### 3.3 招商部（8 人 · 核心战斗部）

#### 4) 招商总监（D）

- **职责**：渠道（5 中介 + 自拓）/ 漏斗 / 生态客户签约 / 周漏斗例会
- **画像**：仲量/戴德/世邦 / 张江/临港园区招商背景，10 年以上
- **薪酬带宽**：**¥80–120 万**
- **KPI**：
  - Y1 累计签约 ≥ 18 家 / Y2 累计 45 家 / Y3 累计 78 家（含链主）
  - Y1 出租率 ≥ 35% / Y3 ≥ 92%
  - 漏斗转化（线索→签约）≥ 17%
  - 中介关系满意度 ≥ 80%
- **直属上级**：项目总监

#### 5) 高级招商经理 · 链主线（S）

- **职责**：TOP5 链主企业全程跟进 / 一页纸提案撰写 / 拜访统筹 / 决策人画像
- **画像**：CRM 重度使用 + 智驾或汽车行业 5–8 年 + 链主资源
- **薪酬带宽**：**¥50–80 万**
- **KPI**：
  - 5 家链主每周接触 ≥ 1 次
  - 季度至少 1 家进入 Term Sheet 阶段
  - 月度漏斗推进 ≥ 80%
- **直属上级**：招商总监

#### 6) 招商经理 · 算法/软件线（M）

- **职责**：6–7F 算法软件类客户开发与签约
- **画像**：3–5 年招商经验 + 互联网/科技背景
- **薪酬带宽**：**¥30–45 万**
- **KPI**：
  - Y1 签约 ≥ 5 家 / Y2 ≥ 10 家
  - 月度签约 ≥ 1 家
- **直属上级**：招商总监

#### 7) 招商经理 · 核心研发线（M）

- **职责**：3–4F 高层高研发客户开发与签约（域控/座舱/Tier1）
- **画像**：3–5 年招商 + 汽车 Tier1 / 硬科技背景
- **薪酬带宽**：**¥30–45 万**
- **KPI**：Y1 签约 ≥ 4 家 / Y2 ≥ 6 家
- **直属上级**：招商总监

#### 8) 招商经理 · 中介渠道线（M）

- **职责**：5 家中介日常对接 / 报备审核 / 佣金结算
- **画像**：3–5 年商办销售或渠道经验
- **薪酬带宽**：**¥30–45 万**
- **KPI**：中介带客 ≥ 30 家/季 / 报备 24h 内回执
- **直属上级**：招商总监

#### 9) 招商经理 · 自拓客户线（M）

- **职责**：300 家库自主开发 / 行业活动获客 / KOL 推荐对接
- **画像**：3–5 年 ToB 销售
- **薪酬带宽**：**¥30–45 万**
- **KPI**：自拓签约 ≥ 8 家/年
- **直属上级**：招商总监

#### 10) 销售助理 / CRM 运营（E）

- **职责**：CRM 维护 / 报备表 / 报价单 / 漏斗看板
- **画像**：1–3 年支持类岗位，熟悉飞书/钉钉
- **薪酬带宽**：**¥15–22 万**
- **KPI**：CRM 数据完整率 ≥ 95%
- **直属上级**：招商总监

#### 11) 客户成功经理（M · M7+ 入职）

- **职责**：入驻客户 NPS / 续约 / 投诉 / 客户增值服务
- **画像**：3–5 年商办客户成功

- **KPI**：续约率 ≥ 80% / NPS ≥ 70

### 3.4 运营部（5 人）

## 五、绩效与激励机制

### 5.1 绩效构成

```
基本工资 60%-70%
+ 月度绩效 10%-15%（KPI 达成）
+ 季度奖金 15%-20%（部门集体）
+ 年终奖金 1-3 个月（公司业绩 + 个人）
+ 项目奖金（链主签约时一次性，按贡献分）
+ 期权（核心 8 人，4 年 vesting）
```

### 5.2 链主签约项目奖（一次性）

| 角色 | 奖金（按链主合同金额） |
| --- | --- |
| 项目总监 | 0.5%–0.8% |
| 招商总监 | 0.3%–0.5% |
| 高招（链主线） | 0.3%–0.5% |
| GR 总监（含政策返还） | 0.2%–0.3% |
| 法务（合同护航） | 0.1%–0.2% |
| 集团董事长 | 项目股权或长期激励 |

### 5.3 期权池（核心 8 人）

- 项目层期权池 5%–8%
- 4 年 vesting，1 年 cliff
- 股权激励对象：项目总监 / GR 总监 / 招商总监 / 运营总监 / 市场总监 + 高招/IT/财务
