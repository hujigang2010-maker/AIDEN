## 五、运营体系搭建（启动 SOP 一览）

1. **CRM**：飞书多维 / 钉钉智能表 / Salesforce（择一）；上线 SLA：M2 内
2. **客户报备 / 中介佣金**：标准化表单 + 自动化结算
3. **客户成功 NPS**：季度 NPS 调研，评分 < 7 立刻进入挽留 SOP
4. **测试区调度系统**：会员制 + 在线预约 + 数据合规白名单
5. **政策代办平台**：与区政务服务对接的"一窗通办"
6. **数据合规沙盒**：与上海数交所协议、脱敏标注流程、出境流程
7. **财务系统**：用友 / Oracle，分户分摊 + 政策返还专户
8. **品牌运营**：官网 + 微信公众号 + 视频号 + 海外站（英文）
9. **安保与应急**：园区 24h、户外测试区独立安保 + 数据机房安全
10. **复盘机制**：周漏斗、月运营、季董事会、年战略
