# 复旦大学住房政策研究中心小程序 · 产品说明

## 1. 定位调整说明

既往演示偏「研究成果 + 政策库」。本次按需求调整为：

> **活动型平台**：为未来活动、活动回顾与展示服务，并补充收费入口。

对标对象：复旦管院校友平台小程序（活动报名、组织/社群、终身学习、捐赠支付、个人中心）。

能力来源：管理学院官网栏目职能 + 高层管理教育中心（EE）公开课/定制课/干部教育/咨询闭环。

## 2. 用户与场景

| 用户 | 典型场景 |
|------|----------|
| 学者与青年研究者 | 报名论坛/工作坊，查看回顾与展览 |
| 政府与行业管理者 | 参加沙龙、报名公开课/干部研修 |
| 合作机构与赞助方 | 浏览合作墙，支持中心或企业定制意向 |
| 公众与媒体 | 主题展、动态与公开活动 |

## 3. 信息架构

```
首页
 ├─ 品牌主视觉 / 快捷入口
 ├─ 即将开始的活动
 └─ 中心动态
活动
 ├─ 筛选（论坛/沙龙/培训/参访）
 ├─ 活动详情（议程/票种）
 └─ 支付/报名
回顾
 ├─ 往期回顾
 └─ 主题展览
我的
 ├─ 收费入口（会员/支持中心）
 ├─ 我的订单
 └─ 关于/联系
```

## 4. 收费入口（必须可见）

| 类型 | 对标 | 演示位置 |
|------|------|----------|
| 活动报名费 | 校友活动票务 | 活动详情 → 确认支付 |
| 培训学费/定金 | EE 公开课招生 | 「住房政策公开课」活动 |
| 中心之友年费 | 校友会员/捐赠 | 我的 |
| 支持中心 | 校友捐赠 | 我的 · 任意金额 |
| 企业定制意向 | EE 定制流程 | Excel 规划（线索，非端内大额） |

正式环境需：微信商户号、`wx.requestPayment`、退款与发票规则、活动后台。

## 5. Excel 蓝图用法

1. 用 `01/02` 对齐学院与教育中心「有哪些职能」
2. 用 `03` 对齐校友小程序「怎么做交互」
3. 用 `04/09` 排期住房中心功能
4. 用 `06/07` 定收费与 MVP 边界
