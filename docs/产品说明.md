## 互动吧特色优点 → 复旦链接活动能力

对外品牌仍用「复旦链接」，不挂互动吧名义。能力吸收如下：

| 互动吧优点 | 落地 |
|------------|------|
| 轻松办活动 | 活动模板与标准流程 |
| 海报/邀请函 | 活动详情「生成海报」 |
| 裂变传播 | 分享路径 / 召集官码演示 |
| 多票种售票 | 免费/学生/标准/VIP/对接席 |
| 验票签到 | 我的票夹电子票 + 核销码 |
| 渠道统计 | 运营后台规划 |
| 到场提醒 | 订阅消息规划 |
| 现场互动 | 签到墙 / 抽奖 / 投票演示 |
| 私域沉淀 | 报名后社群 + 会员复购 |
| 交易保障 | 退改规则、订单可查、发票 |

小程序入口：首页「活动能力」横滑 → `pages/features/features`；活动详情工具条；我的票夹。
