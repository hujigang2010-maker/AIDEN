- Excel「09 驻沪领事馆名录」收录 70+ 机构（国家、类型、开馆日、领区、区域概位、负责人姓名）
- **不提供**电话、传真、邮箱、微信
- 小程序点击姓名 → 复制「公开检索关键词」，用户自行查找官网/新闻
- 已知姓名示例：陈玉茹（斐济，领团团长）、陈子勤（新加坡）、王汉（美国）、李德仁（德国）、冈田胜（日本）等；其余标注「请公开检索现任馆长」
- 任职变动频繁，正式邀约以外办确认及馆方书面回复为准
