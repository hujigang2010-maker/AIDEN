# 对外 BP 框架 & 中介/山姆谈判话术

---

## 一、公司对外 BP 框架（10 页结构）

> 用途：拿项目、对接供应商、谈中介合作

### Slide 1：封面

- 项目名称：山姆供应链服务商 / XX 品牌山姆渠道孵化计划
- 一句话：帮优质品牌以最低风险、最快速度进入山姆

### Slide 2：市场机会

- 山姆中国 60 家门店，会员复购率 >80%
- 低 SKU（约 4000）、高周转、23% 渠道扣点
- 纪要验证品类：零食、酒水、调料、生鲜、药食同源、功能性日化

### Slide 3：痛点（我们解决什么）

| 厂家痛点 | 我们的解法 |
| --- | --- |
| 不知道选什么品 | 选品模型 + 100 品牌库 |
| 盲测/验厂过不了 | 中介辅导 + 3 轮预测试 |
| 15 万准入 + 6 个月周期 | 流程托管，按阶段付费 |
| 2000 万铺货资金 | 山姆合同融资过桥 |
| 45–60 天账期 | 供应链金融对接 |

### Slide 4：我们的模式

**定位：山姆供应链服务商（通道 + 服务 + 金融）**

三种合作：
1. 选品代运营（3–10 万/单品）
2. 渠道服务费（销售额 3–5%）
3. 爆品联合孵化（股权 + 分成）

### Slide 5：已验证路径

- 自有品牌试点（3 个月区域）→ 山姆贴牌（24 个月全国）
- 差异化替代策略（不做新品类，替换 existing SKU）
- 分润结构：厂家 77% / 山姆 23% / 中介 1–5%

### Slide 6：试点产品

- 试点 #1：青岛优质虾米（500g/1kg 家庭装）
- 试点 #2：黑猪肉马蹄丸 / 药食同源饮品
- 选品评分模型（五维加权）

### Slide 7：团队与资源

- 渠道负责人 + 采购资源
- 中介团队（验厂/包装/盲测）
- 青岛产地供应链（虾米）
- 银行过桥金融通道（待签约）

### Slide 8：里程碑

| 时间 | 里程碑 |
| --- | --- |
| 第 1 周 | 品牌名单 100 → 10 |
| 第 4 周 | 确定 1–2 试点，三方见面 |
| 第 2–6 月 | 盲测 → 验厂 → 上架 |
| 第 6–12 月 | 转贴牌 + 横向复制 Costco/盒马 |

### Slide 9：合作方式与费用

| 服务 | 费用 |
| --- | --- |
| 选品评估 | 3–5 万/单品 |
| 全流程托管 | ~15 万/单品（含盲测/验厂辅导） |
| 渠道服务费 | 销售额 3–5% |
| 贴牌升级辅导 | 另议 |

### Slide 10：Call to Action

- 本周：确认 1 个试点品类 + 签意向书
- 下周：三方见面（供应商 + 中介 + 我方）
- 联系方式

## 二、与中介谈判话术

### 2.1 开场（建立对等地位）

> 「我们这边已经梳理了 10 个候选 SKU，其中青岛虾米和药食同源饮品是纪要明确的方向。我们负责品牌方和产地资源，你们负责盲测/验厂/山姆内部流程。想聊一下具体怎么分工、费用怎么拆。」

### 2.2 费用谈判（「三三三一」）

> 「纪要里提到中介总抽点 1–5%，三三三一分配。我们这边会带品牌和供应链资源，对接方这一环是我们。想确认一下：15 万单品准入费里，你们全包哪些环节？如果厂家自行退出，20% 商务费怎么算？」

### 2.3 风险控制

> 「合同里需要明确：如果是山姆方原因被刷下来，押金全退。这个条款你们之前的案例里有吗？能否写到协议里？」

### 2.4 分阶段合作

> 「我们不想一上来就铺 2 个品。建议先拿青岛虾米跑通全流程，6 个月验证后再上第二个。你们觉得这个节奏合理吗？」

### 2.5 收尾

> 「下周能否安排三方见面？我们带上虾米供应商样品和品牌资料，你们帮忙评估一下准入可行性。」

## 三、与山姆/采购方沟通话术

### 3.1 品类切入

> 「我们不是来做全新品类的。看了现有货架，我们想做 **XX 现有 SKU 的差异化替代**——比如用黑猪马蹄丸替换牛肉丸，或者用淡干虾米升级现有海产干货坑位。」

### 3.2 产品力强调

> 「产品已经做了 3 轮内部盲测，口味评分 X.X/5。规格按山姆家庭装标准设计，目标零售价对标现有同类低 10–15%。」

### 3.3 供应保障

> 「工厂日产能 X 吨，有 HACCP/出口备案。我们在山姆华东仓周边有分装合作方案，可以保障 45–60 天账期内的稳定供货。」

### 3.4 合作模式

> 「初期希望走自有品牌 3 个月区域试点，验证销量后再谈 Member's Mark 贴牌。我们理解贴牌要求更高，愿意配合额外验厂和 15 万贴牌费。」

## 四、与供应商（青岛虾米）话术

### 4.1 首次联系

> 「我们是 XX 公司，目前在推进山姆会员店供应链项目。会议纪要里明确提到需要青岛方面的优质虾米资源。想了解贵司的产品等级、月产能、以及是否有山姆/Costco 供货经验。」

### 4.2 索要资料

> 「请提供：SC 许可、最近 3 批质检报告、500g 样品 3 份、工厂实拍视频、以及 500g/1kg 两个规格的出厂报价（含 45–60 天账期）。」

### 4.3 验厂预告

> 「如果样品通过，下一步是山姆验厂，周期约 6 个月。我们会安排中介做验厂辅导，厂家需要配合的是 HACCP 记录、原料溯源、车间规范。请问之前有没有类似经验？」

### 4.4 账期与产能

> 「山姆账期 45–60 天，首批铺货约 600 万体量。想确认贵司能否承受这个账期，以及旺季能否扩产到 50 吨/月。」

## 五、常见异议处理

| 异议 | 回应 |
| --- | --- |
| 「山姆门槛太高，做不了」 | 「我们走替代策略，不做新品类。纪要里李锦记、虾米、姜饮都有成功案例。」 |
| 「15 万太贵」 | 「这 15 万包含盲测+验厂+多轮筛选，6 个月全流程。自行退出只损失 20% 商务费。」 |
| 「铺货资金不够」 | 「可以凭山姆合同做银行融资，我们已对接过桥方案，2000 万起。」 |
| 「贴牌 24 个月太长」 | 「先用自有品牌 3 个月试点，验证了再升级贴牌，风险可控。」 |
| 「虾米供应不稳定」 | 「我们要求至少 3 家备份供应商，青岛 + 福建双产地。」 |
