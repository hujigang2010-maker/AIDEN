## 三、收入结构总览（向森马的对话锚点 v1.1）

胡教授团队 5 项现金口径（已去重）：

1. **保底月费 (Retainer)** — 建议 **20–35 万元/月（推荐 28 万）**，覆盖团队 + 数据接口。
2. **专项奖项激励** — 福布斯 / 行业牌照 / 科技小镇相关挂牌，按数量奖励。
3. **活动运营收入** — 科技开放麦 + 潮玩大赛 + 北欧会客厅外事，单场结算。
4. **招商佣金 (Commission)** — 实际成交年租金的 1–2.5 个月，分档计提。
5. **股权分红** — 合资公司净利润 × 30%（含科技企业服务中心利润分配）。

**合资公司额外营收（信息项，对外收费，通过分红体现）**：
- 科技企业服务中心：T+1 年 ≈ 150 万 / T+3 年 ≈ 640 万 / 三年累计 ≈ 1,090 万元

详细测算见 `02_测算模型/合作收益测算模型.xlsx`。

| 园区 | 日租金 (元/㎡/天) |

| 华谊万创新所 / 上海人工智能产业园 | 2.2 |

## 六、与森马洽谈的「四个必须确认」

1. **合资公司架构**：注册资本、股比（建议 51% / 19% / 30%）、董事席位、CSO 由胡教授担任。
2. **月费金额**：建议 **20–35 万元/月（推荐 28 万）**，已基于团队成本反算 + 同业管理费水平。
3. **佣金阶梯**：≤2,000㎡ 计 1 个月、2,001–5,000㎡ 计 1.5 个月、>5,000㎡ 计 2.5 个月。
4. **基金返投绑定**：追觅基金返投比例（建议 1:1.5）、AI 腾讯导入企业的封闭期与佣金归属。
