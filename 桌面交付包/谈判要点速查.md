# 谈判要点速查（一页纸版 v1.1）

> 给胡教授对外（危总 / 森马）汇报时使用的口袋速查卡。
> v1.1：基于真实市场租金调研后的更新版。

## 1. 我们的角色与价值
> 不是"咨询顾问"，而是**资源出资 + 强运营**的合资公司主导运营方。

## 2. 收入结构（6 个口袋，已去重）

向甲方收：
1. **月费保底**：建议 **28 万元/月**（区间 20–35 万；红线 ≥ 20 万）
2. **挂牌奖励**：每项牌照 / 福布斯 / 小镇奖项 → **20–40 万元**一次性
3. **活动收入**：科技开放麦 + 潮玩大赛 + 北欧外事 → 年度净收入 **≥ 240 万**
4. **招商佣金**：成交年租金的 **1 / 1.5 / 2.5 个月**（按面积阶梯），返投基金客户 **+0.5 个月**

向外部企业收（**不向森马**）：

5. **科技企业服务中心**：9 大类增值服务费，T+1 年 ≈ 150 万 / T+3 年 ≈ 640 万

合资公司层面：

6. **股权分红**：30% 持股，前 24 个月 60% 留存（含服务中心利润分配）

## 3. 我们的承诺（写进协议）
- **90 天**接入仲量联行爬楼大数据
- **12 个月**挂牌北欧创新国际会客厅元谷站
- **12 个月**完成首期返投 ≥ 3 家潮玩企业
- **12 个月**挂牌 ≥ 2 项产业牌照 / 福布斯榜单
- **12 个月**举办 ≥ 10 场科技开放麦
- **12 个月**科技企业服务中心营收 ≥ 150 万元（≥ 30 户）

## 4. 我们希望森马的承诺
- 商业 5.2 万㎡ **5 年独家招商运营权**
- 共享配套（直播 / 选品 / 共享设计中心）**直营授权**
- 月费 + 佣金 + 奖项 + 分红组合（不二选一）
- 政府关系**联合体**：森马牵头、合资公司执行
- 服务中心业务排他：森马不得另行设立或委托第三方提供与服务中心实质性竞争的服务

## 5. 谈判红线
- 月费 **不低于 20 万元/月**（推荐谈判区间 25–30 万）
- 持股 **不低于 25%**（建议 30%，含期权）
- CSO 任期 **不少于 5 年**
- 招商佣金归属保护期 **24 个月**
- 客户名单提交后甲方不得绕开签约

## 6. 市场租金对标速记
- 大零号湾办公 / 研发主流：**1.8–2.5 元/㎡/天**（年租 657–913 元/㎡）
- 紫竹信息数码港（5A 甲级）：2.1–2.5
- 高端项目（云境 443 / 夏日汇）：2.3–4.5
- 商业 1F 临街铺位：3.0–5.0（独立定价）

## 7. 一句话总结（v1.1）
> **"森马给底盘 + 危总给地利 + 胡教授给打法。基金 + 基地 + 活动 + 服务中心，把元谷做成中国潮玩出海的国际客厅。"**
