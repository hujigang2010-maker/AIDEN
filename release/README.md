# 发布产物 / Release

本目录包含可直接交付使用的成果，无需安装任何环境。

## 1. 网页打开版本（单文件）

📄 **`杨浦区楼宇经济数据平台.html`**

- 单个 HTML 文件，已内联全部代码与样式。
- **直接双击**即可在浏览器（Chrome / Edge / Firefox / Safari）中打开使用。
- 包含全部功能：数据总览、楼宇数据表（可在页面内导出 CSV）、地图分布。
- 注意：**「地图分布」**模块需要联网（高德地图在线加载）；其余模块完全离线可用。

## 2. 表格（可用 Excel / WPS 打开）

📁 **`tables/`**

| 文件 | 说明 |
| --- | --- |
| `杨浦区楼宇汇总表.csv` | 每栋楼宇一行：楼宇名称、板块、物业类型/等级、报价租金、平均成交租金、物业费、总建筑面积、已租面积、出租率、入驻企业数、竣工时间、标准层层高 |
| `杨浦区楼宇企业明细表.csv` | 每个入驻企业一行：在楼宇信息基础上展开企业名称、所属行业、入驻楼层、租赁面积、成交租金、免租期、经营状态、剩余租期 |

> CSV 文件带 UTF-8 BOM，使用 Excel / WPS 打开中文不会乱码。

## 重新生成

```bash
npm install
npm run release   # 同时生成单文件 HTML 与两张 CSV
```
