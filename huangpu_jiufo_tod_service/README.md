## 说明

本套文件为「策划服务」交付物,由提供方针对黄埔九佛TOD「全球自贸365街区」项目编制,
内容围绕九佛TOD交通枢纽、黄埔综合保税区升级自贸区、广交会365天延展等项目特征定制。
文案统一维护在 `scripts/content.py`,生成脚本沿用广州知识城项目同一套模板。

## 重新生成

```bash
pip install python-pptx python-docx openpyxl
cd scripts
python3 generate_word.py
python3 generate_excel.py
python3 generate_ppt.py
```
