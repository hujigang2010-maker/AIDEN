# 元谷项目联合运营合资公司 — 核心团队招聘计划

> 用于胡教授团队搭建驻场战队，承接合资公司日常运营。
> 编制原则：**3 名全职 + 1 名 CSO（胡教授本人，每周 ≥ 2 个工作日）+ 1 名共享行政/财务**。
> 月度刚性支出约 19.5 万元（含数据接口与差旅，详见 `02_测算模型/合作收益测算模型.xlsx → 03 月费测算`）。

## 二、岗位 1：产业招商经理 × 1

### 岗位定位
- 把仲量联行爬楼大数据 + 追觅基金返投名单 + AI 腾讯生态导流，转化为元谷项目实际签约。
- 对应 PDF 项目产业构成中 40% 小型潮玩 + 20% 服务机构的主力转化窗口。

### 核心职责（KPI 驱动）
1. **数据中台**：90 日内完成仲量联行爬楼大数据接入合资公司中台，并形成 ≥200 家目标客户初筛清单。
2. **爬楼行动**：每月 ≥ 30 家客户上门 / 拜访，转化率 ≥ 8%。
3. **签约执行**：首年累计成交面积 ≥ 12,000㎡（基础场景），分布满足产业五档配比。
4. **客户档案**：建立元谷项目 CRM，归属保护期 24 个月。
5. **联动**：与活动策划、基金投后岗位每周复盘漏斗。

### 任职要求
- 本科及以上，5+ 年产业地产 / 园区招商 / 商业地产经验，有潮玩、文创、AI、机器人、创业园经验优先。
- 熟悉仲量联行 / 戴德梁行 / 高力 / 第一太平戴维斯等机构数据；具备 Excel + Power BI 数据处理能力。
- 熟悉闵行 / 漕河泾 / 张江 / 临港 / 大零号湾产业生态。
- 具备良好的客户资源、央企对接经验加分。

### 薪酬包（建议）
| 维度 | 标准 |
|------|------|
| 月度底薪 | 25,000 元 |
| 月度绩效 | 10,000 元（按 KPI 完成度发放） |
| 招商提成 | 项目实际佣金的 8–12%（见佣金阶梯） |
| 年终奖 | 1–3 个月底薪（公司+个人双轨考核） |
| 其他 | 五险一金、商业医疗、差旅、餐补 |

## 三、岗位 2：国际合作 & 活动策划 × 1

### 岗位定位
- 承接"北欧创新国际会客厅"在元谷站的运营 + "科技开放麦"系列活动 IP 主场化运营。
- 对应 4# 楼 1–3F 潮玩艺术中心 + 4F 直播中心 + 2# 楼 Livehouse 的复合场景。

### 核心职责
1. **北欧会客厅**：12 个月内完成元谷站挂牌；年度承接 ≥ 6 场北欧 / 国际外事接待与路演。
2. **科技开放麦**：年度 ≥ 12 场常规场 + 2 场大场，单场触达 300–500 人；建立赞助商体系。
3. **潮玩大赛**：联动中国动漫集团 / 中国百货商业协会，主导全国潮玩设计大赛（每年 1 届）。
4. **媒体与传播**：与森马品牌部、福布斯方协同，年度品牌曝光 ≥ 5 亿次。
5. **政府补贴**：识别与申请文创、外事、特色小镇相关补贴，年度争取 ≥ 100 万元。

### 任职要求
- 本科及以上（外语、传媒、市场营销、外事相关专业优先），3+ 年大型 IP 活动 / 国际外事经验。
- 英语口语、文书优秀，能独立接待北欧 / 日韩 / 东南亚客户。
- 有潮玩、二次元、科技开放麦类活动经验优先；熟悉直播 / 电商 / 短视频生态。
- 具备活动财务把控能力（赞助、票务、补贴申报）。

### 薪酬包（建议）
| 维度 | 标准 |
|------|------|
| 月度底薪 | 22,000 元 |
| 月度绩效 | 8,000 元（按场次/转化/曝光） |
| 活动分润 | 每场净利的 3–5% |
| 年终奖 | 1–2 个月底薪 |
| 其他 | 五险一金、商业医疗、外事差旅 |

## 四、岗位 3：基金投后 & 政府关系 × 1

### 岗位定位
- 承接追觅科技基金"返投落地"工作；统筹两大产业牌照（AI 潮玩产业基地 / 潮玩次元商业专委会）申报与挂牌；协同乙方（危总团队）做政府关系。

### 核心职责
1. **基金返投**：12 个月内完成首期返投落地 ≥ 3 家潮玩企业，全周期目标 ≥ 8 家。
2. **牌照挂牌**：12 个月内完成 ≥ 2 项产业牌照公开挂牌（AI 潮玩产业基地、潮玩次元商业专委会）。
3. **政府补贴**：协同乙方，争取"科技时尚特色小镇"市/区级奖项落地。
4. **合规与风控**：合资公司投后管理标准化（季度报告、对赌条款、退出路径）。
5. **资本对接**：维护与追觅、AI 腾讯及外部 LP 的关系；建立元谷项目"投资人开放日"机制。

### 任职要求
- 本科及以上（金融、法律、产业经济相关专业优先），3+ 年 PE/VC 投后或政府关系经验。
- 熟悉国家文创基金、工信部专项、上海市级 / 闵行区级科技文创补贴申报。
- 有产业基金返投落地或类似牌照挂牌经验加分。
- 具备良好的撰写能力与跨部门沟通能力。

### 薪酬包（建议）
| 维度 | 标准 |
|------|------|
| 月度底薪 | 22,000 元 |
| 月度绩效 | 8,000 元 |
| 牌照/奖项激励 | 每项挂牌按合资公司奖项激励的 5–10% 发放 |
| 年终奖 | 1–2 个月底薪 |
| 其他 | 五险一金、商业医疗、对外接待 |

## 七、招聘节奏

| 时间 | 关键动作 |
|------|---------|
| T+0 ~ T+1 月 | 合资公司注册 → 释放 3 个核心岗位 JD（猎聘 / 脉脉 / 圈内推荐） |
| T+1 ~ T+2 月 | 完成 3 名核心岗位面试 + 入职；行政/财务由合资公司主导招聘 |
| T+2 月 | 北欧会客厅元谷站 + 仲量联行数据接入；首场科技开放麦上线 |
| T+3 月 | 团队完整就位；启动季度复盘机制 |
