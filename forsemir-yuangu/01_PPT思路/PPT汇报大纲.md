## P2 — 致敬森马：元谷的双重战略身份
- **大零号湾文创融合核心区**：闵行五大中心之一，能级比肩漕河泾、张江。
- **上海市唯一科技时尚特色小镇**：稀缺政策属性。
- **建筑底盘**：总建面 22 万㎡ / 商业 5.2 万㎡ / 1500+ 商业车位 / 元江路单日客流 5–7 万人次。
- **15 分钟车行覆盖**：居住人口 24 万 + 产业办公 12 万。
- 一句话：**"森马给了元谷骨架，我们要给它产业灵魂。"**

## P3 — 我们对元谷的产业判断
- 6 栋楼 1#–6# 既定功能（总部 / Livehouse / 酒店 / 潮玩艺术中心 / 动漫书店 / 餐饮商务）已经是优质零售底座。
- 但纯零售逻辑无法支撑"产业策源"——需要补 3 条产业能级链：
  1. **国际链**：海外 IP / 技术 → 中国首站。
  2. **资本链**：返投基金 → 锁定潮玩中下游产能。
  3. **数据链**：精准画像 → 把每一个 5–7 万人次的客流转化为产业线索。

## P9 — 招商策略：四级漏斗
1. **L1 牌照**：先签头部央企 / 行业协会（10% 配额，首批 3–5 家）。
2. **L2 资本**：追觅基金返投 + AI 腾讯生态导流（中型企业 20%）。
3. **L3 爬楼**：仲量联行大数据触达（小型潮玩企业 40%）。
4. **L4 活动**：科技开放麦 / 潮玩大赛带流（中小型服务机构 20%）。
- **共享配套 10%**：直播中心 / 选品中心 / 共享设计中心，由合资公司直营。

## P9c — 科技企业服务中心（合资公司对外增值收入引擎）

> **关键**：这是**对入驻企业 + 大零号湾区域内潜在企业**收费的对外服务，**不是向森马收费**，作为合资公司增量价值的核心来源。

- **选址**：4# 楼 5F+ 或 5# 楼 5F+ 潮玩产业集群（与北欧会客厅 / AI 共享设计中心同层联动）。
- **9 大类服务**：
  1. 注册落户（公司注册 / 园区落户 / 政策红利申报）
  2. 财税法（代理记账 / 法律顾问 / 税筹）
  3. 知识产权（商标 / 专利 / 潮玩 IP 维权）
  4. 政府补贴申报（高新技术 / 专精特新 / 创新券 / 文创基金）
  5. 人才与签证（居住证积分 / 落户 / 工作签证）
  6. 投融资（路演 / FA / 并购）
  7. 品牌与公关（含潮玩出海）
  8. 数字化工具（SaaS / AI 设计工作站）
  9. 培训与认证（潮玩产业认证 / 出海实操营）
- **三年营收预测（基础场景）**：
  - T+1 年：30 户活跃 × 5 万 ARPU ≈ **150 万** 营收 / 净利 ≈ 53 万
  - T+2 年：50 户 × 6 万 ≈ **300 万** / 净利 ≈ 114 万
  - T+3 年：80 户 × 8 万 ≈ **640 万** / 净利 ≈ 256 万
- **三年合计**：营收 ≈ **1,090 万** / 净利 ≈ **423 万** / 丙方 30% 分红 ≈ **127 万**

## P13 — 收入结构（v1.1 已含科技企业服务中心，6 条流向）
1. **固定月费 (Retainer)**：**20–35 万元/月（推荐 28 万）**，甲方支付，按月。
2. **招商佣金**：成交年租金 1 / 1.5 / 2.5 个月（按面积阶梯），甲方支付，起租后。
3. **活动运营收入**：单场净利分成，外部 + 甲方混合，按场结算。
4. **专项奖项激励**：牌照 / 福布斯 / 小镇奖项一次性，甲方支付，按事件。
5. **科技企业服务中心**：9 大类增值服务费，**外部入驻企业付费（不向甲方收）**。
6. **股权分红**：合资公司净利 × 30%（含服务中心利润），年度结算。
